코드 인터프리터

Code Interpreter

AI가 격리된 실행 환경(샌드박스)에서 코드를 직접 짜서 실행하고, 오류가 나면 스스로 고쳐 다시 돌린 뒤 그 결과로 답하는 기능이다. 글로만 답하면 틀리기 쉬운 계산, 데이터 분석, 그래프 그리기, 파일 변환처럼 정확한 결과가 필요할 때 쓴다.

구분일반 답변코드 인터프리터
계산머릿속 추정이라 틀릴 수 있음실제로 실행한 값
파일내용을 글로 읽기만 함열고 가공해서 새 파일로 저장
결과물텍스트표, 그래프 이미지, 변환된 파일

ChatGPT의 Code Interpreter가 이 방식을 널리 알렸다.

파일 올리고 말로 시키면 된다

ChatGPT에서는 CSV나 엑셀 파일을 올리고 "월별 매출 추이를 그래프로 그려줘"라고 하면 된다. AI가 pandas로 데이터를 읽고 matplotlib으로 그래프를 그리는 코드를 짜서 실행한 뒤, 이미지와 함께 쓴 코드도 보여준다.

API에서는 OpenAI 응답 요청에 code interpreter 도구를 켜 두면 모델이 필요할 때 알아서 코드를 실행한다. 다른 주요 AI 서비스도 비슷한 코드 실행 도구를 제공하므로, 쓰는 서비스의 도구 문서를 확인하면 된다.

정확한 숫자가 필요할 때 쓴다

상황쓸까?이유
통계, 집계, 복잡한 계산쓴다실행 결과라 숫자가 정확하다
그래프, 파일 형식 변환쓴다결과물을 바로 받을 수 있다
글쓰기, 요약, 아이디어안 쓴다실행할 코드가 없다
최신 웹 정보 찾기안 쓴다보통 인터넷이 막혀 있어 웹 검색이 맞다

샌드박스라 생기는 한계

실행 환경은 안전을 위해 외부 인터넷이 막혀 있는 경우가 많아, 새 라이브러리를 설치하거나 외부 API를 부르기 어렵다. 또 세션이 끝나면 올린 파일과 만든 결과가 사라지므로 필요한 결과물은 바로 내려받아 두는 게 좋다.

코드가 오류 없이 돌았다고 해서 분석이 맞다는 뜻은 아니다. 잘못된 열을 골랐거나 결측값을 빼 버렸을 수 있으니, AI가 쓴 코드를 열어 기준이 맞는지 확인한다.

직접 만들 때는 어디서 돌릴지 고른다

자기 앱에 같은 기능을 넣으려면 코드를 실행할 곳을 정해야 한다. 어디서 돌리느냐에 따라 편의성과 위험이 달라진다.

방식예특징
서비스 내장ChatGPT, OpenAI API 도구설정이 가장 쉽다
클라우드 샌드박스E2B격리된 환경을 직접 제어
브라우저 실행Pyodide서버 없이 사용자 브라우저에서 파이썬 실행
내 컴퓨터에서 실행Open Interpreter로컬 파일을 다룰 수 있지만 실행 전 확인 필수

내 컴퓨터에서 직접 돌리는 방식은 AI가 파일을 지우거나 바꿀 수 있으므로, 실행 전에 코드를 확인하는 설정을 켜 두는 것이 안전하다.

주로 데이터 파일을 맡겨 결과물을 받는다

가장 흔한 방식은 파일을 올리고 분석·가공을 말로 시키는 것이다. 코드를 몰라도 집계, 그래프, 형식 변환을 받을 수 있고, 계산 결과가 맞는지는 AI가 보여준 코드로 확인한다.

어디서어떻게 쓰나
ChatGPT 같은 챗봇엑셀·CSV를 올려 월별 집계, 추이 그래프, 이상값 찾기를 시킨다
문서·파일 작업CSV를 엑셀로 바꾸거나 여러 파일을 합치고, 결과 파일을 바로 내려받는다
계산 확인통계나 복잡한 수식을 글로 추정하지 않고 실제로 실행한 값으로 답을 받는다
자체 앱·에이전트API에서 코드 실행 도구를 켜 두고, 계산·분석이 필요한 단계만 모델이 코드로 처리하게 한다
