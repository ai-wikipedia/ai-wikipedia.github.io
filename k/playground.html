플레이그라운드

AI Playground

플레이그라운드는 코드 없이 브라우저에서 바로 LLM을 불러 프롬프트를 시험하는 웹 화면이다. 새 프롬프트가 잘 먹히는지 빠르게 확인하고 다듬을 때 쓴다.

한눈에 보기

플레이그라운드는 코드 없이 브라우저에서 바로 LLM을 불러 프롬프트를 시험하는 웹 화면이다. 프롬프트를 입력하고 실행을 누르면 답이 바로 뜨고, 마음에 안 들면 문구를 고쳐 다시 누르면 된다. 개발 환경을 세팅하지 않고 모델과 대화하듯 프롬프트를 다듬는 실험실이다.

항목코드로 직접 호출플레이그라운드
준비개발 환경·SDK 설치브라우저만 있으면 됨
문구 하나 고칠 때코드를 다시 실행고치고 실행 버튼
파라미터 바꾸기코드에서 값 수정슬라이더로 조절

지시문과 온도를 바꿔 가며 비교한다

가장 흔한 사용법은 시스템 프롬프트를 바꿔 가며 답의 성격을 비교하는 것이다. "친절하고 짧게 답하라"와 "전문가처럼 근거를 들어 설명하라"의 결과를 나란히 놓고 보면, 어떤 지시가 원하는 톤을 만드는지 금방 감이 온다. 한 문장 고칠 때마다 코드를 다시 돌릴 필요가 없으니 이런 비교가 귀찮지 않다.

온도(temperature)도 슬라이더를 움직이며 눈으로 확인할 수 있다.

온도답의 모습
0에 가깝게매번 비슷하고 안정적인 답
높게표현이 다양하고 예측하기 어려운 답

변수로 여러 입력을 시험하고, 코드로 옮긴다

프롬프트에 {{변수}} 자리를 넣어 두면 지시문은 그대로 두고 값만 바꿔 가며 여러 입력을 한 번에 시험할 수 있다. 같은 지시가 입력마다 어떻게 답하는지 한 화면에서 확인하는 셈이다.

문구가 어느 정도 완성되면 코드 보기 기능으로 지금 설정 그대로 호출하는 API 코드를 복사해 실제 앱에 붙이면 된다. 놀이터에서 다듬은 결과가 곧 제품 코드로 이어진다.

저장·버전·평가까지 하는 작업 공간

요즘 플레이그라운드는 한 번 눌러 보고 마는 곳을 넘어 프롬프트를 저장하고 관리하는 공간이 되고 있다. 프롬프트를 바꾼 뒤 결과가 전반적으로 좋아졌는지 알고 싶다면 평가 기능을 쓰면 된다.

기능하는 일
버전 관리초안·검증·운영 딱지로 이력 관리
평가입력 예시를 모아 결과를 나란히 채점
공유팀원과 프롬프트를 함께 다듬기

여기서 잘 나와도 서비스에서 다시 확인한다

플레이그라운드에서 잘 나온다고 실제 서비스에서도 똑같으리라는 보장은 없다. 여기서는 보통 한 번의 대화를 짧게 확인하지만, 실제 앱에서는 긴 대화 기록이 쌓이고 사용자 입력도 제각각이라 훨씬 다양한 상황을 만난다.

그래서 놀이터는 아이디어를 빠르게 검증하는 출발점으로 삼고, 실제 트래픽에 가까운 조건에서 다시 점검하는 과정을 거쳐야 한다.
