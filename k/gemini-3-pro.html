제미나이 3 프로

Gemini 3 Pro (Google)

구글이 만든 Gemini 3 세대의 대표 추론 모델이다. 이미지·영상·PDF·코드가 섞인 자료나 코드 저장소 전체처럼 긴 자료를 한 모델로 처리하고 싶을 때 쓴다.

한눈에 보기

Gemini 3 Pro는 구글(딥마인드)이 2025년 11월 프리뷰로 공개한 Gemini 3 세대의 대표 모델이다. 글만 잘 쓰는 모델이 아니라 깊게 생각하고 도구를 직접 다루는 데 초점을 맞췄다. 긴 자료나 여러 형식이 섞인 자료를 한 모델로 처리하고 싶을 때 쓴다.

항목내용
입력텍스트·코드·이미지·오디오·동영상·PDF
컨텍스트 창100만 토큰
강점추론, 도구 사용, 바이브 코딩
상태프리뷰 (출시 시점 기준)

무엇이든 통째로 넣고 묻는다

여러 형식을 한 번에 넣을 수 있고 컨텍스트 창도 커서, 코드 저장소 전체나 긴 문서 묶음을 통째로 넣고 질문할 수 있다. "이 영상에서 무슨 일이 벌어지는지 설명해줘", "이 PDF 더미에서 핵심만 정리해줘" 같은 일을 모델 하나로 끝낸다.

수학·물리 추론과 시각 정보 이해도 강하다. 표·그래프·차트처럼 정보가 빽빽한 자료를 읽고 해석할 때 맡기면 좋다.

API는 AI Studio, 터미널은 Gemini CLI

개발자는 모델 ID gemini-3-pro-preview로 Gemini API를 부른다. 어디서 쓰느냐에 따라 통로가 다르다.

쓰는 곳방법이럴 때
구글 AI StudioAPI 키를 받아 코드에서 호출프로토타입 후 Cloud Run 배포
Vertex AI클라우드 환경에 연결엔터프라이즈
Gemini CLI최신판 설치 후 프리뷰 기능 켜기터미널에서 에이전틱 코딩

CLI는 npm install -g @google/gemini-cli@latest로 설치하고 설정에서 프리뷰 기능을 켜면 Gemini 3 Pro가 기본 모델이 된다. 그러면 모델이 직접 명령을 실행하고 도구를 부르며 복잡한 엔지니어링 작업을 단계적으로 푼다. 같은 시점에 나온 에이전트 개발 환경 Antigravity에서도 모델이 계획을 세우고 코드를 짠다.

자세한 사양 없이 앱을 만든다

커뮤니티에서 가장 많이 꼽는 강점은 바이브 코딩이다. "이런 앱을 만들어줘" 정도의 자연어 지시만으로 계획부터 코드 생성까지 한 번에 처리한다. 아이디어를 빠르게 동작하는 결과물로 만들어 보고 싶을 때 잘 맞는다.

프리뷰라 지원이 제한된다

출시 시점에는 프리뷰라 "있는 그대로" 제공되고 지원이 제한될 수 있으며, 곧 gemini-3.1-pro-preview 같은 후속 버전이 나왔다. 오디오를 세밀하게 분석하거나 이미지를 영역 단위로 나누는 일은 우선 설계 대상이 아니므로, 그런 작업에는 다른 모델을 함께 쓰는 편이 낫다.
