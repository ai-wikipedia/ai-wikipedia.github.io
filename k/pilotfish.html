Pilotfish

PilotFish는 서로 다른 시스템 사이에서 데이터를 받아 형식을 바꾸고 알맞은 곳으로 보내 주는 데이터 통합 플랫폼이다. 레거시 시스템이나 의료 시스템처럼 고치기 어려운 시스템을 새 AI 서비스와 이을 때, 양쪽은 그대로 두고 그 사이에 연결 레이어로 넣어 쓴다.

도구 종류주로 하는 일이럴 때 쓴다
PilotFish (통합 엔진)데이터 변환·라우팅레거시·의료 시스템 연결
n8n 같은 자동화 도구앱 사이 작업 흐름 자동화SaaS 연동, 간단한 자동화
LangChain 같은 AI 프레임워크LLM 호출, 에이전트 구성AI 기능 자체 개발

만드는 도구와 돌리는 엔진이 따로 있다

연결은 개발 도구인 eiConsole에서 만든다. 데이터를 어디서 받고, 어떻게 바꾸고, 어디로 보낼지 정하는 일이다. 완성된 설정은 런타임 엔진인 eiPlatform이 실제로 돌린다. 온프레미스, 클라우드, 외부 기관과 연결하는 환경 모두에서 동작한다.

순서할 일
1. 받기원본 시스템 연결 (DB, 파일, API 등)
2. 바꾸기원본 형식을 목적지 형식에 맞게 매핑
3. 보내기조건에 따라 알맞은 목적지로 전달
4. 운영eiPlatform에 배포해서 계속 실행

AI 앞에서 '번역기' 역할을 한다

병원에서 기존 EMR과 새 AI 진단 서비스를 연결하는 경우를 생각해 보자. 두 시스템은 데이터 형식이 달라서 그대로는 대화가 안 된다. 이때 PilotFish가 중간에서 형식을 바꾸고 전달해 준다. 의료 분야는 표준 메시지 형식이 여러 가지라 이런 엔진이 특히 많이 쓰인다.

AI 분석 파이프라인을 만들 때도 쓸 수 있다. 레거시 DB, REST API, 파일처럼 여기저기 흩어진 데이터를 한 레이어로 모으고, 같은 형식으로 정리해서 AI 모델에 넣는다.

AI 전용 도구가 아니라는 점에 주의

PilotFish는 AI 전용 플랫폼이 아니라 범용 통합 솔루션이다. 데이터를 깨끗하게 옮기는 일은 PilotFish에 맡기고, 프롬프트 흐름이나 에이전트 같은 AI 작업 자동화는 LangChain이나 n8n에 맡겨 역할을 나누는 게 좋다.

연결할 시스템이 한두 개뿐이고 형식도 단순하다면 직접 코드를 짜는 편이 더 가벼울 수 있다. 연결이 많고 형식이 복잡하거나, 오래 안정적으로 운영해야 할 때 들일 만한 도구다.

의료 연동과 AI 데이터 준비에 주로 쓴다

가장 흔한 건 의료처럼 표준 메시지 형식이 많은 분야에서 시스템끼리 데이터를 주고받게 하는 일이다. 같은 연결 레이어를 AI 서비스 앞단에 두고, 흩어진 데이터를 정리해 넘기는 데도 쓴다.

어디서어떻게 쓰나
병원 내부 시스템 연동EMR 등 여러 시스템이 보내는 메시지를 받아 형식을 바꾸고 필요한 시스템으로 전달
외부 기관과 데이터 교환기관마다 다른 형식의 데이터를 상대가 요구하는 표준 형식으로 맞춰 주고받기
AI 서비스 연결기존 시스템 데이터를 AI 서비스가 읽을 형식으로 바꿔 보내고, 결과를 다시 원래 시스템으로 돌려주기
AI 분석 파이프라인레거시 DB·API·파일 데이터를 한 형식으로 모아 모델 입력으로 넣기
