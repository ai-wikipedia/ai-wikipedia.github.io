클로드 오퍼스 5.5

Claude Opus 5.5 (Anthropic)

클로드 오퍼스 5.5는 Anthropic의 Claude 5.5 제품군에서 처음 나온 주력 모델로, 대부분의 작업에서 한 등급 위인 Fable 5.1 수준의 성능을 Opus 5보다 약 40% 낮은 비용으로 낸다. 오래 도는 코딩 에이전트나 리서치 작업의 기본 모델로 쓰면 된다.

한눈에 보기

오퍼스 5.5는 한 등급 위 모델이 하던 일을 더 싼 값에 해 주는 모델이다. 판단력이 필요한 복잡한 작업은 기본으로 오퍼스 5.5에 맡기고, 단순한 일은 아래 등급으로, 실수하면 크게 손해 보는 일은 Fable로 넘기면 된다.

모델위치이럴 때 쓴다
Fable 5.1최상위전체 설계, 보안 리뷰처럼 위험이 큰 단계
Opus 5.5주력긴 코딩 에이전트, 리서치, 전문 업무
Sonnet 5.5중간버그 수정, 문서·슬라이드 작성
Haiku 5.5경량싸게 돌리는 대량 처리

이렇게 쓴다

API나 Claude Code에서 모델 ID claude-opus-5-5를 지정하고 effort(추론 노력) 수준을 조절한다. medium으로 시작해 "쓸 만한 결과 하나당 비용"을 재 보고, effort를 높였을 때 결과가 실제로 좋아질 때만 올리는 방식이 권장된다.

작업추천 설정
대규모 리팩터링·마이그레이션의 기본 작업Opus 5.5, medium effort부터
전체 설계, 보안 리뷰Fable 5.1로 넘기기
긴 시스템 프롬프트·코드베이스 컨텍스트프롬프트 캐싱으로 묶어 두기
출처 기반 리서치 보고서Opus 5.5 (지어낸 수치·인용이 적음)

긴 작업을 맡길 때 장점은 지시를 따르면서 기존 기능을 망가뜨리지 않는다는 점이다. 글도 서론을 길게 끌지 않고 바로 본론으로 들어간다.

비용이 약 40% 줄었다

단가 자체가 내려간 데다 같은 일을 더 적은 단계로 끝내서, 실제 청구서는 단가 인하율보다 더 많이 줄어든다. 출력 속도도 Opus 5보다 빠르다.

Opus 5100
Opus 5.5약 60

고를 때 주의할 점

생물학·사이버보안 능력이 최상위 모델에 가까워서 그에 맞는 안전장치가 함께 적용된다. 이 때문에 일부 요청에서는 응답이 제한되거나 동작이 달라질 수 있다. 검증된 연구·보안 기관은 별도 인증 프로그램을 거쳐야 한다.

가장 싼 선택지도 아니다. 범위가 명확한 일상 작업은 Sonnet 5.5가 더 빠르고 싸다. 성능·비용 수치 대부분이 Anthropic 발표라는 점도 알아 두고, 실제로 맡길 작업으로 직접 재 보는 게 확실하다.
