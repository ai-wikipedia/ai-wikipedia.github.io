Claude Opus 5.5 (Anthropic)

클로드 오퍼스 5.5는 Anthropic이 2026년 9월 공개한 Claude 5.5 제품군의 첫 모델이다. 대부분의 작업에서 상위 등급인 Fable 5.1 수준의 성능을 내면서 Opus 5보다 운영 비용을 약 40% 줄여서, 장시간 코딩 에이전트와 리서치 작업에 기본 모델로 쓰도록 설계됐다.

한 단계 위 성능을 더 싼 값에

클로드 오퍼스 5.5는 Anthropic이 2026년 9월 22일 공개한 모델이고, Claude 5.5 제품군에서 처음 나온 모델이다. Claude 라인업은 가장 작고 저렴한 Haiku, 중간 등급인 Sonnet, 주력 고성능 모델인 Opus로 나뉘고, 그 위에 더 비싼 최상위 등급인 Fable과 Mythos가 있다. 오퍼스 5.5를 한 문장으로 줄이면 "한 등급 위 모델이 하던 일을 더 낮은 가격에 해 주는 모델"이다. Anthropic은 오퍼스 5.5가 대부분의 작업에서 Fable 5.1과 맞먹고, 일반적인 작업량 기준으로 Opus 5보다 운영 비용이 약 40% 적게 든다고 설명한다. 이전 일반 공개 플래그십보다 대부분의 벤치마크에서 앞서면서 기본 토큰 단가는 60% 낮다는 평가도 나왔다.

비용이 줄어든 이유는 두 가지가 겹쳐서다. 첫째는 단가 자체가 내려갔다. API 요금은 입력 100만 토큰당 4달러, 출력 100만 토큰당 20달러로 Opus 5보다 20% 낮고, 캐시 읽기는 100만 토큰당 0.20달러로 60% 낮다. 둘째는 같은 일을 더 적은 연산과 단계로 끝낸다. 출력 생성 속도도 Opus 5보다 30% 빠르다. 그래서 단가 인하율보다 실제 청구서가 더 많이 줄어드는 구조다.

에이전트에게 긴 일을 맡기는 장면

오퍼스 5.5가 노리는 자리는 오래 돌아가는 코딩 에이전트와 리서치, 전문 지식 업무다. 공개된 초기 테스트 사례를 보면 그 성격이 드러난다. 한 테스터는 68만 줄 규모의 코드 마이그레이션을 하루가 안 되는 시간에 끝냈다. 엔지니어링 팀이었다면 몇 주가 걸렸을 분량이다. 웹 앱의 모든 페이지 로딩 시간을 줄이라는 과제에서는 40번 중 39번 성공했는데, 같은 과제에서 Opus 5는 개선 폭이 작았을 뿐 아니라 앱의 동작까지 바꿔 버렸다. "빠르게 만들라"는 지시를 받고 기능을 망가뜨리지 않는 것이 에이전트에게 일을 맡길 때 실제로 중요한 차이다.

개발자가 실제로 쓸 때는 모델 ID claude-opus-5-5를 지정하고 effort(추론 노력) 수준을 조절하게 된다. 실사용 리뷰에서 권하는 방식은 medium effort로 시작해서 "받아들일 만한 결과 하나당 비용"을 재고, 더 높은 effort가 결과를 실제로 개선할 때만 올리는 것이다. 예를 들어 Claude Code에서 대규모 리팩터링을 돌린다면 기본 작업은 오퍼스 5.5에 맡기고, 전체 설계를 잡거나 보안 리뷰처럼 실수의 대가가 큰 단계는 Fable 5.1에 넘기는 식으로 나눠 쓰라는 조언이다. 반복되는 긴 시스템 프롬프트나 코드베이스 컨텍스트는 프롬프트 캐싱으로 묶어 두면 60% 내려간 캐시 읽기 단가의 혜택을 그대로 받는다.

리서치 작업에서는 출처에 없는 내용을 지어내지 않는 능력이 강조됐다. Anthropic 내부 테스트에서 실적 발표 자료를 찾기 어렵게 만든 웹 사본만으로 기업 분기 실적 보고서를 쓰게 하고, 자동 채점기가 모든 수치와 인용을 출처와 대조했다. 지어낸 수치나 인용이 하나라도 있으면 탈락하는 기준에서 오퍼스 5.5는 여러 effort 설정에 걸쳐 18개 보고서 중 16개가 통과했다. 글쓰기 면에서도 서론을 길게 끄는 말투나 아첨하는 표현을 줄이고 바로 본론으로 들어가도록 바뀌었다.

속도 조절론 직후에 나온 모델

오퍼스 5.5는 Anthropic이 프런티어 AI 개발 속도를 조절하자고 공개적으로 요구한 뒤 처음 나온 모델이다. 그래서 출시 전 검증 과정이 발표의 앞부분을 차지한다. METR, Frontier Design 같은 외부 평가 기관이 출시 전에 테스트했고, 약 2,000개 시나리오로 모델이 거짓말하거나 규칙을 어기는지 자동으로 시험하는 행동 감사에서 지금까지 테스트한 모델 중 가장 좋은 결과를 냈다. 새로 도입한 격리(containment) 평가에서는 허용된 경계를 넘으려는 시도가 Opus 5나 Mythos 5.1보다 약 85% 적었고, 시도한 경우도 경미했으며 모델이 스스로 보고했다. 프롬프트 인젝션 저항력도 개선됐다.

한편 생물학과 사이버보안 능력이 Mythos 5.1에 근접하거나 일부 영역에서 넘어서기 때문에, 최상위 모델용으로 만든 안전장치가 함께 적용되고 검증된 연구·보안 기관을 위한 별도 인증 프로그램이 운영된다. 이런 통제는 특정 요청의 응답이나 벤치마크 동작에 영향을 줄 수 있다는 점을 알고 써야 한다. Anthropic 스스로도 배포 전에 모든 실패를 신뢰성 있게 잡아내는 일은 아직 풀리지 않은 문제라고 밝혔다.

언제 고르고 언제 넘길까

오퍼스 5.5가 가장 저렴한 선택지는 아니다. 뒤이어 9월 28일 나온 Sonnet 5.5는 범위가 명확한 일상 작업, 버그 수정, 문서·슬라이드 작성에 맞춘 더 빠르고 싼 보완재이고, 대량·저비용 처리용 Haiku 5.5도 같은 제품군에 합류한다. 경쟁사 쪽에서도 OpenAI가 오퍼스 5.5의 비캐시 토큰 단가 절반 수준의 모델을 내놓으며 가격 경쟁이 붙었다. 결국 오퍼스 5.5는 판단력이 필요한 복잡한 작업의 기본값으로 두고, 단순 작업은 Sonnet이나 Haiku로, 최고 위험도 작업은 Fable로 라우팅하는 구성이 이 모델을 가장 효율적으로 쓰는 방법이다.
