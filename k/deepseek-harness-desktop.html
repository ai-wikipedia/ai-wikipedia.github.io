딥시크 하네스 데스크톱

DeepSeek Harness Desktop

딥시크의 오픈소스 에이전트 하네스(DSH)를 macOS·Windows용 설치형 앱으로 만든 것이다. 터미널이나 Node.js 없이 내 컴퓨터의 작업 폴더를 AI 에이전트에게 맡기고 싶을 때 쓴다.

한눈에 보기

딥시크 하네스 데스크톱은 딥시크의 오픈소스 에이전트 하네스(DSH)를 설치형 앱으로 묶은 것이다. 무엇을 할지는 모델이 정하고, 파일 읽기·코드 수정·명령 실행·결과 확인은 하네스가 맡는다. 터미널 없이 내 컴퓨터의 작업 폴더를 에이전트에게 맡기고 싶을 때 쓴다.

환경실행 방법준비물
macOS (Apple Silicon, 13 이상)데스크톱 앱설치 파일만
Windows 64비트데스크톱 앱설치 파일만
Linux브라우저 웹 UINode.js 22.19 이상 또는 24 이상

설치 파일에 런타임이 들어 있다

웹 UI로 쓰려면 Node.js를 먼저 깔아야 하지만, 데스크톱 앱은 자체 런타임을 품고 있어서 따로 설치할 게 없다. 딥시크 다운로드 페이지에서 운영체제에 맞는 파일을 받아 실행하면 끝이다. Windows 설치 파일은 약 276MB이고, 관리자 권한 없이 설치된다.

Linux나 원격 서버에서는 작업 폴더에서 npx @deepseek-ai/dsh web을 실행한다. 브라우저에 로컬 화면(포트 3080)이 열리고, 쓰는 흐름은 앱과 같다.

모델 연결은 세 가지 중 고른다

첫 화면에서 로그인이나 API 키를 바로 넣어도 되고, 'Set up later'로 건너뛰었다가 나중에 정해도 된다. 계정 로그인과 API 키는 비용이 서로 다른 잔액에서 빠지므로, 작업을 돌리기 전에 지금 어느 쪽이 켜져 있는지 확인하는 게 좋다.

연결 방식이럴 때비용
딥시크 계정 로그인가장 빨리 시작하고 싶을 때계정 잔액
API 키사용량을 API로 따로 관리할 때API 크레딧
Ollama 로컬 모델키 없이 무료로 쓰고 싶을 때무료 (속도는 내 PC 성능 따라)

Ollama를 붙일 때는 Custom model API에서 OpenAI Chat Completions 형식을 고르고, 주소는 /v1로 끝나게 넣는다. 모델 목록을 불러온 뒤 컨텍스트 길이를 Ollama 쪽 설정과 맞춰 준다.

아직 미리보기라 격리해서 쓴다

하네스 자체가 개발자 미리보기라 호환성이 깨지는 변경이 잦고, 앱 화면도 버전마다 바뀐다. 보안 감사를 거치지 않았는데 모델이 만든 명령을 실제로 실행하므로, 공식 안전 안내는 최소 권한, 일회용 가상머신·컨테이너 같은 전용 환경, 접근 가능한 파일의 백업을 권한다. 버전을 올리기 전에는 프로필·플러그인·세션도 따로 복사해 두는 게 안전하다.

이름이 비슷한 커뮤니티 제작 데스크톱 앱도 따로 돌고 있다. 공식 앱은 딥시크 홈페이지의 Harness Desktop 메뉴에서 받는다.
