화수 모션

Huashu Motion (Coding-Agent Product Film Director)

Claude Code나 Codex 같은 코딩 에이전트가 제품 런치 영상을 코드로 만들게 해 주는 오픈소스 에이전트 스킬이다. 제품 사이트나 데이터만 주고 30초 남짓한 소개 영상을 뽑고, 화면을 클릭해 고칠 부분만 짚어서 수정하고 싶을 때 쓴다.

단계에이전트가 하는 일
입력제품 사이트, CSV 데이터, 화면 녹화 중 하나를 받는다
기획연출 방향 3가지를 제안하고, 장면별 타이밍을 적은 리듬 시트를 쓴다
제작GSAP 애니메이션이 담긴 index.html 한 장과 효과음을 만든다. 런치 필름이면 ABC 악보 형식으로 음악까지 쓴다
수정로컬 스튜디오에서 짚은 부분만 고치고, 모든 버전을 남긴다

영상 편집기 대신 코드 한 장

타임라인을 손으로 끌어 맞추거나 AI 영상 생성 모델에 맡기지 않는다. 에이전트가 웹 애니메이션 코드를 직접 짜서 영상 전체가 HTML 파일 하나로 남는다. 그래서 에이전트가 결과물을 읽고 고치기 쉽고, 버전마다 코드로 남아 비교와 되돌리기가 편하다.

클릭해서 고칠 곳을 짚는다

코드로 만든 영상은 말로만 수정을 요청하면 어디를 고치라는지 전달하기 어렵다. 이 스킬은 로컬 브라우저 스튜디오를 열어 준다. 영상의 특정 프레임을 클릭해 의견을 남기면 시간, 장면, 요소 정보가 함께 담긴 코멘트가 inbox 파일로 들어간다. 에이전트는 그 파일을 읽고 해당 부분만 고치며, 이전 버전은 지우지 않는다.

설치는 npm, 실행은 에이전트 안에서

에이전트 스킬, CLI, 브라우저 스튜디오 세 부분으로 되어 있다. npm install huashu-motion으로 설치한 뒤 Claude Code나 Codex에서 "이 제품으로 런치 영상 만들어 줘"처럼 요청하면 된다. 결과물은 코드로 그린 모션 그래픽이라, 실사 촬영이나 사람이 나오는 영상이 필요하면 다른 도구를 써야 한다.

같은 제작자의 스킬주로 만드는 것
huashu-designHTML 프로토타입, 슬라이드, 인포그래픽
huashu-art-motion35가지 화풍으로 코드가 그리고 움직이는 그림 영상
huashu-motion제품 런치·소개 영상

사람들은 주로 이렇게 쓴다

가장 흔한 건 제품 출시용 짧은 영상을 개발자가 직접 뽑는 방식이다. 방향 3개 중 하나를 고르고, 스튜디오에서 마음에 안 드는 장면만 클릭해 다듬는다.

어디서어떻게 쓰나
제품 출시제품 사이트 주소를 주고 30초 런치 필름과 배경음악까지 한 번에 만든다
데이터 소개CSV를 넘겨 수치가 움직이는 설명 영상으로 만든다
기능 데모화면 녹화를 넣어 리듬 있는 소개 영상으로 다시 편집한다
