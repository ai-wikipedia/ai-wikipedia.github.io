GLM 5.2 (Z.ai)

GLM 5.2는 Z.ai(옛 Zhipu AI)가 만든 오픈 웨이트 코딩 모델로, 몇 시간씩 이어지는 긴 작업을 끝까지 해내도록 만들어졌다. 코드베이스 전체 분석이나 여러 단계에 걸친 대규모 리팩토링처럼 오래 붙들고 있어야 하는 작업에 쓴다.

한눈에 보기

GLM 5.2는 Z.ai가 공개한 오픈 웨이트 코딩 모델이다. 질문 하나에 답하는 것보다 수십 개 파일을 읽고 고치고 테스트를 돌리는 긴 작업을 흐트러지지 않고 끝내는 데 맞춰져 있다. 가중치는 MIT 라이선스라 상업적으로도 자유롭게 쓸 수 있다.

긴 코딩 작업에 맡긴다

Z.ai가 꼽는 쓰임새는 프로젝트 전체 코드베이스 분석, 여러 단계에 걸친 대규모 리팩토링, 팀의 코딩 규칙을 지키며 작업하기, 논문 재현이다. 정답 한 번보다 많은 파일과 규칙을 오래 기억해야 하는 일들이다. 긴 문맥에서도 연산량을 줄이는 구조를 넣어, 100만 토큰을 다 쓰는 작업에서도 부담이 덜하다.

API는 OpenAI 방식 그대로

모델 ID glm-5.2와 OpenAI 호환 주소 https://api.z.ai/api/paas/v4/를 지정하면 기존 OpenAI SDK 코드를 그대로 쓸 수 있다. 작업에 따라 추론 설정만 바꾸면 된다.

Z.ai API 기준, 100만 토큰당 가격.

Claude Code에 붙이려면 모델명을 직접 적는다

~/.claude/settings.json의 env 항목에 ANTHROPIC_BASE_URL을 https://api.z.ai/api/anthropic으로, ANTHROPIC_AUTH_TOKEN을 Z.ai 키로 넣는다. 그다음 ANTHROPIC_DEFAULT_OPUS_MODEL 같은 모델 매핑 변수에 쓸 GLM 모델명을 적는다. 공식 가이드의 기본 설정은 이제 후속 모델을 가리키므로, 5.2를 계속 쓰려면 모델명을 직접 지정해야 한다.

이미지 입력 불가, 직접 서빙은 무겁다

이미지를 넣을 수 없어서 화면 캡처를 보고 UI를 고치는 작업에는 맞지 않는다. 직접 서빙은 vLLM 0.23.0 이상이나 SGLang에서 되고 FP8 가중치도 있지만, 그래도 고성능 GPU가 여러 장 필요하다. 개인 개발자라면 API나 추론 서비스로 쓰는 게 현실적이다. Z.ai가 같은 가격의 후속 모델 GLM-5.3을 내놓았으니, 새 프로젝트라면 내 작업으로 둘을 비교해 보고 고르는 게 좋다.
