GitHub Copilot

GitHub이 만든 AI 코딩 도구로, 입력하는 동안 다음 코드를 미리 제안하는 자동완성에서 출발해 지금은 한 구독으로 채팅과 에이전트까지 쓸 수 있다. 쓰던 편집기와 GitHub 저장소를 그대로 두고 AI 도움을 받고 싶을 때 고르면 된다.

기능어디서이럴 때 쓴다
코드 자동완성편집기함수 본문, 반복 코드 채우기
Copilot Chat편집기, github.com코드 설명, 오류 원인 묻기
에이전트 모드편집기여러 파일 수정, 명령 실행
코딩 에이전트GitHub 이슈·PR이슈를 맡기고 PR로 받기

주석 한 줄이 함수가 된다

VS Code, JetBrains, Vim 같은 편집기에 확장을 설치하고 GitHub 계정으로 로그인하면 바로 동작한다. 코드를 입력하는 중에 회색 글씨로 제안이 뜨는데, Tab을 누르면 받아들이고 Esc를 누르면 무시한다.

함수 이름과 주석만 써 두면 본문 전체를 제안하고, 테스트 케이스를 하나 쓰면 나머지도 비슷한 형태로 채운다. // TODO: validate email format처럼 주석을 구체적으로 쓸수록 제안도 정확해진다. 관련 파일을 편집기에 함께 열어 두면 맥락을 더 잘 잡는다.

작은 질문은 채팅, 큰 일은 에이전트

코드를 선택한 뒤 채팅에서 "이 함수는 무슨 일을 하나", "이 에러는 왜 나나"처럼 물으면 선택한 코드를 기준으로 답한다. 한두 줄만 고치면 되는 일은 채팅이나 자동완성으로 충분하다.

여러 파일을 고쳐야 하면 에이전트 모드에서 목표를 말한다. 에이전트가 파일을 수정하고 터미널 명령을 실행한 뒤, 결과를 보고 다시 고친다. 직접 지켜보지 않아도 되는 일은 이슈를 Copilot에게 할당하면 된다. 그러면 코딩 에이전트가 클라우드 환경에서 작업해 PR을 올리고, 사람은 리뷰만 하면 된다. 예전에 미리보기로 나왔던 Copilot Workspace가 하던 역할을 지금은 이 흐름이 맡고 있다.

무료로 시작하고, 팀은 관리 기능을 쓴다

요금제대상특징
Free개인 체험월 사용량 제한
Pro·Pro+개인 개발자사용량이 더 많고 고를 수 있는 모델이 많음
Business·Enterprise회사·조직정책 관리, 파일 제외 설정

세부 한도와 가격은 자주 바뀌므로 GitHub 요금 안내에서 확인한다.

채팅과 에이전트에서는 OpenAI, Anthropic, Google 등 여러 회사의 모델 가운데 골라 쓸 수 있다. 가벼운 질문은 빠른 모델로, 어려운 설계 작업은 성능이 높은 모델로 나누면 사용량을 아낄 수 있다.

제안은 검토한 뒤 받는다

그럴듯해 보여도 틀린 코드, 오래된 API, 보안에 약한 코드를 제안할 수 있다. 받은 코드는 반드시 테스트와 리뷰를 거친다. 공개 코드와 똑같은 제안을 막는 설정이 있으니 라이선스가 걱정되면 켜 둔다. 조직에서는 비밀 정보가 담긴 파일을 Copilot이 읽지 못하도록 제외할 수 있다.

평소엔 자동완성, 귀찮은 일은 이슈로 맡긴다

가장 흔한 건 편집기에 켜 두고 반복 코드를 Tab으로 채우는 방식이다. 막히면 채팅에 묻고, 지켜볼 필요 없는 작은 작업은 이슈로 맡겨 PR로 받는다.

어디서어떻게 쓰나
편집기에서 코드 작성함수 본문, 테스트 케이스, 반복되는 코드를 자동완성으로 채우기
낯선 코드 읽기·디버깅코드를 선택하고 채팅에 동작이나 에러 원인을 묻기
여러 파일에 걸친 수정에이전트 모드에 목표를 말하고 수정·명령 실행 결과를 확인
GitHub 이슈 처리작은 버그 수정, 문서 손보기 같은 이슈를 Copilot에 할당하고 올라온 PR을 리뷰
