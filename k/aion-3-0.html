에이온 3.0

Aion-3.0 (AionLabs)

AionLabs가 만든 롤플레이·스토리텔링 전용 언어 모델로, GLM 기반의 여러 전문 모델이 한 응답을 함께 만든다. 캐릭터 대화, 인터랙티브 픽션, 소설 협업처럼 이야기가 중요한 작업에 쓰고, 코딩이나 분석은 범용 모델에 맡기는 게 낫다.

항목내용
기반GLM 패밀리
컨텍스트 / 최대 출력131,072 / 33,000 토큰
가격 (입력/출력)$3 / $6
접근OpenRouter 등 API

가격은 100만 토큰당 기준이다.

여러 모델이 이야기를 나눠 맡는다

서사 구조, 갈등, 긴장감 같은 요소를 모델마다 하나씩 맡고, 그 결과를 합쳐 최종 답을 만든다. 모델 하나가 모든 요소를 챙길 때보다 이야기를 더 풍부하게 만들려는 설계다. 대신 여러 모델을 거치기 때문에 단일 모델보다 응답이 늦을 수 있다.

기존 앱에는 주소만 바꿔 붙인다

OpenAI 호환 API를 제공하므로 GPT용으로 만든 앱에서 엔드포인트, API 키, 모델 이름만 바꾸면 된다. OpenRouter에서는 API 키를 발급받고 base URL을 OpenRouter로 바꾼 뒤 모델 ID를 aion-labs/aion-3.0으로 지정하면 된다.

롤플레이는 시스템 프롬프트에 캐릭터 설정, 세계관, 말투를 적어 두고 대화 기록을 계속 넘겨 주는 방식이 기본이다. 컨텍스트가 13만 토큰 정도라 긴 세션도 꽤 담을 수 있다. 그래도 대화가 아주 길어지면 앞부분을 요약해 넣어 주는 게 안전하다.

이야기 작업에는 쓰고, 다른 작업에는 쓰지 않는다

코딩, 데이터 분석범용 모델

Mini도 같은 협업 생성 구조로 나와 있어서, 품질과 부담을 비교해 보고 고르면 된다.

붙이기 전에 확인할 점

성인 테마나 복잡한 도덕적 갈등처럼 일반 모델이 피하는 소재도 다루도록 설계됐다. 그래서 서비스에 붙인다면 이용 약관과 사용자 연령 정책은 직접 챙겨야 한다. 출력 단가가 입력의 두 배여서 긴 답을 자주 받는 롤플레이라면 최대 출력 길이를 정해 두는 게 비용 관리에 좋다.

주로 이야기를 이어 가는 대화형 창작에 쓴다

가장 흔한 쓰임은 캐릭터와 오래 대화하는 롤플레이다. 보통 OpenRouter 같은 API로 불러 기존 채팅 앱이나 게임에 붙이고, 사람이 방향을 잡으면 모델이 장면과 대사를 채운다.
