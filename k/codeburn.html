Codeburn

Claude Code나 Codex 같은 AI 코딩 도구가 토큰을 어디에 얼마나 썼는지 터미널 대시보드로 한눈에 보여주는 오픈소스 도구.

토큰이 어디로 새는지 보여주는 계량기

AI 코딩 도구를 쓰다 보면 한 달 구독 한도가 금방 차는데, 정작 무엇에 썼는지는 잘 보이지 않는다. 고친 코드는 몇 줄 안 되는 것 같은데 토큰은 수백만 개가 나갔다. CodeBurn은 이 답답함을 풀어주는 오픈소스 도구로, AI 코딩 도구가 쓴 토큰과 비용을 모델별, 프로젝트별, 작업 종류별로 쪼개서 보여준다. 전기 계량기가 어떤 가전이 전기를 잡아먹는지 알려주듯, 코딩 세션의 어느 부분이 돈을 태우는지 알려주는 셈이다. MIT 라이선스로 공개돼 있다.

핵심은 로컬에서만 동작한다는 점이다. 계정도 API 키도 프록시도 필요 없고, 각 도구가 이미 디스크에 남기는 세션 기록을 읽는다. 예를 들어 Claude Code는 ~/.claude/projects/ 아래 세션별 JSONL 파일에 호출마다 모델명과 입력·출력·캐시 토큰 수를 기록하는데, CodeBurn은 이걸 모아 계산한다. Codex, Cursor, Gemini CLI, GitHub Copilot, OpenCode, Zed 등 지원 도구가 수십 개로 늘어서, 여러 도구를 섞어 쓰는 사람도 한 화면에서 합계를 볼 수 있다. 가격은 LiteLLM의 모델 가격표를 받아 24시간 캐시해 쓴다.

13가지 작업 분류와 원샷 비율

흥미로운 기능은 대화 턴마다 작업 종류를 붙이는 분류다. 코딩, 디버깅, 기능 개발, 리팩토링, 테스트, 탐색, 계획, 위임, Git 작업, 빌드·배포, 브레인스토밍, 대화, 기타의 13가지로 나누는데, 별도 LLM을 부르지 않고 규칙으로 정한다. Edit이나 Write 도구를 썼으면 코딩, 수정 없이 Read와 Grep만 했으면 탐색, 에러나 수정 관련 단어와 도구 사용이 함께 나오면 디버깅으로 보는 식이다. 그래서 같은 데이터는 언제 돌려도 같은 결과가 나온다.

또 하나 유용한 지표는 원샷 비율이다. 같은 파일을 수정하고, 셸 명령을 돌린 뒤, 다시 같은 파일을 고치면 재시도로 센다. 수정 턴 가운데 재시도 없이 끝난 비율이 원샷 비율이라, 이 값이 낮으면 에이전트가 고치고 테스트하고 또 고치는 루프에 빠져 토큰을 낭비하고 있다는 신호다.

설치와 기본 사용법

설치 없이 npx codeburn을 실행하면 터미널 대시보드가 뜨고, 화살표 키로 기간을 바꾸고 p로 도구를 전환한다. 계속 쓸 거라면 npm install -g codeburn이나 Homebrew로 설치하면 되고 Node.js 22.13 이상이 필요하다. codeburn context는 한 세션의 컨텍스트 창을 무엇이 채웠는지 분해해 준다. codeburn yield는 지출을 Git 커밋과 연결해 실제 결과물 대비 비용을 보여준다. Claude Code 사용자라면 codeburn guard install로 지출 훅을 걸어 기본값 기준 5달러에서 경고하고 15달러에서 멈추게 할 수도 있다.

codeburn optimize가 찾아내는 낭비는 구체적이다. 매 턴 다시 읽히는 파일, 설치만 해 두고 한 번도 부르지 않은 MCP 서버, 너무 길어져서 모든 요청에 실려 가는 CLAUDE.md 같은 것들이다. 쓰지 않는 MCP 서버도 도구 설명이 매번 프롬프트에 실리므로 턴마다 토큰을 먹는데, --apply를 붙이면 이런 항목을 설정에서 정리해 준다. codeburn compare는 내 사용 기록 위에서 두 모델을 나란히 놓고 원샷 비율, 편집당 비용, 캐시 적중률을 비교해, 비싼 모델이 정말 그 값을 하는지 보여준다.

에이전트와 엮어 쓸 수도 있다. claude mcp add codeburn -- npx -y codeburn mcp로 로컬 MCP 서버를 등록하면 에이전트가 대화 중에 '이번 주 토큰이 어디로 갔지' 같은 질문에 직접 답한다. CLI는 어떤 데이터도 외부로 보내지 않는다.

대시보드를 읽는 요령

숫자를 보는 것만으로는 부족하고 패턴을 읽어야 한다. 프로젝트 문서가 꼽는 대표 신호는 이렇다. 캐시 적중률이 80% 아래에 계속 머물면 시스템 프롬프트나 컨텍스트가 매번 바뀌고 있다는 뜻이다. 같은 파일을 반복해서 읽으면 에이전트가 맥락을 놓치고 있는 것이고, 대화 범주 비중이 크면 일을 하기보다 말을 하고 있는 것이다. 작은 턴에서 Opus급 모델이 비용을 독차지한다면 단순 작업에 과한 모델을 쓰고 있다는 신호다.

한계도 알고 써야 한다. 구독 요금제 사용자의 금액은 실제 청구서가 아니라 API 요금으로 환산한 추정치다. Cursor처럼 토큰 수를 남기지 않는 도구는 텍스트 길이로 추정하고, 가격표에 없는 모델은 추측하지 않아 합계에서 빠질 수 있다. Claude Code는 30일이 지난 세션을 지우므로 오래된 기간은 세션 단위 상세가 줄어든다. 각 도구의 로그 형식에 기대는 구조라, 도구가 형식을 바꾸면 CodeBurn도 업데이트를 기다려야 한다.
