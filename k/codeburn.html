Codeburn

CodeBurn은 Claude Code, Codex 같은 AI 코딩 도구가 토큰과 비용을 어디에 썼는지 터미널 대시보드로 보여주는 오픈소스 도구다. 구독 한도가 너무 빨리 차거나, 어떤 작업에서 토큰이 새는지 알고 싶을 때 쓴다.

한눈에 보기

CodeBurn은 AI 코딩 도구용 토큰 계량기다. 코드는 몇 줄 안 고친 것 같은데 토큰이 많이 나갔을 때, 어느 모델·프로젝트·작업에서 돈이 나갔는지 쪼개서 보여준다. 각 도구가 이미 디스크에 남기는 세션 기록을 읽기만 해서, 계정이나 API 키 없이 내 컴퓨터 안에서만 돌아간다.

항목내용
지원 도구Claude Code, Codex, Cursor, Gemini CLI 등 수십 개
나눠 보는 기준모델별, 프로젝트별, 작업 종류별
데이터 전송외부로 보내지 않음
라이선스MIT 오픈소스

npx 한 줄로 바로 본다

설치 없이 npx codeburn을 실행하면 대시보드가 뜬다. 화살표 키로 기간을, p로 도구를 바꾼다. 계속 쓸 거라면 npm install -g codeburn이나 Homebrew로 설치하면 되고, Node.js 22.13 이상이 필요하다.

명령어이럴 때 쓴다
codeburn optimize매 턴 다시 읽는 파일, 안 쓰는 MCP 서버, 너무 긴 CLAUDE.md 찾기 (--apply로 정리)
codeburn compare비싼 모델이 내 작업에서 정말 값을 하는지 비교
codeburn context한 세션의 컨텍스트 창을 무엇이 채웠는지 확인
codeburn yield지출을 Git 커밋과 연결해 결과물 대비 비용 확인
codeburn guard installClaude Code에서 기본 5달러 경고, 15달러 중단

에이전트가 직접 묻게 할 수도 있다. claude mcp add codeburn -- npx -y codeburn mcp로 등록하면 대화 중에 "이번 주 토큰이 어디로 갔지?"에 바로 답한다.

원샷 비율이 낮으면 헛도는 중

CodeBurn은 대화 턴마다 코딩, 디버깅, 탐색, 대화 같은 작업 종류를 붙인다. 별도 AI가 아니라 규칙으로 나눠서 언제 돌려도 결과가 같다. 함께 보여주는 원샷 비율은 파일을 한 번에 고치고 끝낸 비율로, 낮으면 에이전트가 고치고 테스트하고 또 고치는 루프에 빠져 토큰을 낭비하고 있다는 뜻이다.

이런 패턴이 보이면의미
캐시 적중률이 계속 80% 아래시스템 프롬프트나 컨텍스트가 매번 바뀐다
같은 파일을 반복해서 읽음에이전트가 맥락을 놓치고 있다
대화 범주 비중이 큼일보다 말을 많이 하고 있다
작은 턴에서 Opus급 비용이 큼단순 작업에 과한 모델을 쓰고 있다

금액은 추정치다

구독 요금제라면 화면의 금액은 실제 청구서가 아니라 API 요금으로 환산한 값이다. Cursor처럼 토큰 수를 남기지 않는 도구는 텍스트 길이로 추정하고, 가격표에 없는 모델은 합계에서 빠질 수 있다. Claude Code는 30일 지난 세션을 지우므로 오래된 기간은 상세가 줄고, 도구가 로그 형식을 바꾸면 CodeBurn 업데이트를 기다려야 한다.
