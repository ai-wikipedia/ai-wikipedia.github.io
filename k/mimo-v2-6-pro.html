미모 V2.6 프로

Xiaomi MiMo V2.6 Pro

미모 V2.6 프로는 샤오미가 MIT 라이선스로 공개한 오픈 웨이트 플래그십 추론 모델이다. 100만 토큰 문맥과 이미지·오디오·비디오 입력을 지원하며, 코딩 에이전트나 오래 걸리는 작업을 싼 토큰 가격으로 돌리고 싶을 때 쓴다.

한눈에 보기

MiMo V2.6 Pro는 샤오미가 2026년 9월에 공개한 V2.6 시리즈의 기준 모델이다. 공개 직후 오픈 웨이트 모델 가운데 가장 높은 평가를 받았다. 덩치는 크지만 질문마다 일부만 계산하는 구조라 비용이 낮다. 복잡한 프로젝트, 오래 걸리는 에이전트 작업, 사이버보안, 연구용으로 설계됐다. 시리즈는 세 등급이고 작업 성격에 맞춰 고르면 된다.

등급특징이럴 때 쓴다가격 (입력/출력)
Flash속도·비용 우선단순한 대량 작업$0.14 / $0.28
Pro기준 모델코딩 에이전트, 긴 작업$0.435 / $0.87
Pro-UltraSpeedPro와 같은 품질, 출력이 훨씬 빠름응답 지연이 중요한 대화형 UI$4.35 / $8.70

100만 토큰당 가격. 컨텍스트는 약 105만 토큰이고 입력은 텍스트·이미지·오디오·비디오, 출력은 텍스트다.

모델 ID만 바꾸면 바로 붙는다

샤오미 공식 API나 OpenRouter로 쓴다. OpenAI 호환 형식이라서 기존 클라이언트에서 모델 ID만 mimo-v2.6-pro로 바꾸면 된다. 가중치는 공개돼 있지만 규모가 너무 커서 개인 장비로 돌리기는 어렵다. 그래서 실제로는 API로 쓰는 경우가 대부분이다.

추론(thinking)은 기본으로 켜져 있다. 코딩 에이전트에 붙여 프론트엔드 생성이나 긴 리팩토링을 맡길 때는 켠 채로 두면 된다. 간단한 질문에는 요청에 {"thinking": {"type": "disabled"}}를 넣어 끄면 더 빠르고 싸다.

반복해서 보내는 맥락은 거의 공짜

같은 시스템 프롬프트와 코드베이스를 매번 다시 보내는 에이전트 작업에서 이득이 크다. 이미 보낸 입력이 캐시에 남아 있으면 일반 입력보다 훨씬 싸게 청구된다.

일반 입력$0.435
캐시 입력$0.0036

Pro 기준, 입력 100만 토큰당 가격.

점수만 믿지 말고 직접 돌려 볼 것

벤치마크에 지나치게 맞춰진 것 아니냐는 비판이 나왔다. 일부 과제에서는 Flash가 Pro보다 더 안정적이었다. 어떤 에이전트 도구(하네스)에 붙이느냐에 따라 체감 성능도 꽤 달라진다.

생각을 길게 하는 편이라 토큰 단가가 싸도 작업 하나에 드는 총비용은 커질 수 있다. 내 저장소와 내가 쓰는 도구에서 Pro와 Flash를 나란히 돌려 보고, 성공률과 비용을 비교해 고르는 게 가장 안전하다.
