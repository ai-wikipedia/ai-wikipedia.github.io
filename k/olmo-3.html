OLMo 3 (AllenAI)

OLMo 3는 비영리 연구소 AllenAI(Ai2)가 만든 언어 모델로, 가중치뿐 아니라 학습 데이터·코드·중간 체크포인트까지 모두 공개한다. 모델 내부를 들여다보며 연구하거나, 투명한 오픈 모델을 로컬에서 직접 돌리고 싶을 때 쓴다.

한눈에 보기

OLMo 3는 AllenAI가 2025년 11월에 공개한 완전 공개 언어 모델이다. 7B와 32B 두 크기가 있고, 크기마다 용도가 다른 세 가지 변형이 있다. 상업적으로도 자유롭게 쓸 수 있는 Apache 2.0 라이선스다.

변형성격이럴 때 쓴다
Base기본 모델직접 미세조정하거나 연구할 때
Instruct대화·지시 수행일반 챗봇, 빠른 응답, 에이전트
Think단계적으로 생각복잡한 수학·논리 문제

가중치만이 아니라 만드는 과정까지 공개

보통 '오픈' 모델은 가중치 파일만 받을 수 있다. OLMo 3는 학습 데이터 Dolma 3, 학습·평가 코드, 사전학습부터 미세조정까지의 중간 체크포인트를 모두 공개한다. 그래서 자원만 있으면 누구나 처음부터 똑같이 다시 만들 수 있다.

모델이 왜 그렇게 답하는지를 데이터와 학습 방법까지 거슬러 올라가 확인할 수 있다는 게 가장 큰 가치다.

한 줄로 로컬에서 바로 실행

가장 쉬운 방법은 ollama run olmo-3:7b-instruct다. 7B는 RAM 6GB 정도면 돌아가서 노트북에서도 무리가 없고, gguf·mlx 포맷도 있어 LM Studio 같은 데스크톱 앱에 그대로 올릴 수 있다.

서버로 띄울 때는 vLLM이나 SGLang을 쓰고, 코드에서는 허깅페이스 Transformers로 allenai/Olmo-3.1-32B-Instruct를 불러온다. 도구 사용과 멀티턴 대화를 지원하므로 외부 API를 호출하는 에이전트에도 붙일 수 있다. 32B는 출시 뒤 추가 학습을 거쳐 Olmo 3.1 32B로 업데이트됐고, 수학과 지시 따르기가 더 좋아졌다.

최고 성능보다 투명성이 강점

32B Base는 같은 시기 비슷한 크기의 다른 오픈 모델과 겨룰 만하다. 다만 코딩 같은 일부 영역에서는 비슷한 크기의 Qwen 3 계열보다 떨어진다. 성능이 가장 중요하다면 다른 모델과 직접 비교해 보고, 투명성과 재현성이 중요할 때 고르는 것이 맞다.
