구스

Goose (Block AI Agent)

구스(Goose)는 Block이 만든 오픈소스 AI 에이전트로, 내 컴퓨터에서 돌아가며 원하는 LLM을 연결해 코드 수정부터 테스트, 에러 수정까지 직접 실행한다. 특정 모델에 묶이지 않는 로컬 코딩 에이전트가 필요할 때 쓴다.

한눈에 보기

구스(Goose)는 Block(구 Square)이 만든 오픈소스 AI 에이전트다. 대부분의 AI 코딩 도구는 코드를 제안하는 데서 멈추지만, Goose는 셸 명령을 돌리고 파일을 고치고 테스트를 실행하며, 에러가 나면 스스로 고친다. 특정 LLM에 묶이지 않고 내 컴퓨터에서 직접 돌아가는 코딩 에이전트가 필요할 때 쓴다.

특징의미
직접 실행셸·파일·테스트를 스스로 다룬다
완전 오픈소스Apache 2.0 라이선스
로컬 실행내 머신에서 돌아간다
LLM 선택 자유원하는 모델을 연결한다

터미널은 goose session, 아니면 데스크톱 앱

프로젝트 디렉토리에서 goose session을 실행하면 대화형 세션이 열린다. Goose가 먼저 폴더의 파일 구조를 파악하므로, "이 함수 리팩토링해줘"라고 말하면 코드를 읽고 고친 뒤 테스트까지 돌린다.

터미널이 익숙하지 않다면 데스크톱 앱을 쓰면 된다. 작동 방식은 단순한 반복이다. 요청을 받으면 에이전트가 LLM에 묻고, LLM이 도구 호출을 돌려주면 해당 확장이 실행되며, 일이 끝날 때까지 이 과정이 이어진다.

MCP를 붙일수록 할 수 있는 일이 늘어난다

확장 기능은 MCP 기반이라 GitHub, Slack, Docker, Kubernetes 등 수천 개의 MCP 서버에 연결할 수 있다. 하려는 작업에 맞는 서버만 골라 붙이면 된다.

연결 대상할 수 있는 일
GitHub MCP이슈 읽기, PR 만들기
Docker MCP컨테이너 관리
Ollama 같은 로컬 LLM클라우드 없이 완전 로컬로 실행

재단이 관리하는 공개 프로젝트

Block의 오픈소스 프로그램 오피스가 2025년 1월에 공개했다. 2025년 12월에는 Anthropic의 MCP, OpenAI의 AGENTS.md와 함께 Linux Foundation 산하 Agentic AI Foundation에 기부됐다. 한 회사의 도구가 아니라 에이전트 생태계의 공용 기반으로 다뤄진다는 뜻이다.

프롬프트 인젝션은 꼭 조심

명령을 직접 실행하는 에이전트라서, 읽어 들인 내용에 숨은 지시가 있으면 그대로 따를 위험이 있다. 실제로 Block 보안팀은 눈에 보이지 않는 유니코드 문자에 숨긴 프롬프트 인젝션으로 침해에 성공한 레드팀 결과를 공개했다. 출처를 모르는 파일이나 이슈를 읽게 할 때는 특히 조심해야 한다.
