Claude Opus 4.8 (Anthropic)

Anthropic이 2026년 5월 내놓은 Claude 최상위 모델이다. 어려운 코딩과 오래 도는 에이전트 작업에 쓰고, 자기 작업 결과를 더 솔직하게 보고한다.

한눈에 보기

Claude Opus 4.8은 Anthropic이 일반에 공개한 Claude 모델 가운데 가장 강력한 모델이다. 어려운 코딩, 오래 혼자 도는 에이전트 작업, 길고 빽빽한 문서 분석처럼 품질이 가장 중요한 일에 쓴다. 간단하고 양이 많은 일은 더 가벼운 Claude 모델에 맡기는 편이 낫다.

등급이럴 때 쓴다
Opus (4.8)어려운 디버깅, 큰 작업 설계, 장시간 에이전트
Sonnet일상 코딩, 문서 작업
Haiku분류·추출 같은 단순 대량 작업

같은 가격에 더 정직해졌다

2026년 4월 나온 Opus 4.7 이후 41일 만인 5월 28일에 공개됐다. Anthropic 역사상 가장 빠른 버전 교체였고, 가격은 4.7과 같다. 가장 큰 변화는 자기가 짠 코드의 결함을 그냥 넘기는 일이 크게 줄었다는 점이다.

항목Opus 4.7Opus 4.8

"처음엔 똑똑하다가 점점 무너진다"는 불만에 맞춰, 오래 굴려도 흔들리지 않고 한 번에 일을 끝내는 안정성을 목표로 했다.

API·Claude Code·Bedrock에서 바로 쓴다

Claude API에서는 모델 ID claude-opus-4-8로 부르고, Claude Code에서는 기본 모델로 쓸 수 있다. AWS Bedrock 같은 클라우드에서도 제공된다.

알아둘 설정이 두 가지다. 생각하는 강도를 정하는 effort의 기본값이 모든 환경에서 high로 바뀌었다. 또 추론은 적응형 사고(adaptive thinking)만 지원해서, 모델이 깊게 생각할 필요가 있다고 판단한 턴에서만 추론이 켜진다.

큰 일은 Opus가 지휘, 잔일은 Haiku

다이나믹 워크플로우(Dynamic Workflows)와 함께 쓰면 Opus 4.8이 직접 작업 틀(하네스)을 만들고, 한 번 실행에 최대 1,000개의 하위 에이전트를 지휘할 수 있다. 비싼 Opus는 전체 계획과 판단만 맡고 단순 반복은 저렴한 Haiku에 나눠 주면 비용을 줄일 수 있다. 재무 문서처럼 긴 자료를 다룰 때는 출처 인용이 더 정확해지고 검색에 쓰는 토큰도 줄었다.

비용과 기존 코드는 확인하자

기본 강도가 high라서 따로 정하지 않으면 시간과 토큰을 더 쓸 수 있다. 테스트 결과 요약처럼 단순한 단계는 강도를 낮춰 두는 게 좋다. 이전 모델에서 추론 설정을 직접 지정하던 코드는 적응형 사고 방식에 맞는지 먼저 확인해야 한다. 성능 개선 내용은 Anthropic 발표 기준이므로, 내 작업으로 직접 비교해 보는 게 가장 확실하다.
