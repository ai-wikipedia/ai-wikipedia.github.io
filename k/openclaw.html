오픈클로

OpenClaw

오픈클로는 내 컴퓨터에서 돌아가는 오픈소스 AI 비서다. 텔레그램이나 왓츠앱 같은 메신저로 메시지를 보내면 파일 정리, 브라우저 조작, 메일 관리 같은 실제 작업을 대신 처리한다.

한눈에 보기

오픈클로는 내 컴퓨터에서 돌아가는 오픈소스 AI 비서다. 텔레그램·왓츠앱·슬랙·디스코드 같은 메신저로 말을 걸면 LLM이 무엇을 할지 판단하고, 파일 정리·브라우저 조작·셸 명령·메일과 일정 관리 같은 실제 작업을 한다. 처음 이름은 Clawdbot이었고, Moltbot을 거쳐 지금 이름이 됐다.

구분일반 챗봇오픈클로
하는 일질문에 답하기직접 작업 실행
말 거는 곳웹·전용 앱평소 쓰는 메신저
실행 위치서비스 회사 서버내 PC·홈서버
기억 저장서비스 계정내 컴퓨터의 로컬 파일

메신저를 연결하고 문자로 일을 시킨다

내 컴퓨터에 설치한 뒤 게이트웨이(Gateway)에 메신저를 연결하는 것이 기본 흐름이다. 왓츠앱은 openclaw channels login --channel whatsapp을 실행하고 휴대폰으로 QR을 찍어 로그인한다. 텔레그램은 봇 토큰을 넣으면 된다. 그 뒤로는 밖에서 메시지만 보내도 집에 있는 PC가 작업하고 결과를 채팅으로 알려 준다.

실제로는 정해진 시간마다 도는 일에 많이 쓴다. 매일 아침 뉴스를 모아 요약하거나, 증권사 API를 연결해 주식 리포트를 받아 보는 식이다. 전기를 적게 먹는 저사양 맥이나 홈서버에 올려 24시간 켜 두는 사용자가 많다.

프로그램은 무료, 모델 비용은 따로 낸다

MIT 라이선스로 공개돼 있고 유료 버전이 없다. 대신 연결한 모델의 API 요금은 따로 나온다. openclaw.json에 Claude·GPT 같은 모델을 등록할 수 있고, 하나가 멈추면 다음 모델로 넘어가도록 대체 순서도 정해 둘 수 있다. Claude Pro/Max 구독 계정을 연결하면 약관 위반이므로, 쓴 만큼 내는 API 키를 써야 한다.

가벼운 사용$10~30
보통 사용$30~70
자동화 위주$100~150+

한 달 API 비용 추정치(openclaws.io 기준).

오픈클로는 지시문·대화 기록·도구 설명·메모리를 한꺼번에 모델에 보내서 요청 하나가 크다. 그래서 중요한 판단은 성능 좋은 모델에 맡기고, 주기적인 상태 확인처럼 가벼운 일은 싼 모델에 넘기는 구성이 흔하다. Ollama로 로컬 모델을 쓰면 API 요금은 들지 않는다. 하지만 8B급 작은 모델은 파일 삭제 같은 간단한 명령도 제대로 못 했다는 후기가 있다.

권한이 큰 만큼 사고도 크다

오픈클로를 설치하면 모든 파일에 접근하고, 아무 코드나 실행하고, 인터넷에도 접속할 수 있는 프로그램이 내 PC에서 돌게 된다. 실제로 메일함이 통째로 지워진 사례가 있었고, 악성 스킬 하나만 설치해도 컴퓨터 전체가 위험해질 수 있다는 경고도 나왔다.

위험줄이는 방법
파일 임의 삭제중요한 파일이 없는 별도 기기나 샌드박스에서 실행
민감 정보 유출메일·결제 계정은 처음부터 연결하지 않기
악성 스킬출처를 확인한 스킬만 설치

스킬이 미국 서비스 위주라 국내 예약이나 쇼핑 사이트 자동화는 잘 안 된다는 점도 알아 둬야 한다.
