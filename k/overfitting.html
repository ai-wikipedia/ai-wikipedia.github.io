과적합

Overfitting

모델이 훈련 데이터를 이해하지 않고 외워서, 처음 보는 데이터에서 성능이 떨어지는 현상이다. 모델을 학습하거나 파인튜닝할 때 검증 성능으로 꼭 확인해야 하는 문제다.

한눈에 보기

과적합은 모델이 훈련 데이터를 이해하지 않고 외워 버린 상태다. 기출문제만 외운 학생이 문제가 조금만 바뀌어도 틀리는 것과 같다. 훈련 데이터의 노이즈와 특이한 패턴까지 배워서 훈련 성능은 높은데, 새 데이터에서는 성능이 떨어진다. 모델이 너무 단순해서 훈련 데이터조차 못 맞히는 과소적합과는 반대 개념이다.

상태훈련 성능새 데이터 성능흔한 원인
과소적합낮음낮음모델이 너무 단순, 학습 부족
적정높음높음목표하는 상태
과적합매우 높음낮음너무 오래 학습, 데이터 부족

검증 손실이 오르면 멈출 때다

과적합은 훈련 데이터 성능만 봐서는 알 수 없다. 그래서 데이터를 처음부터 세 묶음으로 나누고, 모델이 학습 중에 보지 않은 데이터로 성능을 따로 잰다.

데이터용도
훈련모델이 실제로 학습하는 데이터
검증학습 중 성능 확인, 설정 조정
테스트마지막에 한 번만 쓰는 최종 평가

학습 그래프에서 훈련 손실은 계속 줄어드는데 검증 손실이 어느 순간부터 늘어나면 과적합이 시작된 것이다. 두 선이 벌어지기 시작하는 지점이 학습을 멈출 때다.

줄이는 방법은 상황에 맞게 고른다

방법하는 일이럴 때
조기 종료검증 손실이 나빠지면 학습 중단거의 항상 기본으로
데이터 늘리기·증강데이터를 더 모으거나 변형해 늘림데이터가 적을 때
드롭아웃학습 중 일부 뉴런을 무작위로 끔신경망이 클 때
L2 정규화가중치가 너무 커지면 벌점특정 특징에 지나치게 쏠릴 때

보통 조기 종료를 기본으로 두고 나머지를 더한다. 너무 세게 막으면 오히려 과소적합이 되니, 검증 성능을 보면서 강도를 조절한다.

파인튜닝은 데이터가 적어 더 위험하다

LLM을 파인튜닝할 때는 준비한 데이터가 적은 경우가 많아 과적합이 쉽게 생긴다. 같은 데이터를 여러 번 반복(에폭)할수록 위험이 커지므로, 반복 횟수와 학습률을 낮게 시작하고 검증 손실을 보면서 늘린다. 과적합된 모델은 훈련 예시 문장을 그대로 따라 하거나, 학습 데이터와 조금만 다른 질문에도 엉뚱하게 답한다.

테스트 데이터가 훈련 데이터에 섞이는 데이터 누수도 조심한다. 점수는 높게 나오지만 실제로는 외운 것이어서 과적합을 알아차리지 못하게 된다.
