OpenTag

OpenTag은 Slack이나 Teams 채널에서 AI를 멘션해 일을 맡기면 결과를 같은 스레드에 올려 주는 'AI 동료'형 에이전트다. 특정 모델 회사에 묶이지 않고 작업마다 모델을 고르거나 직접 서버를 운영하고 싶을 때 쓴다.

한눈에 보기

OpenTag은 팀 메신저에서 동료를 부르듯 AI를 멘션해 일을 맡기는 에이전트다. 결과가 같은 스레드에 올라와서 팀원 모두가 함께 본다. Claude Tag와 쓰는 방식은 같지만 특정 모델에 묶이지 않는다는 점이 다르다. 더 좋은 모델이 나오면 바로 갈아 끼울 수 있다. 지금은 성격이 다른 구현이 세 가지 있다.

구현형태이럴 때 쓴다
OpenTag (YC SaaS)바로 쓰는 서비스반복 업무 자동화
CopilotKit/OpenTag오픈소스 스타터 앱사내 장애 대응(온콜) 봇
amplifthq/opentag오픈소스, MIT내 컴퓨터에서 실제 코드 수정

DASH7 프로토콜 스택, RFID 플랫폼, 필라멘트용 NFC 태그 등 이름만 같은 다른 프로젝트도 많다.

SaaS판은 채널에 초대하면 끝

Slack이나 Teams에 추가하고 원하는 채널에 초대하면 된다. 작업을 태그하면 80개가 넘는 모델 가운데 그 일에 맞는 모델로 보내 준다. 반복되는 일이 보이면 "매주 월요일 9시에 이걸 돌릴까요?"처럼 자동화를 먼저 제안한다.

일하면서 회사가 어떻게 돌아가는지, 누가 무엇을 맡는지를 위키로 정리해 두기 때문에 쓸수록 맥락이 쌓인다. 실행은 클라우드에서 이뤄지고, 실행할 때마다 따로 샌드박스를 만들어 연결한 도구 범위 안에서만 움직인다.

오픈소스 두 가지는 포크해서 쓴다

CopilotKit판은 LangGraph로 만든 셀프 호스팅 온콜 트리아지 봇이다. 처음부터 고쳐 쓰라고 만든 앱이라 바꿀 부분이 파일 하나나 디렉터리 하나에 모여 있다. 장애 대응 봇을 새로 짜지 말고 이걸 받아서 자기 도구만 끼우면 된다.

amplifthq판은 Slack, GitHub, GitLab, Linear, Lark에서 멘션하면 Claude Code나 Codex 같은 코딩 에이전트를 내가 관리하는 컴퓨터에서 실행한다. 컴퓨터가 꺼져 있어도 요청은 큐에 쌓아 둔다. 예를 들어 Linear 이슈 스레드에서 부르면 내 노트북 저장소에서 수정이 진행되고, 진행 상황과 근거가 스레드로 돌아온다.

자동 머지는 없다, 권한은 좁게

채팅방에서 AI를 부르면 편한 만큼 누가 무엇을 바꿀 수 있는지가 흐려지기 쉽다. amplifthq판은 드래프트 PR 게시를 따로 통제하는 단계로 나눠 두었고, 자동 머지는 하지 않는다. 채팅에 적은 말만으로 권한이 넓어지지도 않는다.

선택장점대가
SaaS판바로 쓰고, 모델 라우팅으로 비용 절감회사 맥락이 외부 서비스에 쌓임
오픈소스판코드와 실행 환경을 직접 관리배포·운영을 직접 맡아야 함

팀이 AI 동료에게 바라는 게 업무 자동화인지, 장애 대응인지, 코드 수정인지를 먼저 정하면 고를 구현이 정해진다.
