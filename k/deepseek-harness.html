딥시크 하네스

DeepSeek Harness (DSH)

딥시크가 MIT 라이선스로 공개한 오픈소스 에이전트 하네스(명령어 `dsh`)다. 모델·도구·에이전트 루프까지 전부 플러그인으로 갈아 끼울 수 있어서, 원하는 모델로 내 코딩 에이전트를 직접 구성하고 싶을 때 쓴다.

한눈에 보기

DeepSeek Harness는 언어 모델을 실제로 일하는 코딩 에이전트로 만들어 주는 바깥 껍데기다. 작업 폴더의 파일을 읽고 고치고, 명령을 실행하고, 일을 나눠 맡기며 계획을 관리한다. 특징은 모든 것이 플러그인이라는 점으로, 모델 연결부·도구 목록·세션 기록·에이전트 루프까지 설정만 바꿔 교체할 수 있다.

항목내용
라이선스MIT, 소스 전체 공개
실행 방식웹 UI, 맥·윈도우 데스크톱 앱, 헤드리스
연결 가능한 모델DeepSeek 외 다른 업체 키, OpenAI 호환 주소
상태개발자 프리뷰 (호환 깨지는 변경 예고)

명령 한 줄이면 웹 화면이 열린다

Node.js만 설치하고, 테스트할 저장소 폴더 안에서 npx @deepseek-ai/dsh web을 실행한다. 홈 폴더나 여러 프로젝트가 섞인 폴더에서 띄우지 않는 것이 좋다. 브라우저를 자동으로 열고 싶지 않으면 --no-open을 붙인다.

단계할 일
1. 키 저장Settings → Models에 DeepSeek API 키나 다른 업체 키 입력
2. 폴더 선택Choose workspace로 작업 폴더 지정
3. 작업 지시세션을 열고 할 일 전송, 위험한 작업은 실행 전에 승인 요청

Codex처럼 OAuth로 로그인하는 방식은 아직 지원하지 않아서 API 키를 준비해야 한다.

필요한 기능은 플러그인으로 붙인다

기본 화면은 웹 UI지만, 부족한 부분은 커뮤니티 플러그인으로 채운다. GitHub에서 dsh-plugin 토픽을 찾으면 된다. 터미널에서 일하고 싶다면 TUI 플러그인을, 텍스트 전용 모델에 이미지를 읽히고 싶다면 비전 플러그인을 붙이는 식이다.

이럴 때플러그인 예
터미널에서 계속 작업dsh-TUI (되감기·포크, 세션 이어가기)
텍스트 모델에 이미지 이해 추가ModLens
외부 앱 다수 연결Composio (인증·토큰 갱신 처리)

하네스는 무료, 모델 비용은 따로

하네스 자체는 설치·수정·자체 호스팅 모두 무료다. 하지만 추론 비용은 연결한 모델 업체에 그대로 낸다. 0.2.0 후보판부터는 DeepSeek 계정 모델로 대화하면 별도 API 키 없이 웹 검색을 쓸 수 있고, 데스크톱 앱에 dsh 명령이 함께 들어가 Node 없이도 플러그인을 관리할 수 있다.

일회용 환경에서 돌려야 안전하다

공식 안전 안내에 따르면 아직 보안 감사를 거치지 않았고, 모델이 만든 명령과 서드파티 플러그인을 실행한다. 최소 권한으로, 일회용 가상머신이나 컨테이너에서 쓰고 접근 가능한 파일은 백업해 둔다. 평가 중에는 전체 자동 승인을 켜지 않는다. 또 출시 직후 이름이 비슷한 npm 패키지가 나왔으므로 공식 범위인 @deepseek-ai인지 확인하고 설치한다.
