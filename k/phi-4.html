Phi-4

Phi-4 (Microsoft)

Phi-4는 마이크로소프트가 만든 140억 파라미터 규모의 작은 오픈 모델로, 크기에 비해 수학과 논리 추론을 잘한다. 내 컴퓨터나 작은 서버에서 비용을 아끼면서도 어느 정도 추론력이 필요한 작업을 맡길 때 쓴다.

한눈에 보기

Phi-4는 마이크로소프트가 만든 작지만 추론을 잘하는 오픈 모델이다. 노트북이나 작은 서버 한 대에서도 돌아갈 만큼 가볍다. 그래도 수학과 논리 문제에서는 자기보다 훨씬 큰 모델을 앞서기도 한다. 비용과 속도가 중요하지만 생각하는 능력도 필요한 작업에 잘 맞는다.

모델크기이럴 때 쓴다
Phi-414B수학·논리 추론, 문서 분류
Phi-4-mini3.8B함수 호출이 필요한 에이전트 부품
Phi-4-multimodal5.6B텍스트·이미지·음성을 함께 처리
Phi-4-reasoning-추론에 특화한 작업

크기는 파라미터 수다. 14B는 140억 개를 뜻한다.

내 컴퓨터에서 바로 띄운다

오픈 모델이라 누구나 받아서 직접 실행할 수 있다. 가장 쉬운 방법은 ollama run phi4로 내 컴퓨터에 띄우는 것이다. 데이터를 클라우드로 보내지 않아도 되므로 사내 문서나 민감한 데이터를 다룰 때 좋다.

방법이럴 때
Ollama 로컬 실행개인 PC에서 바로 써 볼 때, 민감한 데이터
Hugging Face 가중치 + vLLM·SGLang직접 서버를 꾸려 서비스할 때
Azure AI Foundry API설치 없이 API로 부를 때

비싼 대형 모델 대신 쓰는 자리

대량의 문서를 분류하거나 수식이 섞인 질문에 답하는 일을 대형 모델 API로 매번 처리하면 비용이 많이 든다. 이런 반복 작업은 Phi-4 한 대로 처리하면 훨씬 저렴하다. 도구를 호출하는 에이전트를 만들 때는 더 작은 Phi-4-mini를 쓰고, 이미지나 음성이 섞이면 multimodal을 고르면 된다.

작은 비결은 잘 고른 데이터

모델을 키우는 대신 학습 데이터의 질을 크게 높였다. 인터넷 글을 마구 모으지 않고, AI가 만든 고품질 합성 데이터와 엄선한 교과서·문제풀이 자료로 학습했다. 아무 책이나 많이 읽히는 대신 잘 정리된 문제집으로 공부시킨 셈이다.

넓은 지식과 긴 대화는 약하다

작은 모델이라 폭넓은 세상 지식이나 길고 복잡한 대화에서는 대형 모델만큼 안정적이지 않다. 틀린 답을 자신 있게 내놓는 환각도 여전하다. 고위험 분야에 쓰기 전에는 정확도와 안전성을 따로 검증해야 한다.
