라마

Llama

Meta가 가중치를 통째로 공개한 오픈 웨이트 LLM 시리즈다. 데이터를 밖으로 보내지 않고 내 PC나 회사 서버에서 돌리거나, 내 분야에 맞게 파인튜닝하고 싶을 때 쓴다.

한눈에 보기

Llama는 Meta가 학습을 마친 모델의 가중치를 누구나 내려받을 수 있게 공개한 LLM 시리즈다. API로만 쓰는 모델과 달리 노트북, 회사 서버, 인터넷이 끊긴 폐쇄망에서도 직접 돌릴 수 있다. 그래서 오픈소스 쪽에서 하는 파인튜닝·양자화·모델 병합 실험은 대부분 Llama에서 시작한다.

항목API 전용 모델Llama (오픈 웨이트)
실행 위치회사 서버내 PC·내 서버·폐쇄망
데이터외부로 보냄밖으로 나가지 않음
비용사용량만큼 요금요금 폭탄 걱정 없음
수정불가파인튜닝 가능

상황에 맞는 도구로 띄운다

내 PC에서 써 보려면 Ollama가 가장 쉽다. ollama run llama3 한 줄이면 모델을 받아 바로 대화할 수 있다. 이때 받는 파일은 GGUF 형식인데, 양자화로 정밀도를 조금 낮추는 대신 크기를 크게 줄여서 평범한 게이밍 PC에서도 돌아간다.

이럴 때방법
내 PC에서 바로 써 보기Ollama + GGUF 양자화 모델
회사 서비스에 붙이기vLLM으로 OpenAI 형태 API 세우기
법률·의료 같은 특정 분야 특화LoRA·QLoRA 파인튜닝

vLLM으로 띄우면 OpenAI용으로 짠 코드를 주소만 바꿔 그대로 쓸 수 있다. LoRA·QLoRA는 모델 전체가 아니라 작은 보조 층만 학습시키는 방식이라 GPU 한 장으로도 분야 특화 모델을 만들 수 있다.

버전마다 달라진 점

버전공개달라진 점
Llama 22023년상업적 사용 허용
Llama 32024년성능이 크게 오름
Llama 42025년 4월MoE 구조로 덩치에 비해 빠름

Llama 4는 질문마다 관련 있는 일부 '전문가'만 골라 쓰는 MoE 구조다. Scout와 Maverick이 공개됐고, 가장 큰 Behemoth는 예고만 됐을 뿐 아직 오픈 웨이트로 풀리지 않았다.

순위표 점수보다 직접 돌려 본다

오픈 웨이트라고 해서 성능이 가장 좋다는 뜻은 아니다. Llama 4가 순위표(LMArena)에 올린 것은 사람 평가자가 좋아하도록 대화체로 다듬은 실험 버전이었고, 누구나 받을 수 있는 공개 가중치는 그만큼 점수가 나오지 않았다. 모델을 고를 때는 순위표 숫자보다 내 작업에 직접 돌려 본 결과를 믿는 편이 안전하다.
