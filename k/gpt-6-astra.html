GPT-6 Astra (OpenAI)

GPT-6 아스트라는 OpenAI GPT-6 계열의 최상위 모델로, 웹 탐색·코딩·문서 작업처럼 사람이 컴퓨터로 하는 일을 여러 단계에 걸쳐 직접 처리한다. 값이 가장 비싸서 가장 어렵고 오래 걸리는 작업에 쓴다.

한눈에 보기

GPT-6 아스트라는 OpenAI가 2026년 9월에 내놓은 GPT-6 계열의 최상위 모델이다. 브라우저 조작, 코드 작성과 디버깅, 슬라이드·스프레드시트 작업, 3D 모델링처럼 컴퓨터로 하는 일을 사람이 단계마다 지시하지 않아도 끝까지 이어서 처리하게 만들었다. 가장 어려운 일은 Astra에, 매일 하는 일은 값이 싼 Sol에 맡기는 식으로 나눠 쓰면 된다.

모델위치이럴 때 쓴다
GPT-6 Astra최상위가장 어려운 과학 연구, 길고 복잡한 컴퓨터 작업
GPT-6.1 Sol주력일상 코딩, 문서 작업, 오래 도는 에이전트

ChatGPT는 데스크톱 앱, 개발자는 gpt-6-astra

ChatGPT Plus·Pro·Business·Enterprise 이용자는 Work 모드나 Codex의 모델 목록에서 Astra를 고른다. 사용량은 구독 한도에 포함되고, 넘치면 크레딧을 사서 더 쓴다. Pro 이상 요금제에서는 Astra Pro도 쓸 수 있다. OpenAI는 컴퓨터를 직접 조작하는 기능을 제대로 쓰려면 ChatGPT 데스크톱 앱을 쓰라고 권한다.

개발자는 OpenAI API에서 모델 ID gpt-6-astra로 부르고, Microsoft Azure나 AWS Bedrock으로도 쓸 수 있다. 데이터를 남기지 않아야 하는 서비스라면 조건을 갖춘 API 고객에게 Zero Data Retention이 지원된다.

출력 단가가 Sol의 5배

Astra는 100만 토큰당 입력 $10, 출력 $50이다. 응답이 최대 2배 빠른 Fast 모드는 값도 2배다. 나중에 나온 GPT-6.1 Sol은 코딩·컴퓨터 사용·업무 작업에서 Astra에 가까운 성능을 Astra의 1/5 가격에 낸다.

Astra Fast$100
Astra$50
GPT-6.1 Sol$10

출력 100만 토큰당 가격. Fast 모드는 표준 가격의 2배다.

작업마다 모델을 나눠 쓴다

모든 일을 Astra로 돌리면 비용이 빠르게 불어난다. OpenAI도 가장 어려운 과학 연구 작업에는 Astra를 쓰라고 안내하므로, 나머지는 Sol로 돌리는 게 기본이다.

작업추천
데이터 분석·시뮬레이션이 섞인 연구Astra
같은 맥락을 반복해 보내는 에이전트6.1 Sol (캐시 입력이 싸다)
사람이 결과를 기다리는 급한 작업Astra Fast 모드

보안 등급과 벤치마크는 따로 확인

Astra는 OpenAI 내부 기준에서 사이버보안 능력이 '위험(Critical)' 단계에 처음 도달한 모델이다. 그래서 보호 장치가 강화됐고, 기업·신뢰 접근 프로그램부터 차례로 열려서 계정에 따라 아직 목록에 안 보일 수 있다. 공개된 점수는 대부분 OpenAI 발표 기준이고, 같은 평가도 실행 환경(하네스)에 따라 점수 차이가 크게 났다. 추론 과정이 겉으로 덜 드러난다는 익명 제보도 있어 모니터링 문제가 거론됐다. 내 작업으로 직접 시험해 보는 게 가장 확실하다.
