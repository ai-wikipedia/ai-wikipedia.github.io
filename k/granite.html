IBM Granite

IBM이 기업용으로 만든 오픈소스 AI 모델 패밀리다. 데이터를 외부로 보내기 어려워 회사 서버나 노트북에서 모델을 직접 돌려야 할 때 쓴다.

한눈에 보기

Granite는 IBM이 만든 오픈소스 모델 패밀리로, 최고 성능보다 기업이 마음 놓고 자체 운영하는 것을 목표로 한다. 상업적으로 자유롭게 쓸 수 있는 라이선스에 크기도 작아서, 기밀 데이터를 외부 API로 보내기 곤란할 때 고르면 된다.

항목Granite프론티어 모델 API
라이선스대부분 Apache 2.0, 상업 이용·수정 자유제공사 약관을 따른다
실행 위치회사 서버, 노트북외부 클라우드
데이터 외부 전송없음필요
복잡한 추론·창작최상위보다 약함강함

내려받아 로컬에서 띄운다

허깅페이스 ibm-granite에서 가중치를 받아 Ollama나 vLLM으로 띄운다. 모델 크기가 350M부터 30B 정도라 회사 GPU는 물론 노트북에서도 돌릴 수 있다.

예를 들어 사내 코드베이스에 답하는 어시스턴트를 만들 때 코드를 외부에 보낼 수 없다면, Granite를 회사 GPU에 올리고 RAG를 붙이면 된다. 민감한 정보를 다루는 금융·의료·공공 분야에서 특히 쓸모가 크다.

작업별로 골라 조합한다

언어 모델 하나만 있는 게 아니다. 작업에 맞는 모델을 골라 이어 붙이면, "PDF 보고서에서 표를 뽑아 요약"처럼 여러 형태가 섞인 일도 Granite 안에서 처리할 수 있다.

모델 종류이럴 때 쓴다
언어 모델일반 대화, 도구 호출
코드 모델코드 작성·질문 (116개 언어로 학습)
비전 모델문서 속 표·차트 읽기
음성·임베딩 모델음성 인식, 검색
Granite Guardian입출력에서 유해·위험한 내용 거르기

4.0 세대부터 긴 입력에 가볍다

최신 4.0/4.1 세대는 구조를 바꿔 긴 입력을 처리할 때 메모리를 덜 쓰면서도 빠르다. 작은 모델인데도 도구 호출, 지시 따르기 같은 실무 작업에서는 훨씬 큰 모델과 견줄 만하다는 게 강점이다.

최고 성능이 필요하면 다른 모델로

Granite는 가장 똑똑한 모델을 노리지 않는다. 복잡한 추론이나 창의적인 글쓰기에서 최상위 모델만큼을 기대하면 실망할 수 있다. 최고 성능이 필요한 작업은 프론티어 모델에, 안심하고 직접 운영해야 하는 작업은 Granite에 나눠 맡기면 된다.
