Muse Spark Open (Meta)

메타가 가중치를 공개한 Muse 시리즈의 대형 오픈웨이트 모델로, 여러 파일에 걸친 리팩토링이나 긴 디버깅 같은 코딩·에이전트 작업을 내 서버나 원하는 클라우드에서 직접 돌리고 싶을 때 쓴다. API로만 쓸 수 있는 Muse Spark 1.x와 달리 가중치를 받아 직접 운영하고 고칠 수 있다.

모델공개 방식이럴 때 쓴다
Muse Spark Open가중치 공개 (Muse 라이선스)대형 코딩·에이전트 작업을 직접 운영
Muse Glimmer가중치 공개 (Apache 2.0)24GB GPU 한 장에서 오프라인 실행
Muse Spark 1.x유료 API만운영 부담 없이 API로 호출

메타 초지능 연구소(MSL)가 2026년 10월 Muse Spark를 바탕으로 만들어 공개했다. 계획하고, 실행하고, 결과를 보고, 스스로 고치는 긴 작업에 맞춰 학습했다.

전체는 크지만 한 번에 쓰는 건 일부

전체 파라미터는 8,160억 개지만, 토큰 하나를 처리할 때는 420억 개 정도만 켜지는 전문가 혼합(MoE) 구조다. 텍스트·이미지·영상·음성을 입력받아 텍스트로 답하고, 컨텍스트는 최대 100만 토큰이다. 저장소 전체와 에러 화면 캡처, 재현 영상을 한꺼번에 넣고 원인을 찾게 하는 식으로 쓸 수 있다.

API로 바로 쓰거나 가중치를 받거나

가장 쉬운 방법은 API 제공사를 쓰는 것이다. OpenRouter, Together AI, Groq, Fireworks AI, Baseten, Modal, Nebius에서 호출할 수 있다. 직접 띄우려면 Hugging Face의 meta-models/Muse-Spark-Open-816B-A42B나 SageMaker, Google Cloud Model Garden, Microsoft Foundry에서 가중치를 받는다.

방식필요한 것비용 감각
API (OpenRouter 기준)API 키입력 $1.25 / 출력 $4.25
집에서 실행M5 Ultra 맥 스튜디오 2대 + MLX장비값이 크다

API 가격은 100만 토큰당 기준이다.

오픈소스가 아니라 오픈웨이트

다운로드, 수정, 파인튜닝, 배포는 허용되지만 Apache 2.0이 아닌 Muse Model License를 따른다. 제품에 쓸 때 지켜야 할 표시 조건과 사용 정책이 있다. 이 모델을 서비스형(MaaS)으로 제공하면서 연 매출이 2,000만 달러를 넘으면 메타에 미리 알리고 따로 계약해야 한다. 사내 사용, 연구, 자체 제품 기능에 넣는 경우에는 이 조항이 적용되지 않는다.

안전장치는 직접 붙여야 한다

메타는 시스템 가드레일 없이 단독으로 쓰일 것을 고려해 안전 학습을 추가했다고 밝혔다. 그래도 직접 배포할 때는 용도에 맞는 가드레일을 함께 두라고 권한다. 고객 응대 에이전트처럼 외부 사용자가 직접 입력하는 서비스라면 입출력 필터를 따로 붙이는 게 좋다.

코드를 밖에 내보내기 싫은 팀의 코딩 에이전트

가장 흔한 쓰임은 직접 운영하는 코딩 에이전트의 두뇌다. 처음에는 API 제공사로 싸게 시험해 보고, 코드나 데이터를 외부로 보내기 어려우면 가중치를 받아 사내 서버나 쓰던 클라우드에 띄운다.

어디서어떻게 쓰나
코딩 에이전트저장소 전체와 에러 캡처를 넣고 여러 파일 리팩토링·긴 디버깅을 맡긴다
사내 서버·자체 클라우드가중치를 받아 띄우고, 외부로 못 나가는 사내 코드와 문서 작업에 쓴다
자체 제품 기능자기 데이터로 파인튜닝해 제품 안의 에이전트 기능에 넣는다. 가드레일은 따로 붙인다
API 제공사장비 없이 OpenRouter 같은 곳에서 불러 성능과 비용을 먼저 재 본다
