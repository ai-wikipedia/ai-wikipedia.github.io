Perplexity Sonar

Perplexity가 만든 검색 특화 언어 모델로, 질문마다 실시간으로 웹을 검색해 출처가 달린 답을 빠르게 낸다. 최신 뉴스처럼 지금 일어나는 일을 물어야 할 때나 앱에 실시간 검색 기능을 붙일 때 쓴다.

한눈에 보기

Perplexity Sonar는 AI 검색 서비스 Perplexity가 직접 만든 검색 특화 모델이다. 질문이 들어오면 먼저 웹을 검색하고, 그 결과를 근거로 출처 링크가 달린 답을 빠르게 낸다. 최신 뉴스나 오늘 일어난 일을 물어야 할 때 쓴다.

구분보통 언어 모델Sonar
아는 범위학습이 끝난 시점까지실시간 웹
최신 질문모르거나 지어냄검색해서 답함
출처없음답변에 링크가 붙음
잘하는 일어려운 추론·코딩빠르고 정확한 최신 정보

검색하고 답하도록 다시 훈련했다

Meta의 Llama 3.3 70B를 가져와 "일단 웹을 검색하고, 그 결과를 근거로 답한다"는 방향으로 추가 훈련한 모델이다. Cerebras의 전용 추론 칩 위에서 돌아가 초당 수백~1,200토큰 수준으로 답할 만큼 빠르고, 검색 용도 모델 중에서는 가볍고 저렴한 편이다.

API 하나로 앱에 검색을 붙인다

예전에는 최신 정보를 답하게 하려면 검색 엔진 API를 따로 붙이고, 결과를 정리해 LLM에 다시 넘기는 RAG 파이프라인을 직접 만들어야 했다. Sonar는 이 과정을 모델 하나로 합쳤다. chat completions 형태의 API에 질문만 보내면 검색부터 출처 달린 답까지 한 번에 돌아온다.

조절 방법이렇게 쓴다
검색 깊이 High/Medium/Low속도와 정확도 중 무엇이 중요한지에 맞춰 고른다
검색 도메인 지정원하는 사이트 안에서만 찾게 한다
Sonar Pro길고 복잡한 조사에 쓴다 (검색 결과 2배)

예를 들어 주식 앱에서 "오늘 이 종목이 왜 떨어졌어?"라고 물으면, Sonar가 방금 올라온 뉴스를 찾아 출처와 함께 요약해 준다.

Perplexity 앱에서는 이미 쓰고 있다

개발자가 아니어도 Sonar를 접하고 있을 수 있다. Perplexity 앱의 기본 검색 모델이라, 무료 사용자가 빠른 답을 받을 때 뒤에서 돌아가는 것이 바로 Sonar다.

검색 말고는 약하다

출처 기반 검색 답변에 맞춘 모델이라 만능은 아니다. 긴 추론, 창의적 글쓰기, 복잡한 코딩에서는 GPT나 Claude 계열 모델보다 약하다. Perplexity 앱이 여러 외부 모델을 골라 쓰는 구조에서 Sonar는 "빠른 검색 전용" 카드라고 보면 된다.
