Beam 1.0 501B (Reflection AI)

빔 1.0은 미국 Reflection AI가 처음 내놓은 오픈 웨이트 추론 모델로, Apache 2.0 라이선스로 공개됐다. 코딩 에이전트나 오래 걸리는 다단계 작업을 싼 API로 돌리거나 회사 서버에 직접 올려 쓰고 싶을 때 고른다.

한눈에 보기

빔 1.0은 Reflection AI가 처음 공개한 오픈 웨이트 모델이다. 전체 크기는 크지만 토큰 하나를 만들 때는 일부 전문가(MoE)만 쓰기 때문에 덩치에 비해 가볍게 돈다. 코딩, 여러 단계에 걸친 도구 호출, 오래 도는 에이전트 작업을 겨냥해 만들었다.

항목내용
크기전체 501B, 토큰당 23B만 사용
컨텍스트100만 토큰 (출력은 최대 약 13만)
입출력텍스트만, 영어 중심
라이선스Apache 2.0, 상업적 사용 가능

API로 쓰면 싸고 빠르게 시작

가장 쉬운 길은 API다. OpenRouter, Cloudflare, NanoGPT, Amazon SageMaker JumpStart 등에서 바로 부를 수 있고 함수 호출과 구조화된 출력(JSON)도 지원한다. 생각하는 강도를 low부터 max까지 고를 수 있으니, 설계·디버깅은 높게, 로그 요약 같은 단순 작업은 낮게 두면 속도와 비용을 함께 아낀다. NanoGPT는 기본값이 max라 그대로 쓰면 토큰이 많이 나올 수 있다.

OpenRouter 모델 페이지 기준 입력 100만 토큰당 $0.25, 출력 $1. 일부 리뷰 사이트는 다른 가격을 적고 있어 공급자마다 확인이 필요하다.

직접 호스팅은 GPU 서버급

가중치는 Hugging Face에 BF16, FP8, NVFP4 세 가지로 올라와 있다. vLLM이나 SGLang으로 띄우면 OpenAI 호환 서버가 되어 기존 클라이언트를 그대로 붙일 수 있다. 다만 개인 PC로는 무리이고, 공식 예시도 GPU 16장 텐서 병렬이다.

LoRA 파인튜닝H200 8장, 1노드
전체 파라미터 SFTH200 64장, 8노드

답이 짧아 토큰을 덜 쓴다

Reflection은 토큰 효율을 강조했고, 외부 평가에서도 같은 문제를 풀 때 쓰는 출력 토큰이 비슷한 모델들보다 적게 나왔다. 출력 단가가 비용을 좌우하는 에이전트에서는 이 차이가 그대로 청구서에 반영된다.

비교 모델 중앙값130M

증류·재학습까지 허용

파인튜닝, 양자화, 모델 병합은 물론 출력을 다른 모델 학습에 쓰는 것(증류)도 막지 않는다. 사내 데이터로 LoRA를 입혀 자기 도메인용 코딩 모델을 만들거나, 작은 모델의 교사로 쓰기 좋다. 지식은 2026년 6월 말까지라 그 뒤 라이브러리 변경은 문서를 함께 넣어 주는 편이 안전하다.
