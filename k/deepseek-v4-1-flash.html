딥시크 V4.1 플래시

DeepSeek V4.1 Flash

딥시크 V4.1 플래시는 DeepSeek이 MIT 라이선스로 공개한 오픈 웨이트 모델로, 텍스트와 이미지를 입력으로 받는다. 긴 작업 기록을 매번 다시 읽는 코딩 에이전트를 싸고 빠르게 돌릴 때 쓴다.

한눈에 보기

딥시크 V4.1 플래시는 DeepSeek이 2026년 9월 공개한 오픈 웨이트 모델이다. 에이전트는 턴마다 지금까지의 대화와 파일, 도구 결과를 전부 다시 읽기 때문에 오래 돌릴수록 비싸진다. 이 모델은 이렇게 쌓이는 비용을 줄이는 데 설계를 집중했다.

항목내용
라이선스MIT (오픈 웨이트)
컨텍스트 / 최대 출력100만 토큰 / 384K 토큰
입력텍스트, 이미지
잘 맞는 일긴 기록을 반복해서 읽는 에이전트 작업

긴 기록을 다시 읽어도 메모리를 덜 쓴다

모델은 앞서 읽은 내용을 '캐시'로 저장해 두고 다시 쓰는데, 기록이 길어질수록 이 캐시가 커져서 느리고 비싸진다. V4.1 플래시는 입력을 읽는 부분은 가볍게, 답을 쓰는 부분만 무겁게 나눠서 캐시를 크게 줄였다. 입력은 길고 출력은 짧은 에이전트 작업에 맞춘 구조다.

V4 플래시1
V4.1 플래시약 1/4

같은 길이 기준으로 GPU 메모리에 두는 캐시 크기. 오래 저장해 두는 캐시는 약 1/8로 줄었다. DeepSeek 발표 기준.

API 이름은 deepseek-flash, 옛 ID는 확인 필요

DeepSeek API에서는 모델 이름을 deepseek-flash로 지정한다. 기존 V4 계열 ID로 보낸 요청도 지금은 V4.1 플래시가 받으므로, ID를 코드에 박아 둔 프로젝트는 실제로 어떤 모델이 답하는지 확인해 두는 게 좋다. OpenCode, CodeBuddy 같은 코딩 에이전트가 공식으로 지원하고 OpenRouter, LM Studio Cloud로도 부를 수 있다.

기존 모델 ID지금 실제로 답하는 모델
deepseek-v4-flash, deepseek-v4-flash-vision-expV4.1 플래시 (기존 모델 은퇴)
deepseek-v4-proV4.1 플래시, 플래시 요금 (9월 14일부터, V4.1 Pro 출시 전까지)

밤에 돌리면 가격이 절반

피크 시간이 아닐 때는 요금이 절반이다. 밤마다 돌리는 대규모 리팩토링이나 테스트 생성처럼 급하지 않은 에이전트 작업을 오프피크로 몰아 두면 비용이 반으로 준다. 출력 한도가 커서 긴 코드 파일이나 문서를 응답 한 번에 통째로 다시 쓸 수도 있다.

코딩은 추론을 켜고, 맞지 않는 일은 다른 모델로

코딩 품질이 중요하면 thinking을 최대로 켜는 게 좋다. 한 리뷰어의 측정에서는 thinking을 켜자 점수가 크게 올랐고, 늘어나는 생성 시간은 빠른 출력 속도로 어느 정도 상쇄된다.

다만 터미널을 오래 직접 다루는 어려운 작업에서는 아직 최상위 모델에 뒤진다. 비디오·오디오·PDF는 입력으로 받지 않고, 오픈 웨이트라도 크기가 커서 개인 PC에서 가볍게 돌리기는 어렵다. 이런 작업은 다른 모델과 나눠 쓰는 편이 현실적이다.
