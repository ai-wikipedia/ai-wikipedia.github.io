GPT-5.5 (OpenAI)

OpenAI의 플래그십 모델로, 여러 단계로 얽힌 실제 업무를 스스로 계획하고 도구를 쓰며 결과를 확인해 끝까지 처리한다. 터미널 자동화나 오래 도는 코딩 에이전트처럼 맡겨 두고 끝까지 밀고 나가야 하는 일에 쓴다.

한눈에 보기

GPT-5.5는 OpenAI가 2026년 4월 내놓은 플래그십 모델이다. 질문에 답만 잘하는 모델이 아니라, 복잡한 일을 맡기면 스스로 계획하고 도구를 쓰고 결과를 확인하며 끝까지 해내도록 만들었다. ChatGPT, Codex, API에서 쓸 수 있다.

항목내용
모델 IDgpt-5.5
문맥 / 최대 출력약 105만 / 12만 8천 토큰
입력텍스트, 이미지
지식 기준 시점2025년 12월 1일

단가는 두 배, 작업당 비용은 20% 안팎

토큰 단가는 GPT-5.4의 정확히 두 배다. 하지만 같은 작업을 끝내는 데 출력 토큰을 40% 가까이 덜 써서, OpenAI는 작업 하나당 실제 비용이 20% 안팎으로 오른다고 설명한다. 토큰 단가보다 작업 하나를 끝내는 총비용으로 비교해야 한다.

GPT-5.4$15
GPT-5.5$30

출력 100만 토큰당 가격. GPT-5.5 입력은 $5, 캐시된 입력은 $0.5다.

긴 입력은 요금이 확 뛴다

100만 토큰 문맥을 쓸 수 있다고 매번 코드베이스를 가득 넣으면 안 된다. 입력이 27만 2천 토큰을 넘으면 그 세션 전체에 할증이 붙는다. 반대로 급하지 않은 대량 작업은 배치로 돌리면 절반이다.

조건요금 변화
입력 27만 2천 토큰 초과세션 전체 입력 2배, 출력 1.5배
배치 API절반
지역 처리 엔드포인트10% 추가

프롬프트를 공들여 맞춘 서비스라면 gpt-5.5-2026-04-23처럼 스냅샷 이름으로 고정해 두어야 나중에 모델이 바뀌어도 동작이 흔들리지 않는다. 출력이 매번 같아야 하거나 비용 제약이 큰 서비스는 서둘러 옮기지 말고 GPT-5.4에 머무는 것도 방법이다.

추론 강도는 한 단계 낮춰 시작

reasoning_effort는 none부터 xhigh까지 고를 수 있고 기본값은 medium이다. 답이 간결해져서 medium으로도 GPT-5.4의 high와 비슷한 결과가 나오는 경우가 많으니, 기존 설정보다 한 단계 낮춰 비교해 보자. 이전 모델용으로 넣어 둔 '수정 전에 파일이 있는지 꼭 확인하라' 같은 방어적 지시는 빼도 되는 경우가 많다.

Codex CLI에서는 codex -m gpt-5.5로 실행하거나 세션 중 /model gpt-5.5로 바꾼다. 작업별 프로필을 나눠 두면 비용을 크게 아낄 수 있다.

작업모델추론 강도
계획 수립GPT-5.5high
평소 작업GPT-5.5medium
단순 반복더 작은 모델low

터미널 자동화는 강하고, 이슈 해결은 섞어 쓴다

OpenAI 발표 기준으로 명령줄 작업을 계획하고 도구를 엮는 일, 아주 긴 문서에서 정보를 찾는 일에서 크게 나아졌다. 반면 실제 GitHub 이슈 해결에서는 Claude Opus 4.7에 뒤졌다. 터미널 중심 자동화는 GPT-5.5에 맡기고, 오래 걸리는 이슈 해결은 다른 모델과 섞어 쓰는 게 낫다. 더 정확해야 하는 단계에는 gpt-5.5-pro가 있지만 여섯 배 비싸니 꼭 필요한 곳에만 쓴다.
