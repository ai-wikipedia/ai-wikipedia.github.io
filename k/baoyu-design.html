바오위 디자인

Baoyu Design

Claude Code 같은 코딩 에이전트에 설치하는 에이전트 스킬로, UI 목업·프로토타입·슬라이드를 브라우저에서 바로 열리는 HTML 파일로 만들게 해 준다. 빌드나 라이브러리 설치 없이 파일만 열면 되니, 본격적으로 개발하기 전에 화면 시안을 빨리 눈으로 확인하고 싶을 때 쓴다.

방식결과물바로 볼 수 있나
그냥 "디자인해줘"설명, 코드 조각직접 붙여 넣어야 함
바오위 디자인자체 완결형 HTML더블클릭하면 끝
디자인 툴(피그마 등)디자인 파일사람이 직접 그려야 함

설치하고 말로 시키면 된다

Claude Code나 Cursor에서 npx skills add 명령으로 스킬을 설치한다. 그다음 평소처럼 "관리자 대시보드 와이어프레임 만들어줘"라고 요청하면, 에이전트가 스킬에 담긴 디자인 지침을 불러와 HTML 시안을 만든다.

나온 파일을 브라우저로 열어 보고, 마음에 안 드는 부분을 "버튼을 오른쪽 위로", "색을 차분하게"처럼 다시 말해 고친다. 이 확인과 수정을 몇 번 반복하는 게 기본 흐름이다.

개발 전 시안 단계에 쓴다

화면을 어떻게 나눌지 아직 정하지 못했거나, 기획 회의에 보여 줄 시안이 급할 때 가장 쓸모 있다. 실제 앱 코드에 손대기 전에 여러 안을 빨리 만들어 비교할 수 있다.

상황쓸까?이유
화면 구성 잡기, 회의용 시안쓴다빠르게 눈으로 확인
클릭해 보는 프로토타입, 발표 슬라이드쓴다HTML 하나로 공유 가능
실제 서비스에 넣을 화면 코드보조로만프로젝트 구조·컴포넌트에 맞춰 다시 짜야 함

시안은 시안일 뿐이다

결과물은 한 파일에 모든 것이 담긴 HTML이라, 기존 프로젝트의 프레임워크나 디자인 시스템과 그대로 이어지지 않는다. 시안으로 방향을 정한 뒤 실제 구현은 따로 하는 게 안전하다. 품질도 에이전트 모델과 요청을 얼마나 구체적으로 했는지에 따라 달라진다.

바오위 스킬 모음의 하나

중국 AI 개발자 바오위(宝玉, JimLiu)가 공개한 Baoyu Skills 컬렉션에 들어 있다. 같은 모음에 이미지 생성, 인포그래픽, 마크다운→HTML 변환, 커버 이미지 같은 콘텐츠 제작 스킬도 있어, 필요한 것만 골라 함께 설치하면 디자인부터 발행용 자료까지 에이전트 하나로 이어 만들 수 있다.

에이전트에서 시안을 뽑아 바로 돌려 본다

가장 흔한 건 코딩 에이전트 안에서 시안을 먼저 뽑아 보는 방식이다. 만든 HTML 파일을 브라우저로 열어 확인하고, 그대로 팀에 보내 의견을 받은 뒤 고른 안을 기준으로 구현을 시작한다.

어디서어떻게 쓰나
코딩 에이전트 (Claude Code, Cursor)기능을 만들기 전에 화면 시안 두세 개를 요청해 브라우저에서 비교하고, 고른 안으로 구현 방향을 정한다
기획·회의 준비회의용 와이어프레임이나 클릭해 보는 프로토타입을 HTML 파일 하나로 만들어 공유한다
발표 자료슬라이드를 HTML로 만들어 따로 프로그램 없이 브라우저에서 바로 띄운다
콘텐츠 제작같은 모음의 인포그래픽·커버 이미지 스킬과 함께 설치해 시안부터 발행용 자료까지 이어서 만든다
