Xiaomi MiMo

스마트폰 회사 샤오미가 만든 오픈소스 언어 모델 계열이다. 코딩과 에이전트 작업에 강하고 비슷한 성능의 해외 모델보다 훨씬 싸서, 코딩 도구를 싸게 돌리고 싶을 때 쓴다.

한눈에 보기

MiMo는 스마트폰·가전 회사 샤오미가 만든 오픈소스 언어 모델 계열이다. 코딩과 에이전트 작업에 강하면서도 비슷한 성능의 해외 상용 모델보다 훨씬 싸다. 그래서 코딩 도구에 값싼 모델을 붙이고 싶을 때 많이 쓴다.

모델특징이럴 때 쓴다
MiMo-7B첫 모델, 작은 추론 특화형수학·코딩 추론을 가볍게
MiMo-V2-Flash256K 컨텍스트, 생각 켜고 끄기긴 코드를 다루는 에이전트
MiMo-V2-Pro상위 모델코드 설계, 작업 계획
MiMo-V2.5MIT 라이선스 공개상업 이용, 추가 학습·파인튜닝

작아도 끝까지 추론하게 만들었다

2025년 4월 나온 첫 모델 MiMo-7B는 크기는 작지만 사전학습 단계부터 수학·코딩 문제를 끝까지 물고 늘어지도록 설계했다. 강화학습으로 다듬자 훨씬 큰 추론 모델급 성적을 냈다. 이후 샤오미는 대형 모델로 넘어가 V2와 V2.5 계열을 빠르게 내놓았다.

코딩은 최상위권, 값은 몇십 분의 일

V2-Flash는 실제 깃허브 이슈를 고치는 코딩 평가에서 오픈소스 모델 가운데 최상위권에 들었다. V2-Pro는 코드 설계와 작업 계획 능력이 Claude Opus급에 가깝다는 평가를 받았다.

그런데 비용은 비슷한 성능을 내는 해외 상용 모델의 몇십 분의 일 수준이다. 그래서 코딩 도구를 만드는 개발자들이 빠르게 채택했다.

엔드포인트만 바꿔 코딩 도구에 붙인다

샤오미는 MiMo를 별도 앱보다 API와 개발 도구 연동 위주로 내놓았다. OpenAI 호환 API와 Anthropic 호환 API를 모두 제공하므로, GPT나 Claude를 쓰던 코드에서 엔드포인트만 MiMo로 바꾸면 거의 그대로 돌아간다.

쓰는 방식방법이럴 때
코딩 에이전트 연결Claude Code, OpenCode, Cline 등에서 모델만 MiMo로 지정평소 쓰는 도구의 비용을 줄일 때
API 호출기존 OpenAI·Anthropic 코드의 엔드포인트 교체이미 만든 앱을 옮길 때
직접 구동Hugging Face 가중치를 vLLM 등으로 서빙로컬이나 자체 서버에서 돌릴 때

음성 인식(ASR)·음성 합성(TTS)·멀티모달 이해 모델도 함께 공개했다. 음성·이미지·영상을 다루는 에이전트도 한 계열 안에서 꾸릴 수 있다.

버전이 많고, 직접 시험해 봐야 한다

V2, V2.5, Pro, Flash로 빠르게 갈라져 나와서 어떤 모델이 무슨 용도인지 헷갈리기 쉽다. 또 평가 점수가 높다고 모든 작업에서 최상위 상용 모델을 대신하지는 못하니, 실제로 맡길 작업으로 직접 시험해 보는 게 좋다.
