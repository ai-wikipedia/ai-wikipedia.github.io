모델 붕괴

Model Collapse

모델 붕괴는 AI가 만든 데이터로 다음 AI를 학습시키는 일을 되풀이할 때, 세대가 지날수록 모델이 점점 단조롭고 부정확해지는 현상이다. 합성 데이터로 파인튜닝하거나 AI 글이 섞인 웹 데이터로 학습할 때 주의해야 하며, 사람이 만든 원본 데이터를 버리지 않으면 대부분 막을 수 있다.

단계나타나는 모습
초기드문 표현과 소수 사례부터 사라진다
후기출력이 비슷비슷해지고 원래 데이터와 멀어진다

복사본을 다시 복사하면 글자가 흐려지는 것과 같다.

드문 것부터 사라진다

모델은 학습 데이터에 자주 나온 패턴을 더 잘 따라 한다. 그래서 모델이 만든 글에는 흔한 표현은 많이, 드문 표현은 적게 들어간다. 이 글로 다시 학습하면 드문 부분이 더 줄고, 작은 오류는 다음 세대로 넘어가며 쌓인다.

초기에는 평균 성능이 멀쩡해 보여 알아차리기 어렵다. 사투리, 전문 용어, 소수 의견처럼 드물게 나오는 내용부터 빠지기 때문이다.

원본 데이터를 버리지 않으면 대부분 막힌다

연구에서 가장 위험한 경우는 매 세대마다 실제 데이터를 합성 데이터로 통째로 바꿀 때였다. 실제 데이터는 그대로 두고 합성 데이터를 덧붙이면 붕괴가 훨씬 덜했다. 합성 데이터 자체보다, 사람이 만든 데이터와 연결이 끊기는 게 문제다.

학습 방식붕괴 위험
실제 데이터를 합성 데이터로 교체높음
실제 데이터에 합성 데이터를 추가낮음
검수한 합성 데이터만 추가낮고 품질 관리도 쉬움

합성 데이터로 파인튜닝할 때 지킬 것

큰 모델로 예시 데이터를 만들어 작은 모델을 파인튜닝한다면 아래 순서를 지킨다. 핵심은 원본을 남기고, 걸러 내고, 다양성을 확인하는 것이다.

단계할 일
섞기사람이 쓴 실제 데이터를 일정 비율 함께 넣는다
거르기중복, 오류, 틀린 답을 규칙이나 사람 검수로 뺀다
다양성 확인주제·길이·문체가 한쪽으로 몰리지 않았는지 본다
출처 기록어떤 데이터가 AI 생성인지 표시해 둔다

평가할 때는 평균 점수만 보지 말고, 드문 사례를 따로 모은 테스트셋을 확인한다. 붕괴는 거기서 먼저 드러난다. 학습한 모델의 출력을 다시 학습 데이터로 넣는 반복 구조는 특히 조심해야 한다.

과적합·망각과는 다른 문제

용어원인차이
모델 붕괴AI 생성 데이터로 반복 학습여러 세대에 걸쳐 진행
과적합학습 데이터에 지나치게 맞춤한 번의 학습 안에서 생김
파국적 망각새 작업을 배우며 이전 지식을 잃음데이터 출처와 상관없음
모드 붕괴GAN이 몇 가지 결과만 반복 생성모델 하나를 학습하는 중에 생김

AI 출력이 다시 학습에 들어가는 곳에서 점검한다

모델 붕괴는 직접 쓰는 기법이 아니라, 학습 데이터를 만들 때 점검하는 기준으로 쓰인다. AI가 만든 글이 다시 학습 데이터로 흘러드는 곳이면 어디서든 따져 봐야 한다.

어디서어떻게 쓰나
작은 모델 파인튜닝큰 모델이 만든 예시에 실제 데이터를 섞고, 드문 사례 테스트셋으로 결과를 확인한다
웹 데이터 수집AI 글이 섞인 최신 웹 데이터는 출처를 표시하고 걸러서 넣는다
자기 출력 재학습모델 답변을 다시 학습에 넣을 때 원본 데이터를 매번 함께 유지한다
