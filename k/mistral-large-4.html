미스트랄 라지 4

Mistral Large 4 (Mistral AI)

미스트랄 라지 4는 프랑스 Mistral AI가 만든 1조 파라미터급 멀티모달 추론 모델로, 가중치가 공개될 예정인 오픈 웨이트 모델이다. 미국·중국 밖에서 직접 운영할 수 있는 최상위급 모델이 필요할 때, 특히 보안 감사나 업무 자동화 에이전트에 검토한다.

한눈에 보기

미스트랄 라지 4(ML4)는 Mistral AI가 2026년 10월 Public Preview로 내놓은 플래그십 모델이다. 덩치는 1조 개가 넘는 파라미터로 크게 키웠지만, 질문마다 필요한 '전문가' 일부만 불러 계산하기 때문에 실제 연산 비용은 전작과 비슷하다. 이미지와 텍스트를 함께 받아 생각을 거친 뒤 텍스트로 답한다.

항목라지 3라지 4
전체 파라미터675B1.05조
실제로 계산에 쓰는 양47B약 49~52B
가중치 공개공개10월 말 공개 예정

이렇게 쓴다

가중치가 나오기 전까지는 API로 쓴다. Mistral API는 Function Calling, Structured Outputs, 배치, Agents와 내장 도구를 지원하므로, 기존 Mistral 코드라면 모델 ID만 바꿔 도구 호출과 JSON 출력을 그대로 쓸 수 있다.

경로호출 방법이럴 때
Mistral API공식 API도구 호출·에이전트 기능까지 쓸 때
Ollamaollama run mistral-large-4:cloud로컬 도구 체인에 붙일 때
OpenRoutermistralai/mistral-large-4-0여러 모델을 한곳에서 비교할 때

컨텍스트 길이는 경로마다 다르다. Mistral 문서는 1M 토큰이라고 적지만, OpenRouter에서는 입력 512K·출력 최대 256K로 표기되니 쓰는 곳의 한도를 먼저 확인한다.

지금은 가격이 절반

정가도 싼 편인데, 현재는 50% 할인가로 제공된다. 같은 맥락을 반복해 보내는 에이전트라면 캐시 입력 가격이 크게 낮아진다.

잘하는 일: 보안과 업무 자동화

Mistral이 가장 내세우는 분야는 사이버 보안이다. 오픈소스 취약점을 재현하고 패치하는 테스트에서 모든 모델 중 가장 높은 점수를 받았다. 코드 보안 감사 파이프라인에서 취약점 재현과 패치 초안을 맡기고, 가중치가 나오면 사내에서 돌리는 구성이 잘 맞는다. Gmail·Slack·Salesforce 같은 앱을 넘나드는 업무 자동화에도 쓸 만하다.

쓰기 전에 주의할 점

종합 성능은 최상위 폐쇄 모델에 아직 못 미치고, 법률처럼 강한 분야와 프론트엔드 코드처럼 약한 분야의 차이가 크다. 또 생각을 길게 하는 편이라 같은 평가에서 비슷한 모델보다 출력 토큰을 두 배 넘게 썼다. 단가가 싸도 청구액은 커질 수 있으니, 출력 토큰 상한을 걸고 내 작업으로 다른 모델과 총비용을 직접 비교해 보는 게 안전하다.
