AGENTS.md 폴백

Claude Code AGENTS.md Fallback Support

Claude Code는 프로젝트에 CLAUDE.md가 없으면 그 대신 AGENTS.md를 읽는다. 이 기능을 AGENTS.md 폴백이라 한다. Codex·Cursor 같은 다른 코딩 에이전트와 한 저장소를 함께 쓰는 팀이 지침 파일 하나만 관리하고 싶을 때 쓴다.

한눈에 보기

Claude Code는 2.1.277 버전(2026년 9월)부터 프로젝트에 CLAUDE.md가 없으면 그 대신 AGENTS.md를 읽는다. 여러 코딩 에이전트가 한 저장소를 함께 쓸 때 지침 파일을 하나로 줄이려고 만든 기능이다. 두 파일을 합쳐 읽는 게 아니라 CLAUDE.md가 없을 때만 대신 읽는다는 점이 핵심이다.

저장소 상태Claude Code가 읽는 파일
CLAUDE.md만 있음CLAUDE.md
AGENTS.md만 있음AGENTS.md
둘 다 있음CLAUDE.md만

작업 폴더나 그 위의 상위 폴더 어디에든 CLAUDE.md가 있으면 '있음'으로 친다.

둘 다 읽게 하려면 CLAUDE.md에 한 줄을 넣는다

CLAUDE.md가 이미 있는 저장소에 AGENTS.md를 추가해도 Claude Code는 AGENTS.md를 읽지 않는다. 두 파일을 함께 쓰는 방법은 두 가지다.

방법적용 범위이럴 때
CLAUDE.md 맨 위에 @AGENTS.md저장소와 함께 팀 전체공통 지침은 AGENTS.md에, Claude 전용 지침은 CLAUDE.md에 둘 때
/config → Project instructions에서 모드 변경내 사용자 설정만나만 동작을 바꿔 시험해 볼 때

이 기능은 내장 플러그인(Claude Code Mod) 형태로 들어 있고, 모드는 네 가지다. 기능을 끄는 것도 /config에서 한다. 두 파일을 섞어 쓰면 서로 어긋나는 지시가 생기기 쉽다. 2.1.283부터는 /doctor prompt-audit가 CLAUDE.md, CLAUDE.local.md, AGENTS.md를 함께 읽고 서로 모순되는 파일을 찾아 준다.

다른 도구의 파일 이름을 모두 읽지는 않는다

AGENTS.md 계열이라도 다른 도구에서 쓰는 이름까지 다 읽지는 않는다. 그래서 Codex용으로 만든 로컬 덮어쓰기 파일은 Claude Code에 적용되지 않는다.

파일Claude Code
AGENTS.md, .claude/AGENTS.md읽음
AGENTS.override.md, AGENTS.local.md읽지 않음
.agents/ 폴더읽지 않음

AGENTS.md가 안 읽히는 것 같을 때 확인할 것

업그레이드한 직후의 첫 세션은 AGENTS.md를 건너뛸 수 있다. 실패했다고 판단하기 전에 세션을 한 번 더 열어 본다. 또 플러그인이 불러온 AGENTS.md에서는 InstructionsLoaded 훅이 실행되지 않는다. 그래서 이 훅으로 로딩을 기록하고 있었다면 기록이 남지 않는다.

AGENTS.md 안의 @ 가져오기가 작업 폴더 바깥을 가리키면, 그 프로젝트에서 외부 가져오기를 이미 승인한 경우에만 불러온다. 이때 승인 창도 뜨지 않는다. AGENTS.md는 여러 도구가 함께 쓰는 형식이라 Claude Code 전용 문법은 CLAUDE.md에 두는 편이 안전하다. 서브에이전트는 하위 폴더에 있는 AGENTS.md를 따로 받고, 포크는 부모가 쓰던 것을 그대로 물려받는다.
