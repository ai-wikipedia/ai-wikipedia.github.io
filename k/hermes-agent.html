Hermes Agent

Hermes Agent는 Nous Research가 만든 오픈소스 자율 에이전트다. 해낸 작업을 스킬로 저장하고 세션이 끝나도 기억을 이어 가므로, 비슷한 일을 반복해서 맡길 때 쓰면 좋다.

한눈에 보기

Hermes Agent는 쓸수록 일하는 방법이 쌓이는 오픈소스 에이전트다. Nous Research가 2026년 2월 MIT 라이선스로 공개했다. 같은 종류의 일을 여러 번 맡기는 환경에서 특히 쓸모가 있다.

구분일반 AI 에이전트Hermes Agent
대화가 끝나면배운 것을 잊는다영구 메모리에 남긴다
같은 일을 또 시키면처음부터 다시 한다저장한 스킬을 불러온다
실패했을 때사람이 프롬프트를 고친다원인을 분석해 스킬을 고칠 수 있다

해낸 일은 스킬 파일로 남는다

핵심은 닫힌 학습 루프(closed learning loop)다. 작업을 끝내면 그 과정을 마크다운 스킬 파일로 저장하고, 결과는 메모리에 기록한다. 다음에 비슷한 요청이 오면 저장한 스킬부터 꺼내 쓴다.

예를 들어 "이 프로젝트 테스트 돌려줘"를 처음 시키면 시행착오를 거친다. 한 번 성공하면 그 순서가 스킬이 되어, 다음부터는 헤매지 않고 바로 실행한다.

몇 주 전 대화도 찾아 쓴다

메모리는 SQLite 데이터베이스에 저장하고, FTS5 전문 검색과 LLM 요약을 함께 쓴다. 그래서 몇 주 전에 나눈 대화도 검색해서 맥락을 되살릴 수 있다. 보완 프로젝트인 hermes-agent-self-evolution은 실행 기록을 분석해 왜 실패했는지 찾고, 스킬과 프롬프트를 자동으로 다듬는다.

반복 업무에 맡기고, 일회성 작업엔 과하다

GitHub 저장소에서 내려받아 자기 컴퓨터나 서버에 설치하고, 연결할 LLM을 정한 뒤 터미널에서 일을 시킨다. 처음 몇 번은 결과를 지켜보며 쓸 만한 스킬이 쌓이는지 확인하는 게 좋다.

상황추천이유
매일 비슷한 개발·운영 작업쓴다스킬이 쌓일수록 빨라진다
오래 이어지는 개인 프로젝트쓴다지난 맥락을 기억한다
한 번 묻고 끝나는 질문안 써도 된다쌓을 경험이 없다

잘못 배운 스킬은 직접 지워야 한다

스스로 배우는 에이전트는 잘못된 방법도 배운다. 초기에 틀린 스킬이 저장되면 이후 작업까지 계속 영향을 준다. 생성된 스킬 파일을 주기적으로 열어 보고, 틀리거나 낡은 것은 고치거나 지우는 습관이 필요하다.

메모리에 대화 내용이 계속 쌓이므로 비밀번호나 키 같은 민감한 정보는 대화에 넣지 않는 편이 안전하다. 서버에서 돌린다면 에이전트가 실행할 수 있는 명령의 범위도 미리 제한해 두는 게 좋다.
