n8n (nodemation)

n8n은 노드를 끌어다 연결해서 업무 자동화와 AI 에이전트를 만드는 워크플로우 도구다. 여러 서비스를 잇는 반복 작업을 자동화하고 싶을 때, 특히 데이터를 내 서버에 두고 돌리고 싶을 때 쓴다.

한눈에 보기

n8n은 '이 일이 생기면 저걸 한다'는 자동화를 캔버스 위에 노드를 이어서 만드는 도구다. 코드 없이 시작할 수 있고, 필요하면 노드 안에 코드를 넣을 수 있다. 내 서버에 직접 설치할 수 있다는 점이 Zapier 같은 서비스와 가장 크게 다르다.

방식장점약점
n8n셀프호스팅 가능, 코드 노드로 확장직접 설치하면 관리 부담
Zapier·Make가입만 하면 바로 사용클라우드 전용, 데이터가 외부로 나감
직접 코딩자유도 최고만들고 고치는 데 시간이 듦

설치는 클라우드 또는 명령 한 줄

가장 쉬운 길은 유료 n8n Cloud에 가입하는 것이다. 직접 돌리려면 Node.js가 있는 PC에서 npx n8n을 실행하거나 Docker 이미지 n8nio/n8n을 띄운 뒤, 브라우저에서 localhost:5678로 들어가면 편집 화면이 열린다.

개인 실험은 로컬에서, 팀이 매일 쓰는 자동화는 서버나 클라우드에서 돌리는 게 좋다. 로컬 PC는 꺼지면 자동화도 멈춘다.

트리거 하나에 노드를 이어 붙인다

모든 워크플로우는 시작 신호인 트리거에서 출발한다. 그 뒤에 서비스 노드를 순서대로 붙이고, 연결 노드가 없는 서비스는 HTTP Request 노드로 API를 직접 부른다.

노드역할이럴 때 쓴다
Schedule·Webhook시작 신호매일 아침 실행, 외부 요청 받기
Gmail·Slack 등서비스 연결메일 읽기, 알림 보내기
HTTP Request아무 API 호출전용 노드가 없을 때
CodeJavaScript·Python 실행데이터 가공이 복잡할 때

AI 에이전트는 노드 세 개로 시작

Chat Trigger로 질문을 받고, AI Agent 노드에 OpenAI·Claude·Gemini 같은 모델을 연결한 뒤, 도구 노드를 붙이면 된다. 에이전트는 질문을 보고 어떤 도구를 쓸지 스스로 고른다. 메모리 노드를 더하면 이전 대화를 기억하고, MCP 클라이언트 노드로 MCP 서버의 도구도 쓸 수 있다.

예를 들어 메일이 오면 AI가 분류해 급한 건 Slack으로 알리고, 고객 문의는 답장 초안을 만들어 Google Sheets에 적는 흐름을 한 캔버스에 담을 수 있다. 처음에는 공식 템플릿을 불러와 고쳐 쓰는 게 빠르다.

셀프호스팅은 관리도 내 몫

직접 설치하면 업데이트, 백업, 보안 설정을 스스로 챙겨야 한다. 저장된 로그인 정보는 암호화 키로 보호되므로 서버를 옮길 때 이 키를 잃어버리면 안 된다.

라이선스는 소스를 공개한 fair-code 방식이다. 회사 내부 업무에 쓰는 건 자유롭지만, n8n 자체를 유료 서비스로 다시 파는 건 제한되니 상업용으로 쓸 때는 약관을 확인한다. 에이전트 로직이 복잡해지면 노드가 금방 많아지므로, 작게 나눠 만드는 게 좋다.
