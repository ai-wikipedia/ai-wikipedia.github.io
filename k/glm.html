GLM (Zhipu AI)

중국 Zhipu AI(Z.ai)가 MIT 라이선스로 공개하는 오픈소스 언어 모델 계열이다. 코딩·에이전트 작업을 싸게 돌리거나, 데이터를 밖으로 보내지 않고 직접 호스팅해야 할 때 쓴다.

한눈에 보기

GLM(General Language Model)은 중국 스타트업 Zhipu AI가 만드는 대규모 언어 모델 계열이다. 회사는 2025년 해외용 브랜드를 Z.ai로 바꿨다. 가장 큰 특징은 모델 파일을 MIT 라이선스로 통째로 공개한다는 점이다. 그래서 내 컴퓨터나 회사 서버에 올려 직접 돌릴 수 있다. 코딩과 에이전트 작업을 싸게 맡기고 싶을 때 주로 고른다.

항목GPT·Claude 같은 폐쇄형GLM
쓰는 방식회사 서버로만모델 파일을 받아 직접
내 데이터로 추가 학습어려움파인튜닝 가능
성능최상위상위권, 코딩·에이전트에 강함

GLM-4.5, 4.6, 4.7을 거쳐 최신 GLM-5까지 코딩과 에이전트 쪽으로 발전해 왔다. 덩치는 큰 편이지만, 답을 낼 때마다 모델의 일부만 써서 돌리는 비용을 낮췄다.

Claude Code에서 모델 이름만 바꾼다

가장 흔한 쓰임은 저렴한 AI 코딩이다. GLM은 Claude API와 호환되게 만들어져서, Claude Code의 ~/.claude/settings.json에서 모델 이름만 "GLM-5" 같은 값으로 바꾸면 쓰던 도구를 그대로 쓰면서 비용을 크게 줄일 수 있다.

Z.ai의 코딩 구독 플랜이나 api.z.ai 엔드포인트를 OpenClaw, OpenCode 같은 에이전트 도구에 연결해 쓰는 방법도 있다.

내 서버나 PC에서 직접 돌린다

모델 파일이 공개돼 있어서 상황에 맞게 실행 방법을 고르면 된다. 데이터를 외부로 보내면 안 되는 환경이거나, 우리 코드베이스에 맞춰 파인튜닝하고 싶을 때 폐쇄형 API 대신 쓴다.

방법도구이럴 때
서버에서 서빙vLLM, SGLang팀이 함께 쓰는 사내 모델
로컬 구동Ollama, LM Studio양자화 버전을 내 PC에서
경량 버전GLM-4.7-Flash (30B급)일반 PC에서 가성비 있게

"근접"이지 "동등"은 아니다

벤치마크 점수가 Claude Opus 같은 최상위 모델에 가깝다는 것이지, 모든 작업에서 같은 수준은 아니다. 영어권의 미묘한 추론이나 최신 도구 연동에서는 차이가 날 수 있으니, 실제 작업 흐름에 넣기 전에 직접 테스트해 보는 게 좋다.

또 GLM은 통계학의 일반화 선형 모형(Generalized Linear Model)을 뜻하기도 해서, 검색할 때 헷갈리지 않게 주의한다.
