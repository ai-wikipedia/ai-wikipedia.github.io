GPT

Generative Pre-trained Transformer

GPT는 OpenAI가 만든 언어 모델 시리즈로, 많은 글을 미리 배워 둔 뒤 다음 단어를 하나씩 이어 쓰는 방식으로 답을 만든다. 대화·글쓰기·코딩처럼 말로 일을 시키는 거의 모든 작업에 쓰이고, 지금 쓰이는 LLM 대부분의 기본 틀이 됐다.

한눈에 보기

GPT는 Generative Pre-trained Transformer의 줄임말이고, OpenAI 모델 시리즈의 이름이다. 인터넷의 방대한 글을 먼저 배워 둔 뒤, 앞 단어들을 보고 다음 단어를 하나씩 만들어 낸다. 과제마다 모델을 새로 훈련하지 않고 모델 하나에 말로 일을 시키는 방식이 GPT에서 시작됐다.

단어뜻
Generative분류·채점이 아니라 글을 만들어 낸다
Pre-trained특정 과제가 아닌 일반 글로 미리 배운다
Transformer많은 학습을 감당하는 모델 구조

클수록 새로운 능력이 생겼다

구조는 거의 그대로 두고 크기만 키웠는데, 세대마다 전에 없던 능력이 나타났다. 특히 GPT-3부터는 프롬프트에 예시 몇 개만 넣어도 새 과제를 해냈고, 여기서 프롬프트 엔지니어링이 시작됐다.

세대달라진 점
GPT-1 (2018)미리 배우고 조금만 다듬는 방식을 증명
GPT-3 (2020)예시 몇 개로 새 과제 수행
GPT-4 (2023)이미지도 입력으로 받음
GPT-5 계열답하기 전 길게 생각하는 추론, 에이전트 작업

GPT와 ChatGPT는 다르다

2022년 11월 나온 ChatGPT는 GPT 모델을 대화하기 좋게 다듬어 채팅 화면에 담은 제품이다. 이때부터 GPT가 '챗봇 AI'의 대명사처럼 쓰이면서 용어가 자주 섞인다.

용어실제 의미
GPT모델 구조이자 OpenAI 모델 시리즈 이름
ChatGPT그 모델을 채팅 화면으로 감싼 제품
커스텀 GPT모델이 아니라 프롬프트·도구를 묶어 둔 설정
OpenAI이 모두를 만든 회사

직접 쓰는 길은 두 가지

일반 사용자는 ChatGPT 화면에서 대화로 쓴다. 개발자는 OpenAI API로 모델을 불러 자기 앱에 넣는다. 그래서 "우리 서비스에 GPT를 붙였다"는 말은 보통 ChatGPT 화면을 넣었다는 뜻이 아니라 API로 모델을 호출한다는 뜻이다.

다른 LLM도 같은 틀을 따른다

GPT는 원래 트랜스포머에서 글을 만드는 쪽(디코더)만 떼어 써서 키우기 쉽게 만들었다. 지금 주요 LLM은 거의 모두 이 구조를 쓰고, 미리 배운 뒤 사람 피드백(RLHF)으로 태도를 다듬는 방식도 같다. 문헌에서 보이는 '디코더-온리', '자기회귀 모델'도 결국 이런 GPT류 모델을 가리킨다. 이해 전용인 BERT 계열과는 반대쪽이다.
