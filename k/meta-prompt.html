메타 프롬프트

Meta-Prompt

LLM에게 좋은 프롬프트를 대신 써 달라고 요청하는 프롬프트다. 시스템 프롬프트 초안을 빠르게 만들거나 이미 쓴 프롬프트를 다듬을 때 쓴다.

한눈에 보기

메타 프롬프트는 "이 작업에 맞는 프롬프트를 써 줘"라고 LLM에게 부탁하는 프롬프트를 만드는 프롬프트다. 빈 화면에서 시스템 프롬프트를 처음 써야 할 때 초안을 빨리 얻거나, 이미 쓴 프롬프트를 고칠 때 쓴다. 사람이 처음부터 직접 쓰는 방식과 자동 최적화 도구의 중간쯤에 있다.

방식하는 일이럴 때
직접 작성사람이 처음부터 쓴다짧고 단순한 지시
메타 프롬프트LLM이 초안을 써 준다새 챗봇·에이전트의 첫 시스템 프롬프트
자동 최적화 (DSPy 등)평가 데이터로 프롬프트를 반복해서 개선한다정답 예시가 많고 성능을 수치로 잴 수 있을 때

콘솔 버튼이나 채팅창 한 줄로 시작한다

Anthropic의 Claude Console에는 원하는 작업을 설명하면 시스템 프롬프트를 만들어 주는 프롬프트 생성기가 있고, OpenAI Playground에도 비슷한 생성 기능이 있다. 이런 도구가 없어도 일반 채팅창에서 "다음 작업용 시스템 프롬프트를 써 줘"라고 요청하면 된다.

요청에 아래 내용을 담을수록 초안이 좋아진다.

넣을 내용예시 (고객 지원 챗봇)
작업과 대상전자제품 고객 지원, 일반 소비자
말투공감하면서도 기술적으로 정확하게
지켜야 할 규칙환불 정책은 문서에 적힌 대로만 안내
출력 형식짧게, 필요하면 단계별로 안내

초안, 테스트, 다시 요청 순서로 돌린다

받은 초안을 바로 쓰지 말고, 실제로 들어올 만한 질문 몇 개를 넣어 돌려 본다. 엉뚱한 답이 나오면 그 입력과 출력을 붙여서 "이런 경우를 잘 처리하도록 프롬프트를 고쳐 줘"라고 다시 메타 프롬프트를 쓴다. 기존 프롬프트를 넣고 개선만 부탁하는 것도 같은 방식이다.

언제 쓰고 언제 안 쓰나

상황메타 프롬프트이유
긴 시스템 프롬프트의 첫 초안추천구조를 잡고 빠진 항목을 채워 준다
기존 프롬프트 개선추천모호한 지시를 찾아 고쳐 준다
한두 줄짜리 간단한 질문불필요직접 쓰는 게 더 빠르다
사내 정책·전문 지식이 핵심보조로만모델이 모르는 사실을 지어낼 수 있다

그럴듯한 초안일 뿐이다

생성된 프롬프트는 길고 그럴듯해 보이지만, 실제로 잘 작동하는지는 따로 확인해야 한다. 필요 없는 지시가 많으면 오히려 모델이 헷갈릴 수 있으니 테스트하면서 덜어낸다.

정책 문구나 상품 정보처럼 정확해야 하는 내용은 사람이 직접 넣는다. 같은 프롬프트라도 모델마다 반응이 다르므로, 테스트는 실제로 쓸 모델로 해야 한다.
