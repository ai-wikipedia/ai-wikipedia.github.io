딥시크 V4

DeepSeek V4

중국 DeepSeek가 만든 오픈웨이트 언어 모델로, 100만 토큰의 긴 맥락을 아주 싸게 처리한다. 큰 코드베이스를 다루는 코딩 도구나 오래 도는 에이전트에 비용을 아끼면서 쓰기 좋다.

한눈에 보기

DeepSeek V4는 중국 DeepSeek가 2026년 4월에 공개한 언어 모델이다. 가중치가 MIT 라이선스로 공개돼 있어 누구나 내려받아 직접 돌릴 수 있다. 가장 큰 장점은 긴 맥락을 싸게 처리한다는 점이라, 큰 코드베이스나 긴 문서를 통째로 넣어야 할 때 쓰기 좋다.

모델위치이럴 때 쓴다
V4-Pro최상위복잡한 추론, 코딩 에이전트
V4-Flash경량·저렴빠른 응답, 대량 처리

책 여러 권 분량도 한 번에 넣는다

한 번에 100만 토큰까지 넣을 수 있다. 책 여러 권이나 큰 코드베이스를 통째로 넣을 수 있는 양이다. 입력을 압축해서 읽는 방식 덕분에, 같은 길이를 처리할 때 이전 세대보다 계산과 메모리가 훨씬 적게 든다.

V3.2 계산량100%
V4 계산량27%
V4 메모리 캐시10%

100만 토큰 길이 기준으로 V3.2를 100%로 놓은 값이다.

내 컴퓨터에서도, API로도 쓴다

직접 돌리려면 ollama run deepseek-v4-pro:cloud처럼 Ollama로 바로 띄우거나, vLLM·SGLang으로 서빙하면 된다. 클라우드에서 쓰려면 DeepSeek 공식 API(deepseek-ai/DeepSeek-V4-Pro)나 Together AI, NVIDIA NIM 같은 호스팅 업체로 호출한다.

Cursor·Kilo Code 같은 코딩 도구에 백엔드 모델로 연결해 쓰는 경우가 많다. 도구를 계속 호출하며 오래 도는 에이전트는 토큰이 빠르게 쌓이는데, 이럴 때 V4가 비용을 크게 줄여 준다. 어려운 설계나 추론은 Pro에, 단순 반복 작업은 Flash에 맡기면 된다.

성능은 최상위권, 가격은 몇 분의 일

코딩, 어려운 과학 추론, 실제 깃허브 이슈를 고치는 에이전트 과제에서 상위권 성적을 냈다. 그런데도 출력 100만 토큰당 몇 달러 수준이라, 서구권 상용 모델 가격의 몇 분의 일밖에 안 된다.

검열과 성능 검증은 따져 봐야 한다

중국 정치와 관련된 주제에는 답을 제한하는 검열이 들어 있다. 공개된 성능 점수와 미국 NIST 산하 기관 같은 제3자의 독립 평가 결과가 다르다는 지적도 있다. 쓰기 전에 내가 실제로 맡길 작업으로 직접 시험해 보는 게 좋다.
