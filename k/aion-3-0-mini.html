Aion-3.0-Mini (AionLabs)

Aion 3.0 Mini는 AionLabs가 롤플레이·스토리텔링용으로 만든 Aion 3.0의 경량 버전이다. 컨텍스트 길이는 풀 모델과 같고 가격은 약 1/4이라, 캐릭터 채팅이나 이야기 생성 앱을 싸게 만들 때 쓴다.

한눈에 보기

Aion 3.0 Mini는 AionLabs의 롤플레이·스토리텔링 특화 모델 Aion 3.0을 가볍고 싸게 줄인 버전이다. 여러 모델이 함께 답을 만드는 협업 생성 구조와 GLM 계열 기반 설계는 그대로 이어받았다. 컨텍스트 길이와 출력 한도는 풀 모델과 같고 가격은 약 1/4이라, 캐릭터 채팅이나 이야기 생성 앱을 만들 때 먼저 고를 만하다.

항목Aion 3.0Aion 3.0 Mini
컨텍스트131,072 토큰같음
최대 출력32,768 토큰같음
가격 (입력/출력)$3 / $6$0.7 / $1.4
이럴 때 쓴다품질이 가장 중요한 장면대량 대화, 프로토타입

가격은 100만 토큰 기준이다.

긴 대화는 그대로, 값은 1/4

롤플레이는 대화가 길어질수록 매 턴마다 앞의 내용을 다시 보내야 해서 토큰이 빠르게 쌓인다. Mini는 같은 길이의 대화를 훨씬 싸게 이어 갈 수 있다.

Aion 3.0$6
Aion 3.0 Mini$1.4

출력 100만 토큰당 가격. Mini의 캐시 읽기는 $0.18이다.

캐릭터 설정이나 세계관처럼 매번 똑같이 앞에 붙는 내용은 캐시가 적용되면 더 싸게 처리된다. 그래서 고정 설정이 긴 앱일수록 아끼는 비용이 커진다.

OpenAI 호환 API라 모델 이름만 바꾸면 된다

OpenAI 호환 API로 제공되므로 기존 OpenAI SDK 코드에서 접속 주소(base URL)와 모델 이름만 바꿔 붙이면 된다. OpenRouter나 Puter 같은 서비스에서는 aion-labs 제공 모델로 찾을 수 있다. 추론(reasoning) 기능도 지원한다.

작업추천이유
캐릭터 채팅 일반 턴Mini대화 수가 많아 비용이 핵심
장편 스토리 초안Mini출력 한도가 같아 긴 글도 가능
여러 인물이 얽힌 핵심 장면풀 모델세밀한 묘사에서 차이가 날 수 있음

처음에는 Mini로 개발하고, 품질이 아쉬운 부분만 풀 모델로 바꾸는 순서가 실용적이다.

세밀한 묘사는 직접 비교해 본다

경량 모델이라 등장인물이 많은 복잡한 서사나 섬세한 감정 표현에서는 풀 모델보다 품질이 떨어질 수 있다. 내 앱의 실제 대화 몇 개로 두 모델을 나란히 돌려 보고 정하는 게 가장 확실하다.

창작에 특화된 모델이라 코딩이나 정확한 사실 확인이 중요한 작업에는 범용 모델을 쓰는 편이 안전하다.
