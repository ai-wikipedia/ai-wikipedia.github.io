클로드 소네트 5

Claude Sonnet 5 (Anthropic)

Anthropic이 2026년 공개한 Sonnet 5세대 모델로, Sonnet 가격대에서 Opus에 가까운 성능을 내도록 설계된 에이전트 특화 모델이다. 2026년 9월 후속인 클로드 소네트 5.5가 나오면서 이전 세대 모델이 됐다.

Opus에 가까운 일을 Sonnet 값에

Claude Sonnet 5는 Anthropic이 2026년 6월 30일 내놓은 중간 등급 모델이다. Claude 라인업은 가장 강하고 비싼 Opus, 빠르고 싼 Haiku, 그 사이의 Sonnet으로 나뉘는데, Sonnet 5의 목표는 위쪽 Opus와의 간격을 좁히는 것이었다. Anthropic은 이 모델을 '가장 에이전틱한 Sonnet'이라고 소개했다. 계획을 세우고, 브라우저와 터미널 같은 도구를 쓰고, 사람이 일일이 지시하지 않아도 긴 작업을 이어가는 능력이 당시 최상위 모델 Opus 4.8에 근접했다는 뜻이다. 출시와 동시에 claude.ai 무료·Pro 요금제의 기본 모델이 됐다.

가격과 스펙에서 달라진 점

API 가격은 입력 100만 토큰당 2달러, 출력 10달러다. 처음엔 도입 할인가로 발표됐다가 8월에 정식 가격으로 굳어졌는데, 같은 시기 Opus 4.8은 5달러와 25달러였다. 직전 Sonnet 4.6(3달러, 15달러)보다 오히려 싸진 셈이다. 반복되는 시스템 프롬프트를 캐시해 두면 캐시 읽기는 100만 토큰당 0.2달러로 떨어지고, 급하지 않은 대량 작업을 배치 API로 돌리면 입출력 모두 절반 가격이다. 다만 토크나이저가 바뀌어 같은 입력이 Sonnet 4.6보다 최대 1.35배 많은 토큰으로 계산될 수 있으니, 실제 청구액은 자기 프롬프트로 직접 재봐야 한다. 문맥 길이는 100만 토큰, 최대 출력은 12만 8천 토큰이며 텍스트와 이미지를 입력으로 받는다.

생각하는 방식도 바뀌었다. 예전처럼 생각에 쓸 토큰 수를 고정 예산으로 정해 주는 대신, 모델이 문제 난도에 따라 얼마나 생각할지 스스로 정하는 적응형 사고(adaptive thinking)를 쓰고, 개발자는 effort 파라미터로 그 깊이를 조절한다. 단계는 low부터 max까지 다섯 가지이고 기본값은 high다. 그 대신 temperature나 top_p 같은 샘플링 값을 기본값이 아닌 값으로 보내면 오류가 난다.

개발자가 쓰는 자리

API 모델 ID는 claude-sonnet-5이고, Amazon Bedrock에서는 anthropic.claude-sonnet-5, Google Cloud와 Microsoft Foundry에서는 같은 이름으로 부른다. 가장 자연스러운 자리는 Claude Code 같은 에이전트의 일꾼 역할이다. 기획과 까다로운 설계 판단은 Opus에 맡기고, 파일 탐색이나 테스트 작성처럼 양이 많은 하위 작업은 Sonnet 5 서브에이전트에 나눠 주면 비용을 크게 줄이면서 품질을 유지할 수 있다. effort도 작업별로 나누는 게 요령이다. 일상적인 기능 구현은 medium, 버그 원인을 끝까지 파고드는 작업은 high 이상으로 두는 식이다.

써본 사람들이 말하는 장단점

코드 리뷰 도구를 만드는 CodeRabbit의 평가는 이 모델의 성격을 잘 보여준다. Sonnet 5는 테스트를 먼저 쓰고 직접 돌려본 뒤에야 완료를 보고하며, 길고 열린 작업에서 계획을 고쳐 가며 끈질기게 파고든다. 리뷰 코멘트가 실제 버그를 가리키는 비율도 Sonnet 4.6보다 올랐다. 반면 4.6보다 느리고 토큰을 더 쓰며, 작은 요청에도 보조 함수와 긴 테스트 파일을 덧붙이는 과잉 구현 경향이 있다. 버그를 빠짐없이 잡아내는 비율은 오히려 4.6이 더 높았고, effort를 최대로 올리는 건 비용 대비 효율이 가장 나빴다. 중간 정도 effort에서 이점의 대부분을 얻는다는 게 결론이다.

안전 설계와 지금의 위치

Anthropic의 출시 전 평가에서 Sonnet 5는 Sonnet 4.6보다 악의적인 요청을 더 잘 거절하고 프롬프트 인젝션에 더 잘 버티며, 환각과 아첨하는 답변도 줄었다. 외부 웹페이지나 이슈 본문을 읽으며 일하는 에이전트에 붙일 때 의미 있는 개선이다. 사이버보안 작업은 따로 학습하지 않아서 위험한 해킹 능력 평가에서 Opus 4.8보다 확연히 낮은 수준이다. 출시 때부터 사이버 안전장치가 기본으로 켜져 있어 정당한 보안 작업 요청이 거절되기도 하는데, Anthropic은 안전장치가 완화된 환경이 필요한 보안 작업에는 Opus 4.8을 권한다. 그리고 2026년 9월 말 후속작 Claude Sonnet 5.5가 같은 가격으로 나오면서 Sonnet 5는 레거시 모델로 분류됐다. 2027년 6월 30일 이전에는 종료되지 않으므로 기존 시스템은 그대로 돌려도 되지만, 새로 시작한다면 5.5와 함께 비교해 보는 게 맞다.
