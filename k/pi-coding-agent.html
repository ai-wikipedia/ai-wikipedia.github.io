Pi Minimal Terminal Coding Agent

Pi는 읽기·쓰기·편집·bash 네 가지 도구만 가지고 시작하는 오픈소스 터미널 코딩 에이전트다. 필요한 기능은 TypeScript 확장으로 직접 붙여 쓰기 때문에, 내 작업 방식에 맞춘 에이전트를 만들고 싶을 때 쓴다.

한눈에 보기

Pi는 Mario Zechner가 2025년 말에 만든 최소한의 코딩 에이전트 하네스로, 지금은 Earendil이 관리한다. 기본으로 주는 도구는 파일 읽기·쓰기·편집과 bash 네 가지뿐이고, 시스템 프롬프트도 짧다. 다른 에이전트에 기능이 너무 많아 무겁다고 느끼거나, 모델을 자유롭게 바꾸고 싶을 때 고르는 도구다. OpenClaw의 핵심 엔진으로도 쓰인다.

항목일반 코딩 에이전트Pi
기본 도구수십 개4개 (read, write, edit, bash)
서브에이전트·플랜 모드내장없음, 필요하면 직접 만든다
권한 확인 팝업있음없음, 컨테이너나 확장으로 대신한다
모델 선택한 회사 모델 위주여러 회사 모델, 로컬 모델

도구가 적어도 되는 이유

만든 사람은 tmux에 키 입력만 보내는 단순한 에이전트가 터미널 작업 벤치마크 상위권에 오른 것을 보고, 도구를 많이 주지 않아도 된다고 판단했다. GitHub 작업도 전용 도구를 따로 두지 않고 gh CLI를 bash로 부르게 하면 된다. 모델이 이미 아는 CLI를 쓰게 하면 도구 설명이 컨텍스트를 차지하지 않는다.

설치하고 바로 쓰는 법

Node.js 22.19 이상이 필요하고, npm install -g --ignore-scripts @earendil-works/pi-coding-agent로 설치한다. 작업할 폴더에서 pi를 실행하면 된다. Claude Pro나 GitHub Copilot 구독이 있으면 /login으로 연결해 API 비용 없이 쓸 수 있고, API 키나 로컬 모델도 붙일 수 있다.

하고 싶은 일명령
지난 세션 이어 하기 / 세션 목록 보기pi -c / pi -r
스크립트에서 한 번만 실행pi -p "프롬프트"
작업 중 모델 바꾸기/model 또는 Ctrl+L
셸 명령 직접 실행!명령어

필요한 기능은 확장으로 키운다

TypeScript 확장, 스킬, 프롬프트 템플릿, 테마로 기능을 더하고, 이것들을 묶은 Pi 패키지를 npm이나 git으로 공유한다. 확장은 슬래시 명령뿐 아니라 진행 표시줄, 파일 선택기, 표 같은 TUI 화면도 그릴 수 있다. 서브에이전트가 필요하면 tmux로 Pi를 여러 개 띄우거나, 남이 만든 패키지를 설치하면 된다. 앱에 넣을 때는 interactive, print/JSON, RPC, SDK 네 가지 모드 중 하나를 고른다.

쓰기 전에 알아둘 점

권한 팝업이 없어서 에이전트가 명령을 바로 실행한다. 중요한 저장소라면 컨테이너 안에서 돌리거나 확인 절차를 확장으로 직접 만들어야 한다. MCP는 처음에 일부러 빼 두었다가 지금은 기본으로 들어갔으니, 오래된 글을 읽을 때는 이 차이에 주의한다. 새 기여자가 올린 이슈와 PR은 자동으로 닫히고, 관리자가 나중에 검토한다.
