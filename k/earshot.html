이어샷

Earshot (Audio Analysis for Coding Agents)

이어샷은 코딩 에이전트에게 귀를 달아 주는 오픈소스 도구로, 에이전트가 만든 효과음이나 영상 속 소리를 듣고 어떤 소리인지 설명한 뒤 점수와 고칠 점을 돌려준다. 소리를 코드로 만들 수는 있어도 들어 볼 수 없던 에이전트가 결과를 의도대로 다듬을 때 쓰며, GPU 없이 CPU만으로 내 컴퓨터에서 돌아간다.

기능하는 일이럴 때 쓴다
듣기(분석)소리를 말로 설명하고, 설명과 얼마나 맞는지 점수를 매긴다만든 효과음이 의도대로인지 확인
구간별 피드백문제가 있는 구간마다 시간 위치와 수정 방법을 알려 준다렌더링한 영상의 오디오 다듬기
earshot forge코드로 소리를 만들고 들어 보며 고친다효과음을 직접 합성
fit녹음을 수정할 수 있는 Python 레시피로 바꾼다기존 소리를 코드로 재현·변형

두 모델이 나눠서 듣는다

분석은 두 갈래로 이뤄진다. 한쪽은 소리를 이미지 같은 스펙트로그램으로 바꿔 길이나 크기 같은 물리적인 값을 잰다. 다른 쪽(CLAP)은 '짧게 유리 깨지는 소리' 같은 글 설명과 오디오가 얼마나 맞는지 비교하고, 다르게 들릴 수 있는 해석도 함께 내놓는다. 그래서 파일 이름이나 자막이 아니라 실제 소리를 근거로 판단한다.

에이전트 루프에는 MCP 서버로 붙인다

쓰는 방법은 CLI, Python API, MCP 서버 세 가지다. 소리를 한 번만 확인할 때는 CLI로 충분하다. 에이전트가 계속 만들고 고치는 작업이라면 MCP 서버를 띄워 두는 편이 낫다. 서버가 계속 켜져 있어서 호출할 때마다 모델을 다시 불러오느라 기다리지 않아도 된다.

흐름은 이렇다. 에이전트가 효과음 코드를 짜서 렌더링하면, 이어샷이 점수와 구간별 문제점을 돌려준다. 에이전트는 그걸 보고 코드를 고친 뒤 다시 듣게 한다. 사람이 매번 들어 보지 않아도 1차 검수가 돌아간다.

쓰기 전에 알아 둘 점

주의할 점내용
처음 실행 비용모델 캐시를 받는 시간과 시작 시간이 든다
fit 결과의 권리원본 녹음에서 뽑은 레시피는 법적으로 원본에 묶일 수 있다
최종 판단만들어진 소리는 사람이 직접 들어 보고 확정한다
이름이 같은 다른 것소리 포렌식 비영리단체 Earshot, 게임 아머드 코어의 무기와는 관계없다

소리 작업의 1차 검수를 에이전트에게 맡긴다

가장 흔한 방식은 코딩 에이전트의 검수 도구로 붙여 두는 것이다. 에이전트가 소리를 만들 때마다 이어샷으로 들어 보게 하고, 사람은 마지막에 통과한 결과만 직접 들어 확정한다.

어디서어떻게 쓰나
효과음 합성earshot forge로 코드로 소리를 만들고, 점수가 오를 때까지 들어 보며 고친다
영상·제품 데모 제작렌더링한 영상의 오디오를 구간별 피드백으로 점검하고 문제 구간만 다시 손본다
기존 녹음 재현fit으로 녹음을 Python 레시피로 바꿔 길이·음색을 코드로 조정한다
빠른 단일 확인CLI로 파일 하나를 들려 보고 설명과 맞는 소리인지만 확인한다
