큐원

Qwen

Alibaba Cloud가 만들어 가중치를 공개한 LLM 시리즈다. 무료로 받아 내 컴퓨터나 서버에서 돌리고 싶을 때, 그리고 코딩·이미지 이해·음성 같은 특화 모델이 필요할 때 쓴다.

한눈에 보기

Qwen은 Alibaba Cloud가 만든 오픈 웨이트 LLM 시리즈다. 모델 파일을 직접 받아 내 장비에서 돌릴 수 있고, 대부분 Apache 2.0 라이선스라서 상업적으로도 쓸 수 있다. 중국어와 영어를 중심으로 여러 언어를 잘 다루고, 노트북용 소형부터 서버용 대형까지 크기가 다양하다.

변형이럴 때 쓴다
Qwen (기본)대화, 문서 요약, 일반 업무
Qwen-Coder코드 생성, 코딩 도구 백엔드
Qwen-VL이미지·문서 사진 이해
Qwen-Math수학 풀이
Qwen-TTS음성 합성 (한국어 포함)

쓰는 방법은 세 가지

가장 쉬운 방법은 웹 채팅(Qwen Chat)에서 바로 써 보는 것이다. 내 PC에서 돌리려면 Ollama에서 ollama run qwen3처럼 한 줄로 실행하면 된다. 서버에 올려 여러 사람이 쓰게 하려면 Hugging Face에서 모델을 받아 vLLM으로 vllm serve Qwen/Qwen3-8B처럼 띄운다.

직접 운영하기 번거로우면 Alibaba Cloud의 API로 부를 수도 있다. OpenAI 방식과 호환되는 주소를 제공해서, 기존 코드의 주소와 모델 이름만 바꿔 연결할 수 있다.

크기는 장비에 맞춰 고른다

크기가 클수록 똑똑하지만 메모리가 많이 든다. 먼저 작은 모델로 시작해 품질이 부족할 때 한 단계씩 올리는 게 비용을 아끼는 방법이다. Qwen3에는 전체는 크지만 답할 때 일부만 쓰는 MoE 모델도 있어, 큰 모델 치고 빠르다.

크기어디서맞는 작업
소형 (수십억 미만)노트북, 휴대기기분류, 간단한 추출
중형 (8B~32B)GPU 한 장사내 챗봇, 코딩 보조
대형 MoE여러 GPU 서버어려운 추론, 긴 문서 분석

생각 모드를 켜고 끈다

Qwen3는 한 모델 안에서 깊게 생각하는 모드와 바로 답하는 모드를 오갈 수 있다. 수학·디버깅처럼 어려운 질문은 생각 모드를 켜고, 번역이나 짧은 답은 끄면 응답이 빨라지고 토큰도 덜 쓴다. 대화 중에는 프롬프트에 /think, /no_think를 붙여 바꿀 수 있다.

다른 오픈 모델과 비교

모델만든 곳라이선스

LlamaMeta자체 커뮤니티 라이선스

주의할 점도 있다. 모델마다 라이선스가 다를 수 있어 상업용이면 모델 페이지에서 꼭 확인한다. 정치적으로 민감한 주제는 답을 피하는 경향이 있고, 한국어 품질은 작은 모델일수록 떨어진다. 데이터를 밖으로 보내면 안 되는 일이라면 API 대신 직접 설치해 쓰는 편이 안전하다.
