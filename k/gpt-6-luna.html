GPT-6 루나

GPT-6 Luna (OpenAI)

GPT-6 루나는 OpenAI GPT-6 제품군에서 가장 빠르고 가장 싼 모델이다. 분류·추출처럼 요청이 많은 작업을 하거나, 에이전트 안에서 실제 작업을 반복해서 처리하는 역할을 싸게 맡길 때 쓴다.

한눈에 보기

GPT-6 루나는 GPT-6 세 등급 가운데 가장 작고 싼 모델이다. 판단이 필요한 일은 솔이나 아스트라에 맡기고, 많은 양을 빠르게 처리하는 일은 루나에게 넘기면 된다. 이전 세대에 있던 중간 등급 테라가 GPT-6에는 없어서, 루나와 솔의 차이가 더 뚜렷해졌다.

모델위치이럴 때 쓴다
GPT-6 아스트라최상위가장 어려운 문제, 결과 검토
GPT-6 솔주력매일 하는 실무, 작업 계획
GPT-6 루나경량분류·추출·채팅 같은 대량 작업

이렇게 쓴다

API에서는 모델 ID gpt-6-luna로 부른다. 텍스트와 이미지를 넣으면 텍스트로 답하고, 컨텍스트는 약 105만 토큰이다. 추론 강도가 여섯 단계로 나뉘어 있어서, 같은 모델이라도 요청마다 속도와 생각의 깊이를 바꿀 수 있다. Chat Completions에서 함수 호출을 쓰려면 reasoning_effort를 none으로 둬야 한다.

상황설정이유
고객 문의 수만 건 분류추론 끔빠르고 싸게 처리
버그 원인 찾기max깊게 생각하게 해서 솔급 일을 맡김
에이전트 워커작업에 맞게계획은 솔, 실제 반복 작업은 루나

Codex와 ChatGPT Work에서는 Plus·Pro·Business·Enterprise·Edu 사용자가 쓸 수 있고, Free·Go 사용자도 데스크톱 앱에서 쓸 수 있다. 출시 때 기준으로 일반 채팅 화면에서는 고를 수 없다.

가격이 절반 아래로

코딩 에이전트를 오래 돌리는 비용을 줄이려고 나온 모델이다. 이전 세대 루나보다 값이 절반도 안 된다.

GPT-5.6 루나$1.20
GPT-6 루나$0.50

출력 100만 토큰당 가격(GPT-5.6 루나는 7월 인하 뒤 가격). GPT-6 루나의 입력 가격은 $0.10이다.

요금표에서 놓치기 쉬운 규칙

같은 맥락을 반복해서 보내면 캐시 덕분에 싸지지만, 입력이 너무 길면 오히려 비싸진다. 컨텍스트가 100만 토큰이라고 해서 무조건 꽉 채우면 손해다.

조건요금
캐시된 입력입력 단가의 10%
입력이 27만 2천 토큰 넘음요청 전체에 입력 2배, 출력 1.5배
Batch·Flex (급하지 않은 일)절반
Fast 모드2배

고를 때 주의할 점

OpenAI는 루나가 어려운 코딩에서도 훨씬 비싼 모델과 비슷하다고 발표했다. 하지만 독립 평가에서는 코딩 점수가 이전 세대 루나보다 조금 낮게 나오기도 했다. 대량 분류·추출에는 확실히 잘 맞지만, 어려운 코딩을 맡길 생각이라면 내 작업으로 솔과 직접 비교해 보는 게 안전하다.
