OpenAI SDK

OpenAI 모델을 Python·TypeScript 코드에서 함수 호출처럼 부를 수 있게 해 주는 공식 라이브러리다. 내 프로그램에 채팅·이미지·음성·임베딩 기능을 붙이거나 에이전트를 만들 때 쓴다.

한눈에 보기

OpenAI SDK는 HTTP 요청을 만들고, 인증키를 넣고, 돌아온 JSON을 풀어 보는 귀찮은 일을 대신 해 주는 공식 라이브러리다. openai 패키지를 설치하고 클라이언트를 하나 만들면 채팅·이미지·음성·임베딩을 평범한 함수처럼 부를 수 있다. 공식 지원 언어는 Python과 JavaScript/TypeScript다.

패키지하는 일이럴 때 쓴다
openai모델 호출앱에 대화·이미지·음성 기능 붙이기
openai-agents에이전트 실행도구를 골라 쓰며 여러 단계로 일하는 에이전트

새 프로젝트는 responses, 기존 코드는 그대로

호출 방식은 두 가지다. 새로 시작한다면 responses를 쓰는 게 좋다. 웹 검색·파일 검색·코드 실행을 옵션 하나로 켜면 모델이 알아서 쓰기 때문에, 이런 도구를 직접 만들어 붙일 필요가 없다.

방식특징권장
client.chat.completions.create(...)모델 이름과 메시지 목록을 넘기면 답이 온다이미 짜둔 코드는 계속 써도 된다
responses검색·코드 실행 같은 도구를 옵션으로 켠다새 프로젝트

서버 주소만 바꾸면 다른 모델도 부른다

채팅 요청 형식은 사실상 업계 공용어가 됐다. 다른 회사 모델을 다루는 도구들도 "OpenAI 호환"으로 같은 모양의 요청을 받아 준다. 그래서 코드에서 서버 주소만 바꾸면 여러 모델을 같은 방식으로 부를 수 있어, 모델을 갈아탈 때 부담이 적다.

Agents SDK로 에이전트 만들기

지시문과 쓸 수 있는 도구를 묶어 에이전트를 정의하고 러너에 넘기면 된다. 그러면 모델이 도구를 부르고, 결과를 보고, 다시 판단하는 반복이 자동으로 돈다. 여기에 아래 세 기능이 더해진다.

기능하는 일
핸드오프자기가 못 하는 일을 다른 에이전트에게 넘긴다
가드레일입력과 출력이 규칙에 맞는지 동시에 검사하고, 어긋나면 바로 멈춘다
트레이싱어떤 모델과 도구를 썼는지 기록해 대시보드에서 보여 준다 (기본으로 켜짐)

에이전트가 이상하게 행동하면 트레이싱 기록부터 열어 보면 원인을 찾기 쉽다.

편한 만큼 감춰진 부분이 많다

SDK는 여러 일을 보이지 않는 곳에서 대신 처리한다. 세밀하게 제어해야 하는 복잡한 시스템이라면 SDK가 무엇을 대신 해 주는지 먼저 알고 쓰는 게 안전하다.
