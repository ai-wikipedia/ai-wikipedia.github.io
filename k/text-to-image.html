텍스트-이미지 생성

Text-to-Image

글로 쓴 설명(프롬프트)만 넣으면 AI가 새 이미지를 만들어 주는 기술이다. 직접 그리거나 사진으로 찍기 어려운 장면을 게임 에셋, UI 목업, 마케팅 소재 같은 시안으로 빨리 뽑아 볼 때 쓴다.

방식예이럴 때 쓴다
대화형 AIChatGPT 같은 채팅 서비스대화하며 고쳐 가면서 몇 장 만들 때
전용 생성 서비스Midjourney 등스타일과 완성도가 중요할 때
API·로컬 모델DALL-E API, Stability AI API, Stable Diffusion앱에 기능을 넣거나 내 환경에서 대량으로 돌릴 때

노이즈에서 시작해 그림을 다듬는다

대표적인 방식은 디퓨전(Diffusion) 모델이다. 무작위 노이즈에서 출발해 텍스트 설명에 맞게 이미지를 조금씩 다듬어 간다. 수많은 텍스트-이미지 쌍으로 학습해서 단어의 뜻을 그림으로 옮기는 법을 배웠다.

그래서 같은 프롬프트를 넣어도 돌릴 때마다 결과가 다르다. 여러 장을 뽑아서 마음에 드는 것을 고르는 게 기본 사용법이다.

프롬프트는 대상·스타일·조명·구도로 나눠 쓴다

결과물은 프롬프트에 크게 좌우된다. 그냥 "고양이"라고 쓰기보다 무엇을, 어떤 느낌으로, 어떻게 담을지 나눠 적으면 원하는 그림에 훨씬 가까워진다.

요소예시
대상창가에 앉은 회색 고양이
스타일사실적인 사진, 수채화, 3D 렌더링
조명·분위기해 질 녘의 따뜻한 빛
구도·비율클로즈업, 가로로 긴 화면

처음부터 완벽하게 쓰려고 하기보다 짧게 한 번 뽑아 보고, 마음에 안 드는 부분만 덧붙여 다시 만드는 편이 빠르다. 넣지 말아야 할 요소를 따로 적는 칸(네거티브 프롬프트)이 있는 서비스라면 그것도 같이 쓴다.

시안에는 강하고 정확한 최종본에는 약하다

잘 맞는 일피하는 게 나은 일
게임 에셋 프로토타입로고·브랜드 자산 최종본
UI 목업에 넣을 이미지글자가 많이 들어가는 포스터
마케팅 소재 초안실제 제품을 정확히 재현해야 하는 사진

이미지 속 글자, 손가락 같은 작은 부분, 여러 물체의 위치 관계는 아직도 틀리기 쉽다. 최종본으로 쓰기 전에 반드시 확대해서 확인한다.

쓰기 전에 약관과 권리부터 확인한다

상업적으로 써도 되는지, 만든 이미지의 권리가 누구에게 있는지는 서비스 약관마다 다르다. 실존 인물이나 유명 캐릭터, 특정 작가의 화풍을 흉내 내 달라고 하면 서비스가 거절하거나 저작권·초상권 문제가 생길 수 있다. 회사 기밀이 담긴 설명은 외부 서비스에 넣지 말고, 민감한 작업이라면 Stable Diffusion처럼 내 컴퓨터에서 돌릴 수 있는 공개 모델을 쓰는 방법도 있다.

최종본보다 방향 잡는 시안에 주로 쓴다

가장 흔한 방식은 여러 장을 뽑아 방향을 정하는 데 쓰는 것이다. 마음에 드는 안을 골라 사람이 다듬거나, 디자이너에게 넘길 참고 자료로 삼는다.

어디서어떻게 쓰나
게임·콘텐츠 기획캐릭터·배경 컨셉을 여러 장 뽑아 방향을 정하고, 고른 안을 바탕으로 다시 그린다
디자인·기획 문서UI 목업이나 발표 자료에 들어갈 임시 이미지를 채운다
마케팅 소재 제작광고·SNS 이미지 초안을 여러 버전 만들어 비교하고, 최종본은 사람이 손본다
앱·서비스 개발API로 이미지 생성 기능을 넣거나, 로컬 모델로 필요한 이미지를 대량으로 만든다
