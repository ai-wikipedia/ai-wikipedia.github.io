GLM 5.3 (Z.ai)

GLM 5.3은 중국 Z.ai가 내놓은 오픈 웨이트 모델로, 복잡한 코딩과 오래 걸리는 에이전트 작업에 맞춰 만들어졌다. 코딩 에이전트의 백엔드로 바꿔 쓰거나 직접 서버에 띄워 쓸 때 고른다.

한눈에 보기

GLM 5.3은 Z.ai(옛 Zhipu AI)가 2026년 8월에 공개한 오픈 웨이트 코딩·에이전트 모델이다. GLM-5.2와 같은 베이스 모델을 쓰고, 며칠짜리 실전 개발 과제를 훨씬 많이 훈련시켜 코딩 실력을 끌어올렸다. 가중치를 누구나 내려받을 수 있지만, 해킹 능력도 함께 강해져 보안 논쟁이 일고 있다.

모델특징이럴 때 쓴다
GLM-5.3전체 753B, 실제로 쓰는 건 약 40B긴 코딩 작업, 에이전트
GLM-5.3-Flash전체 320B, 활성 18B, 이미지 등 멀티모달 지원더 가볍게, 텍스트 외 입력도 다룰 때

쓰는 방법은 세 가지

가장 쉬운 건 GLM Coding Plan 구독이다. Claude Code, Cline, OpenCode, Codex 같은 코딩 에이전트에서 백엔드 모델만 GLM-5.3으로 바꿔 쓸 수 있다.

방법어떻게이럴 때
GLM Coding Plan쓰던 코딩 에이전트의 모델만 교체바로 써 보고 싶을 때
APIOpenAI SDK에서 base_url·키만 바꾸고 model="glm-5.3"기존 OpenAI 코드에 붙일 때
직접 서빙vllm serve "zai-org/GLM-5.3" 또는 SGLang내 서버에서 돌려야 할 때

NVIDIA NIM은 4비트로 줄인 버전을 서빙해서, 드물게 원본 모델과 답이 다르게 나올 수 있다.

큰 작업은 주말에 돌리면 싸다

Coding Plan은 포인트로 사용량을 계산하는데, 주말 전체를 포함한 한가한 시간대에는 포인트가 절반만 빠진다. 대규모 리팩토링이나 테스트 일괄 생성처럼 토큰을 많이 쓰는 일은 주말에 몰아서 돌리면 비용을 아낄 수 있다.

토큰을 덜 쓰고 더 잘 푼다

같은 과제를 풀 때 쓰는 출력 토큰이 이전 버전이나 경쟁 모델보다 적다. 오래 도는 에이전트일수록 이 차이가 비용으로 이어진다.

GLM-5.3 (High)약 50K
GLM-5.2약 96K
Claude Opus 4.8약 120K

과제 하나에 쓴 출력 토큰. GLM-5.3이 가장 적게 쓰고도 점수는 더 높았다. Z.ai 발표 기준.

강한 해킹 능력, 안전장치는 직접

취약점을 찾고 공격 코드를 만드는 능력이 예상보다 빨리 자랐다. Anthropic은 간단한 기법으로 안전장치를 쉽게 우회할 수 있다고 지적했고, 미국 CAISI도 오픈 웨이트 모델 중 사이버 능력이 가장 뛰어나다고 평가했다. 내 서비스 보안 점검에는 쓸모 있지만, 직접 배포한다면 용도에 맞는 안전성 평가와 가드레일을 스스로 갖춰야 한다.
