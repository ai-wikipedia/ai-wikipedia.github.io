GLM 5.3 (Z.ai)

GLM 5.3은 중국 Z.ai(옛 Zhipu AI)가 내놓은 753B 파라미터 MoE 오픈 웨이트 모델로, 복잡한 코딩과 오래 걸리는 에이전트 작업에 맞춰 만들어졌다. GLM-5.2와 같은 베이스 모델을 쓰면서 포스트 트레이닝만으로 코딩 성능을 끌어올렸고, 취약점 탐지·익스플로잇 능력도 크게 올라 보안 논쟁의 한가운데에 선 모델이다.

같은 몸, 다른 훈련으로 나온 모델

GLM 5.3은 Z.ai가 2026년 8월에 공개한 플래그십 모델이다. 특이한 점은 새 모델을 처음부터 다시 학습시키지 않았다는 것이다. 직전 버전인 GLM-5.2와 똑같은 베이스 모델을 그대로 쓰고, 성능 향상은 전부 사전학습이 끝난 뒤의 포스트 트레이닝에서 나왔다. 비유하자면 같은 신입 사원에게 더 길고 실전 같은 업무를 훨씬 많이 맡겨 경력직처럼 키운 셈이다. Z.ai는 장기 과제 환경을 이전보다 10배 늘리고, 개발 도구와 엔지니어링 워크플로우를 더 넓게 쓰게 했다. 일부 학습 과제는 버그를 찾고, 수정안을 쓰고, 코드를 짜고, 테스트를 돌려 결과를 내놓는 소프트웨어 개발 전 과정을 흉내 냈고, 과제 하나가 시니어 엔지니어의 며칠치 업무량에 맞먹었다고 한다.

그 결과 Z.ai 자체 벤치마크인 Z.ai Code Bench에서 GLM-5.2보다 50% 높은 점수를 냈고, Terminal Bench 3.0과 Agents' Last Exam에서는 오픈 웨이트 모델 중 최고 성적을 기록했다. 토큰 효율도 좋아졌다. Max effort에서 GLM-5.3은 과제당 약 75K 출력 토큰으로 34.5%를 달성했는데, GLM-5.2는 96K 토큰을 쓰고 23.4%에 그쳤다. High effort에서는 약 50K 토큰으로 31.4%를 기록해, 120K 토큰을 쓴 클로드 오퍼스 4.8(29.5%)보다 적은 토큰으로 더 높은 점수를 냈다.

개발자가 실제로 붙여 쓰는 방법

가장 빠른 길은 Z.ai의 GLM Coding Plan이다. 이 구독으로 Claude Code, Cline, OpenCode, Codex 같은 코딩 에이전트의 백엔드 모델을 GLM-5.3으로 바꿔 쓸 수 있다. 새 플랜은 포인트 기반 쿼터를 쓰고, 주말 전체를 포함한 비혼잡 시간대에는 포인트가 절반만 차감된다. 그래서 대규모 리팩토링이나 테스트 일괄 생성처럼 토큰을 많이 먹는 작업은 주말에 몰아 돌리는 식으로 비용을 아낄 수 있다.

API는 OpenAI 호환이라 기존 OpenAI SDK 코드에서 base_url과 API 키만 바꾸고 model="glm-5.3"을 지정하면 된다. 가중치는 출시 2주 뒤 안전성 평가와 보강을 마치고 Hugging Face의 zai-org/GLM-5.3으로 풀렸다. 직접 띄우려면 vllm serve "zai-org/GLM-5.3"이나 SGLang의 sglang.launch_server로 OpenAI 호환 서버를 열면 된다. NVIDIA NIM에서는 4비트 NVFP4로 양자화한 체크포인트를 서빙하는데, 극단적인 경우 원본 정밀도 모델과 출력이 다를 수 있다는 점은 알고 써야 한다.

753B인데 40B만 움직이는 구조

구조는 희소 MoE 트랜스포머다. 전체 파라미터는 753B지만 토큰 하나를 처리할 때 실제로 쓰는 건 약 40B뿐이다. 디코더 레이어는 78개로, 앞의 3개는 일반 dense MLP이고 나머지 75개가 MoE 레이어다. MoE 레이어마다 256개의 전문가가 있고, 그중 8개를 골라 쓰는 top-8 라우팅에 항상 켜져 있는 공유 전문가 1개가 더해진다. 어텐션은 DeepSeek Sparse Attention 방식이라, 인덱서가 쿼리마다 2,048개 토큰만 골라 주의를 기울인다. 긴 컨텍스트에서도 모든 토큰을 다 보지 않으니 연산량이 줄어든다. 여기에 여러 토큰을 미리 예측하는 MTP 레이어 1개가 붙어 있다. 함께 나온 GLM-5.3-Flash는 계열이 다르다. 새로 학습한 베이스 모델 위에 희소 어텐션과 선형 어텐션을 섞은 하이브리드 구조를 처음 도입했고, 총 320B에 활성 18B로 GLM-5.3 시리즈 최초의 네이티브 멀티모달 모델이다.

예상보다 빨리 자란 해킹 능력

Z.ai 스스로도 포스트 트레이닝을 늘리면서 사이버 능력이 예상보다 빨리 자랐다고 밝혔다. 취약점 발견 벤치마크 CyberGym에서 84.5%를 기록해 GLM-5.2의 77.2%를 크게 넘었고, Z.ai 발표 기준으로 Mythos 5(83.8%)와 GPT-5.6 Sol(83.6%)을 근소하게 앞섰다. 익스플로잇 단계로 갈수록 격차가 커져, 익스플로잇 벤치마크에서는 GLM-5.2의 두 배 이상을 냈다. Z.ai는 모델이 찾은 취약점을 정리하는 Security Disclosure Ledger를 만들어, 영향받은 프로젝트와 심각도, CVE 번호, 공개 여부를 공개 기록으로 관리하고 있다.

문제는 이 능력이 열린 가중치로 풀렸다는 점이다. Anthropic은 분석 보고서에서 GLM-5.3이 비슷한 수준의 다른 모델과 달리 의미 있는 안전장치 없이 공개됐고, 간단한 기법으로 64~100% 확률로 안전장치를 우회할 수 있었다고 지적했다. NIST 산하 CAISI도 GLM-5.3을 지금까지 나온 오픈 웨이트 모델 중 사이버 능력이 가장 뛰어나다고 평가하면서, 미국 최전선 모델보다 약 4개월 뒤처진 수준이라고 봤다. NVIDIA 모델 카드 역시 배포하는 쪽이 용도별 안전성 평가와 가드레일을 직접 갖추라고 권고한다. 자기 서비스의 보안 점검에는 쓸모 있는 도구지만, 그 능력을 누구나 내려받을 수 있다는 사실이 이 모델을 둘러싼 논쟁의 핵심이다.
