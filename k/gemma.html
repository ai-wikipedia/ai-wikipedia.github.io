Gemma

Google DeepMind가 Gemini 연구를 바탕으로 만들어 공개한 오픈 웨이트 경량 모델 시리즈다. 내 컴퓨터에서 직접 돌리거나 내 데이터로 파인튜닝해야 할 때 쓴다.

한눈에 보기

Gemma는 Google이 Llama, Mistral에 대응해 내놓은 오픈 웨이트 모델이다. Gemini를 만들 때 쓴 기술을 바탕으로 하지만, 크기를 작게 만들어 노트북이나 스마트폰에서도 돌아간다. 모델 파일을 직접 받아 쓰기 때문에 데이터를 밖으로 보내지 않아도 되고, 내 용도에 맞게 고쳐 쓸 수도 있다.

크기는 기기에 맞춰 고른다

Gemma는 작은 것부터 수십억 단위(최대 27B 수준)까지 여러 크기로 나온다. 클수록 똑똑하지만 메모리를 더 많이 먹는다. 최신 세대는 글뿐 아니라 이미지 이해도 지원한다.

크기돌릴 수 있는 곳이럴 때 쓴다
작은 모델휴대폰, 라즈베리파이, 일반 노트북분류, 요약, 오프라인 앱
중간 모델메모리 넉넉한 노트북, 일반 GPU개인 비서, 문서 질의응답
큰 모델고성능 GPU코딩 보조, 복잡한 추론

양자화(압축) 버전을 쓰면 같은 크기라도 더 적은 메모리로 돌릴 수 있다. 대신 품질이 조금 떨어질 수 있다.

Ollama 한 줄이면 로컬에서 바로 실행

가장 쉬운 방법은 Ollama를 설치하고 ollama run gemma3를 입력하는 것이다. 설치 없이 먼저 써 보고 싶으면 Google AI Studio에서 바로 테스트할 수 있고, 모델 파일은 Hugging Face나 Kaggle에서 받는다. 순서는 AI Studio로 맛보기 → Ollama로 로컬 실행 → 필요하면 파인튜닝으로 가면 된다.

파인튜닝으로 내 일에 맞춘다

크기가 작아서 LoRA처럼 일부만 학습하는 방식으로 적은 비용에 도메인 특화 모델을 만들기 쉽다. 사내 용어가 많은 문서 분류나 정해진 형식의 답변처럼 범위가 좁은 작업일수록 효과가 크다. Keras나 Hugging Face 도구로 학습 코드를 빠르게 짤 수 있다.

언제 쓰고 언제 안 쓰나

개인정보 때문에 데이터를 밖으로 보낼 수 없거나, 인터넷 없이 돌아가야 하거나, 대량 작업에서 API 비용을 아끼고 싶을 때 쓴다. 반대로 아주 어려운 추론이나 긴 문서 분석이 필요하면 Gemini 같은 대형 모델이 낫다. 연구용과 상업용 모두 허용하지만 Google이 정한 이용 조건이 따로 있으니, 서비스에 넣기 전에 해당 버전의 라이선스를 확인해야 한다.
