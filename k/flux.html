FLUX (Black Forest Labs)

Stable Diffusion을 만든 사람들이 세운 Black Forest Labs의 이미지 생성 모델이다. 그림 속 글자까지 또렷하게 넣어야 할 때나 이미지 생성 모델을 내 GPU에서 직접 돌리고 싶을 때 쓴다.

한눈에 보기

FLUX는 Stable Diffusion을 만든 사람들이 새로 세운 회사 Black Forest Labs가 만든 이미지 생성 모델이다. 글로 원하는 그림을 설명하면 그대로 그려 주고, 특히 이미지 안에 글자를 또렷하게 넣는 일을 잘한다. 하나의 모델이 아니라 용도와 라이선스에 따라 여러 버전으로 나뉜다.

버전쓰는 방법이럴 때 쓴다
FLUX.1 [pro]API 전용품질이 가장 중요할 때
FLUX.1 [dev]내려받아 실행 (비상업)로컬 실험, 개인 작업
FLUX.1 Kontext글+이미지 입력기존 사진 일부만 말로 고치기
FLUX.2Pro/Flex/Dev/Klein고해상도, 참조 이미지 여러 장으로 일관된 결과

API로 부르거나, 내 GPU에서 돌리거나

가장 쉬운 방법은 BFL, fal.ai, Replicate 같은 곳의 API를 호출해 내 서비스에서 이미지를 받아오는 것이다. 직접 돌리고 싶다면 FLUX.1 [dev] 같은 공개 모델을 내려받아 diffusers 라이브러리로 FluxPipeline.from_pretrained("black-forest-labs/FLUX.1-dev")처럼 불러오거나, ComfyUI에 모델 파일을 얹어 쓴다.

GPU 메모리가 부족하면 FP8로 줄인 버전을 쓴다. 특정 화풍이나 인물을 일정하게 뽑아야 할 때는 LoRA로 가볍게 학습시켜 붙인다. 제품 사진을 같은 스타일로 대량으로 만드는 일에 잘 맞는다.

사진 편집은 Kontext와 FLUX.2로

새 그림을 만드는 게 아니라 있는 사진을 고치고 싶다면 Kontext를 쓴다. "이 사진에서 배경만 바꿔줘"처럼 말로 지시하면 나머지는 그대로 두고 원하는 부분만 바뀐다. 참조 이미지 여러 장을 한꺼번에 넣어 같은 인물·제품으로 여러 변형을 뽑아야 하면 FLUX.2가 맞다.

"오픈"이어도 상업용은 따로 확인

가장 많이 쓰이는 FLUX.1 [dev]는 비상업 라이선스라서 돈을 버는 데 쓰려면 별도 라이선스가 필요하다. 제약 없이 쓰려면 Apache 2.0으로 공개된 버전을 고른다.

버전상업적 사용
FLUX.1 [dev]별도 라이선스 필요
FLUX.2 Klein자유 (Apache 2.0)
Pro 계열API로 이용

버전마다 품질과 속도가 다르니, 만들 결과물과 가진 GPU에 맞춰 고르면 된다.
