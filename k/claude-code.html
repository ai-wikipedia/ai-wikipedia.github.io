클로드 코드

Claude Code CLI

터미널에서 자연어로 지시하면 코드를 읽고, 고치고, 테스트하고, 커밋까지 해 주는 AI 코딩 에이전트다. 작업 하나를 통째로 맡기고 결과만 검토하고 싶을 때 쓴다.

한눈에 보기

Claude Code는 터미널에서 도는 코딩 에이전트다. 에디터가 다음 줄을 제안해 주는 방식이 아니라, "환불 로직 추가해줘"처럼 작업을 통째로 맡기면 코드를 훑어보고, 파일을 고치고, 테스트를 돌리고, 커밋과 PR까지 만든다. 사람은 결과를 검토하면 된다.

쓰는 곳이럴 때 좋다
터미널 CLI기본 방식. SSH 원격 서버나 CI처럼 에디터가 없는 곳
VS Code·JetBrains 확장에디터 안에서 같은 에이전트를 쓰고 싶을 때
데스크톱 앱·웹터미널 없이 쓰고 싶을 때

어디서 쓰든 동작 방식은 같다.

계획은 승인하고, 실수는 되감는다

큰 작업은 플랜 모드로 계획만 먼저 세우게 하고, 방향이 맞으면 실행시킨다. 위험한 명령은 실행 전에 허락을 구하므로 처음엔 하나씩 승인하고, 믿음이 생기면 허용 범위를 넓히면 된다. 파일을 잘못 고쳤으면 체크포인트로 이전 상태로 되돌릴 수 있다.

코드베이스가 넓어서 둘러볼 게 많으면 서브에이전트에 맡긴다. 서브에이전트는 따로 파일을 읽고 결론만 알려 주므로 메인 대화의 기억 공간을 아낄 수 있다. .claude/agents/에 리뷰 전담, 테스트 전담처럼 역할을 적어 두면 필요할 때 알아서 불려 나온다.

규칙 파일과 자동화로 내 프로젝트에 맞추기

세팅을 어떻게 하느냐에 따라 같은 모델이라도 결과 품질이 크게 달라진다. 아래 네 가지를 조합해 에이전트가 일하기 좋은 환경을 만든다.

도구하는 일예시
CLAUDE.md세션 시작 때마다 읽는 프로젝트 규칙코딩 컨벤션, 빌드 명령, 금지 사항
스킬반복 작업을 슬래시 커맨드로/commit, /deploy
훅정해진 시점에 무조건 도는 셸 스크립트파일 수정 직후 린트 실행
MCP외부 서비스 연결GitHub 이슈 읽기, 사내 DB 스키마 조회

스킬은 모델이 판단해서 쓰고, 훅은 예외 없이 실행된다. 이 구성을 플러그인 하나로 묶어 팀에 배포할 수도 있다.

사람 없이 돌리려면 claude -p

claude -p 헤드리스 모드로 실행하면 대화 없이 결과만 출력하고 끝난다. 크론으로 매일 아침 이슈를 분류시키거나, PR이 열릴 때마다 자동 리뷰를 붙이는 데 쓴다. GitHub Actions용 공식 액션도 있어서, 몇 줄만 추가하면 이슈에서 멘션만 해도 작업을 시작한다. Claude Code를 만든 기반인 Claude Agent SDK로 나만의 에이전트를 만들 수도 있다.

작게 쪼개고, 긴 작업은 끊어 가기

큰 작업을 한 번에 던지기보다 확인할 수 있는 단위로 나눠 시키는 게 결과가 좋다. 테스트가 있는 코드라면 에이전트가 고친 내용을 스스로 확인할 수 있으니 더 많이 맡겨도 안전하다.

대화가 길어지면 내용이 자동으로 압축되면서 처음에 정한 세부 사항이 흐려질 수 있다. 긴 작업은 단계마다 세션을 끊고, 진행 상황을 CLAUDE.md나 계획 파일에 남겨 두는 편이 안정적이다.
