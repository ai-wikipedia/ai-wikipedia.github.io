머신러닝

Machine Learning

사람이 규칙을 짜는 대신 데이터에서 패턴을 스스로 배워 예측하는 AI 기술이다. 딥러닝과 LLM도 여기 속하며, 표 형태 데이터로 이탈·사기·수요를 예측할 때는 지금도 클래식 머신러닝이 가장 좋은 선택인 경우가 많다.

한눈에 보기

머신러닝은 사람이 조건문으로 규칙을 쌓는 대신, 데이터를 주고 구분하는 법을 컴퓨터가 스스로 찾게 하는 방식이다. 스팸 필터라면 '무료라는 단어가 있으면 스팸' 같은 규칙을 계속 고치는 대신, 스팸 메일과 정상 메일을 많이 보여 주고 차이를 배우게 한다.

방식무엇을 주나예
규칙 기반사람이 짠 조건문수법이 바뀔 때마다 규칙을 다시 짠다
머신러닝데이터새 데이터로 다시 학습하면 된다

배우는 방식은 세 가지

정답이 있는지, 보상만 있는지에 따라 나뉜다. 실무에서 쓰는 머신러닝은 대부분 지도학습이다.

방식배우는 법이럴 때 쓴다
지도학습문제와 정답을 쌍으로 준다메일이 스팸인지 예측
비지도학습정답 없이 구조를 찾는다소비 패턴이 비슷한 고객끼리 묶기
강화학습잘하면 보상, 못하면 감점게임 전략, 챗봇을 사람 말 잘 듣게 다듬기

표 데이터는 LLM보다 클래식 ML

딥러닝과 LLM은 머신러닝의 한 갈래일 뿐이다. 엑셀처럼 행과 열로 된 데이터로 고객 이탈, 카드 사기, 수요를 예측한다면 XGBoost나 랜덤 포레스트 같은 클래식 알고리즘이 더 낫다.

항목클래식 MLLLM
학습·추론 속도몇 초, 비용 거의 없음느리고 비쌈
예측 근거변수별 기여도까지 설명흐릿함

정답이 붙은 데이터가 충분하고 예측할 대상이 분명하면 클래식 ML부터 써 본다.

학습은 한 줄, 시간은 데이터에 든다

파이썬에서는 pandas로 데이터를 정리하고, scikit-learn으로 학습용과 시험용을 나눈 뒤 model.fit(X_train, y_train)으로 학습하고 시험용으로 정확도를 잰다. 실제로 시간이 드는 건 어떤 데이터를 넣을지 고르고 다듬는 일과 결과 검증이다.

배포가 끝이 아니다. 소비 패턴이나 사기 수법이 바뀌면 모델 성능이 서서히 떨어지는데(드리프트), 그래서 운영 중인 모델은 성능을 계속 지켜보다가 새 데이터로 주기적으로 다시 학습시킨다.

실패는 대개 데이터에서 온다

알고리즘보다 데이터 문제로 실패하는 경우가 훨씬 많다. 모델을 고르는 시간보다 데이터를 의심하는 시간을 길게 잡는 게 좋다.

함정무슨 일이 생기나막는 법
과적합연습 문제를 외워 실전에서 틀린다학습에 안 쓴 데이터로 검증
나쁜 데이터편향을 그대로 따라 한다데이터 품질부터 점검
데이터 누수개발 땐 정확하다가 실전에서 무너진다예측 시점에 알 수 없는 정보(예: 해지 날짜) 빼기
