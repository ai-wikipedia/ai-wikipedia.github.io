지속 학습

Continual Learning

새로운 데이터와 태스크를 순차적으로 학습하면서도 이전에 배운 지식을 잊지 않는 AI 학습 방식. 배포 후 가중치가 동결되는 현재 LLM의 한계를 넘어 인간처럼 평생 학습하는 AI를 만들기 위한 핵심 연구 분야다.

배운 것을 지키면서 새로 배우기

지속 학습(Continual Learning)이란 모델이 새로운 데이터나 과제를 차례로 배우면서도 앞서 배운 지식을 잃지 않도록 하는 학습 방식이다. "평생 학습(lifelong learning)"이라고도 부른다. 당연한 요구처럼 들리지만 신경망에게는 유독 어렵다. 사람은 스페인어를 새로 배워도 모국어를 잊지 않는데, 신경망은 새 데이터에 맞춰 가중치를 고치는 순간 예전 데이터에서 익힌 패턴을 덮어써 버린다. 이 현상을 파국적 망각(catastrophic forgetting)이라고 한다. 지금의 LLM이 학습을 마치면 가중치를 얼린 채 배포되는 것도 이 때문이다. 그래서 모델이 아는 것은 사전학습 때 본 정적인 지식과 지금 컨텍스트 윈도우에 들어 있는 내용이 전부다. 구글 리서치는 이 상태를 새 기억을 만들지 못하는 순행성 기억상실증에 빗대기도 했다.

새 문서로 계속 파인튜닝하면 생기는 일

개발자가 이 문제를 처음 체감하는 순간은 대개 파인튜닝이다. 사내 API 문서를 학습시킨 모델에 다음 분기 문서를 또 학습시키고, 이어서 고객 상담 말투까지 학습시키는 식으로 데이터를 쌓아 가면, 마지막 과제는 잘하는데 처음에 잘하던 일반 추론이나 코딩 실력이 눈에 띄게 떨어지는 경우가 흔하다. 모델은 지금 보고 있는 데이터에만 맞춰 최적화되기 때문이다.

실무에서는 몇 가지 요령으로 피해를 줄인다. 새 데이터만 넣지 않고 이전 학습 데이터나 범용 지시문 데이터 일부를 섞어 함께 학습시키고, 학습률을 낮게 잡는다. 원본 가중치를 건드리지 않는 LoRA도 방패가 된다. "LoRA Learns Less and Forgets Less" 연구에 따르면 LoRA는 전체 파인튜닝보다 새 과제를 덜 배우는 대신 기존 능력도 덜 잃는다. 과제마다 어댑터를 따로 학습해 두고 요청에 따라 갈아 끼우면 과제끼리 간섭할 일 자체가 줄어든다.

망각을 막는 세 갈래 처방

연구 쪽에서는 크게 세 방향으로 이 문제를 공략해 왔다. 리플레이는 과거 데이터 샘플을 버퍼에 저장해 두거나 생성 모델로 비슷한 데이터를 만들어 새 데이터와 섞어 학습한다. 정규화는 이전 과제에서 중요했던 파라미터가 크게 바뀌지 않도록 벌점을 주는 방식으로, 파라미터별 중요도를 계산하는 EWC가 대표적이다. 파라미터 격리는 새 과제마다 별도 모듈을 붙이고 예전 과제용 파라미터는 얼려서 간섭을 원천 차단한다. 앞서 말한 과제별 LoRA 어댑터도 이 갈래에 속한다.

어떤 상황을 다루느냐에 따라 난이도도 달라진다. 지금 어떤 과제인지 모델이 알고 있는 과제 증분, 과제는 같은데 데이터 분포가 바뀌는 도메인 증분, 구분해야 할 범주 자체가 계속 늘어나는 클래스 증분으로 나누는데, 마지막이 가장 어렵다. 스팸 필터가 새 유형의 스팸을 익히는 건 도메인 증분이고, 상품 분류기가 신상품 카테고리를 추가로 배우는 건 클래스 증분이다.

2025년에는 LLM 포스트 트레이닝에서 흥미로운 관찰이 나왔다. 같은 새 과제를 지도 파인튜닝(SFT)과 강화학습(RL)으로 각각 가르치면 새 과제 성능은 비슷한데, RL 쪽이 기존 능력을 훨씬 덜 잊는다는 것이다. MIT 연구진은 이를 RL's Razor라 부르며, 모델이 스스로 생성한 답으로 학습하는 온-폴리시 RL은 새 과제를 푸는 여러 해법 중 원래 모델의 출력 분포에서 가장 덜 벗어나는 쪽을 고르는 경향이 있기 때문이라고 설명했다. 망각의 정도가 원래 모델과의 분포 차이(KL 발산)로 예측된다는 점도 함께 보였다.

기억을 붙이는 것과 배우는 것은 다르다

"쓸수록 똑똑해지는 AI"라고 홍보하는 제품 중 상당수는 실제로 가중치를 바꾸지 않는다. 대화 내용을 외부 메모리에 적어 두었다가 RAG로 다시 꺼내 컨텍스트에 넣거나, 데이터를 모아 주기적으로 오프라인 재학습을 돌리는 방식이다. 에이전트 메모리나 CLAUDE.md 같은 파일에 규칙을 쌓아 두는 것도 실용적인 대안이지만, 모델 자체가 경험에서 배우는 파라메트릭 지속 학습과는 구조가 다르다. 메모리는 검색이 빗나가면 소용이 없고, 쌓인 기억이 많아질수록 컨텍스트 비용이 커진다. 그래도 실무의 분업은 비교적 분명하다. 가격표나 사내 규정처럼 자주 바뀌는 사실은 RAG나 메모리로 넣고, 가중치 학습은 말투, 출력 형식, 도메인 특유의 추론 방식처럼 잘 변하지 않는 능력을 가르치는 데 쓴다.

진짜 지속 학습을 향한 연구도 이어지고 있다. 구글은 2025년 11월 모델을 서로 다른 속도로 업데이트되는 여러 겹의 학습 과정으로 보는 네스티드 러닝(Nested Learning)을 발표하고, 빠르게 바뀌는 기억과 천천히 굳는 기억을 나눠 둔 실험 아키텍처 Hope를 공개했다. 다만 아직은 연구 단계다. 배포된 모델이 사용자와 대화하며 실시간으로 가중치를 고친다면 잘못된 정보나 악의적인 데이터까지 그대로 배워 버릴 수 있어, 무엇을 배우게 할지 통제하는 문제도 함께 풀어야 한다.
