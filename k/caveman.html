Caveman

AI가 원시인처럼 핵심만 짧게 말하게 해서 출력 토큰을 줄이는 Claude Code 스킬이다. 사용량 한도가 빠듯하거나, 이미 익숙한 작업을 길게 반복시키는 세션에서 켜 둔다.

한눈에 보기

Caveman은 AI의 정중하고 긴 답변에서 군더더기를 빼고 핵심만 짧게 말하게 만드는 스킬이다. 줄어든 단어만큼 출력 토큰이 줄어 요금과 사용량 한도를 아낄 수 있고, 답도 빨리 나온다. 원리는 시스템 프롬프트에 말투 규칙을 넣는 것 하나다.

구분답변 예시
평소렌더링마다 새 객체 참조를 만들고 있기 때문일 가능성이 높습니다. useMemo로 메모이제이션하는 것을 권장드립니다.
CavemanNew object ref each render. useMemo fix.

/caveman으로 켜고, 강도는 세 단계

Claude Code에 스킬로 설치한 뒤 /caveman으로 켜고 끈다. 한 번 켜면 끌 때까지 계속 유지되니, 토큰을 빨리 쓰는 긴 디버깅 세션에 켜 두면 효과가 크다. Codex, Cursor, Gemini 같은 다른 코딩 에이전트에도 같은 방식으로 붙는다.

강도말투
lite문장은 그대로, 군더더기만 뺀다
full문장을 조각낸 전형적인 원시인 말투
ultra화살표와 단어만 남긴다

설정 파일까지 줄이는 compress

/caveman:compress는 CLAUDE.md나 메모리 파일을 원시인 말투로 줄여 덮어쓴다. 원본은 FILE.original.md로 백업하고, 코드 블록·URL·기술 용어는 그대로 둔다. 매 세션 읽는 파일이 짧아지니 앞으로의 모든 대화에서 입력 토큰이 줄어든다. 코드 파일은 건드리지 않는다.

실제 절감은 생각보다 작다

처음 알려진 '75% 절감'은 프로젝트가 직접 '최대 65%'로 고쳤고, 실제로 써 보면 30~50% 정도라는 평가가 많다. 게다가 줄어드는 건 출력 토큰뿐인데, Claude Code 비용은 대부분 코드를 읽는 입력 토큰에서 나온다. 청구서 전체가 그만큼 줄지는 않는다.

초기 주장75%
공식 정정최대 65%
실사용30~50%

출력 토큰 절감률 기준.

켤 때와 끌 때를 가린다

설명이 빠지면 답이 모호해질 수 있다. 그래서 보안 경고나 파일 삭제처럼 되돌릴 수 없는 작업에서는 자동으로 잠시 꺼진다. '간결하게 답해'라는 평범한 지시로도 비슷하게 아낄 수 있다는 비교도 있어서, 압축률보다는 언제 켤지 고르는 게 더 중요하다.
