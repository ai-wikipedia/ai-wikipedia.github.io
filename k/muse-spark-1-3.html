뮤즈 스파크 1.3

Muse Spark 1.3 (Meta)

뮤즈 스파크 1.3은 메타가 만든 멀티모달 추론 모델이다. 여러 단계에 걸쳐 도구를 부르며 길게 이어지는 에이전트 작업과 코딩에 쓴다.

한눈에 보기

뮤즈 스파크 1.3은 Meta Superintelligence Labs가 2026년 9월 2일 공개한 모델이다. 한 번 답하고 끝내는 대신 계획을 세우고, 도구를 부르고, 결과를 확인하며 작업을 끝까지 끌고 가도록 다듬었다. 저장소 단위 코딩이나 긴 에이전트 작업을 맡길 때 쓴다.

항목내용
입력텍스트, 이미지, 비디오, PDF 등 파일
출력텍스트
컨텍스트약 100만 토큰
쓰는 곳Meta Model API, Muse Code, OpenRouter

1.2를 쓰고 있다면 모델 ID만 바꾸면 된다

엔드포인트, SDK, 가격이 1.2와 같아서 Meta Model API에서 모델 ID를 muse-spark-1.3으로 바꾸기만 하면 된다. 함수 호출은 tools와 tool_choice로 붙이고, 구조화된 출력이 필요하면 response_format에 JSON 스키마를 넣는다. OpenRouter에도 올라와 있어서 쓰던 클라이언트에서 모델 이름만 바꿔 시험해 볼 수 있다.

추론 강도이럴 때 쓴다
max어려운 추론, 긴 에이전트 작업
xhigh 등 낮은 단계비용과 속도를 아껴야 할 때

터미널에서 쓰려면 Muse Code 에이전트를 설치한다. 지금 베타는 macOS와 Linux만 되고 Windows는 아직 안 된다.

지시는 다 적지 말고 열어 둔다

이 모델은 지시가 모호하면 직접 되묻도록 만들어졌다. 조건을 처음부터 빽빽하게 다 적어 넣으면 이렇게 되묻는 기능이 오히려 꺼진다. 큰 작업은 목표만 주고, 모델이 묻는 질문에 답하면서 범위를 좁혀 가는 편이 이 모델에 맞다.

싼 요금제는 데이터로 값을 치른다

요금제가 둘이다. muse-spark-1.3-contributor는 훨씬 싼 대신 프롬프트와 출력이 메타의 제품 개선에 쓰일 수 있다. OpenCode Zen에서는 이 버전을 무료로 열어 둬서, OpenCode의 모델 선택 메뉴에서 고르기만 하면 비용 없이 써 볼 수 있다.

요금제입력 / 출력이럴 때 쓴다
일반$1.25 / $4.25사내 코드, 민감한 데이터
contributor$0.10 / $0.20개인 실험, 공개 프로젝트

100만 토큰당 가격. 캐시 읽기는 일반 $0.15, contributor $0.002.

효율 수치는 메타 내부 비교라 직접 재 봐야 한다

메타는 1.2보다 도구 호출과 토큰이 줄었다고 하지만, 어떤 작업으로 비교했는지 공개하지 않았다. 실사용 후기도 엇갈린다. 1.2보다 낫다는 반응이 있는 한편, 토큰을 많이 쓰고 작업 중간에 멈춰서 "continue"로 한 번 더 밀어 줘야 했다는 후기도 있다. 도입하기 전에 내 저장소에서 기존 모델과 같은 과제를 나란히 돌려 보고 정하는 게 안전하다.
