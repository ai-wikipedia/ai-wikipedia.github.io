클로드 페이블 5.1

Claude Fable 5.1 (Anthropic)

클로드 페이블 5.1은 Anthropic이 2026년 9월 공개한 클로드 5 제품군의 최상위 모델이다. 오퍼스 5.5로 부족한 어려운 추론이나 오래 도는 에이전트 작업을 통째로 맡길 때 쓴다.

한눈에 보기

페이블 5.1은 일반 사용자가 쓸 수 있는 클로드 가운데 가장 성능이 높은 모델이다. 바로 답하기보다 계획을 세우고, 도구를 쓰고, 결과를 스스로 확인하며 긴 작업을 끝까지 해낸다. 다만 공식 문서는 대부분의 작업을 오퍼스 5.5로 시작하라고 권한다.

모델위치이럴 때 쓴다
오퍼스 5.5기본 선택대부분의 일상 작업
페이블 5.1최상위어려운 추론, 오래 도는 에이전트
미토스 5.1같은 모델안전장치를 완화한 버전, 초대받은 기관만

생각의 깊이는 effort 하나로 정한다

API 모델 ID는 claude-fable-5-1이다. 생각하는 기능(thinking)은 항상 켜져 있고, 얼마나 깊게 생각할지는 effort 값으로 고른다. low나 medium으로 낮춰도 페이블 5와 비슷하거나 더 나은 결과를 훨씬 싸게 내도록 만들어졌다.

어디서 쓰나기본 effort
API, Claude Codehigh
Claude.ai, Coworkmedium

Claude Code에서는 맡겨 두고 길게 돌리는 작업에서 차이가 가장 크다. 테스트를 직접 써서 확인하고, 화면을 보며 UI를 디자인과 대조하고, 중단된 곳부터 다시 이어 간다. API로 에이전트를 만든다면 메시지별 effort(베타)로 계획·설계는 높게, 반복적인 파일 수정은 낮게 나눠 비용을 아낄 수 있다. 도구 호출 사이 진행 상황을 읽기 쉽게 보려면 display: "updates"(베타)를 쓴다.

캐시 읽기 가격이 4분의 1로

에이전트는 같은 프롬프트와 대화 기록을 매번 다시 보내므로 캐시 읽기 가격이 사실상 비용을 좌우한다. 기본 가격은 그대로지만 이 부분이 크게 내려가, 에이전트 비중이 높은 작업일수록 많이 절약된다.

페이블 5$1
페이블 5.1$0.25

캐시 읽기 100만 토큰당 가격. 입력 $10, 출력 $50은 페이블 5와 같다.

페이블 5 코드를 그대로 옮기면 세 곳이 깨진다

여러 모델을 오가며 쓰는 구조라면 사고 블록 호환을 특히 확인해야 한다.

바뀐 점영향
도구 호출 강제(forced tool use)에러를 반환한다
사고 블록 호환이전 모델이 5.1의 사고 블록을 읽지 못한다
이전 턴 수정그 턴의 사고 블록이 무효가 된다

보안은 소스 코드까지만, 높은 effort는 범위를 넘는다

보안 작업은 소스 코드 취약점 찾기까지만 한다. 바이너리 분석, 침투 테스트, 익스플로잇 작성은 다른 모델로 넘기고, 정상적인 요청이 막힐 때도 있다. 하위 모델보다 응답이 느리다는 점도 감안해야 한다.

effort를 높이면 요청하지 않은 수정까지 덧붙이는 경향이 있다. 정해진 범위만 고쳐야 한다면 프롬프트에 수정 범위를 분명히 적어 둔다.
