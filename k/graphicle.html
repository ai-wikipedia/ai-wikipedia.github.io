Graphicle (Code Graph and Memory for Coding Agents)

저장소를 코드 그래프로 만들고 프로젝트 문서·결정 사항·지난 에이전트 세션을 기억해, 코딩 에이전트에게 파일과 줄 번호가 붙은 근거를 건네주는 로컬 오픈소스 도구다. Claude Code·Codex·Cursor 같은 에이전트가 프로젝트 맥락을 매번 잊어버릴 때 쓴다.

한눈에 보기

그래피클은 코드 그래프와 프로젝트 메모리를 프로그램 하나로 합친 도구다. 함수 호출 관계 같은 코드 구조와 문서·결정 사항·지난 세션 기록을 함께 저장해 두고, 에이전트가 물어보면 정확한 파일과 줄을 인용해서 돌려준다. Rust로 만든 Graphify 포팅판에 메모리를 더한 형태이고, Apache-2.0 라이선스로 공개돼 있다.

항목코드 그래프 도구 + 메모리 서버그래피클
설치도구 두 개, 때로는 DB 서버까지한 번 설치
에이전트 연결에이전트마다 도구별로 설정graphicle setup 한 번
MCP 서버두 개를 따로 설정하나로 그래프·메모리 모두 제공
저장소그래프 파일 + DBSQLite 파일 하나

그래프는 구조, 메모리는 맥락

코드 그래프는 tree-sitter로 파일·함수·클래스·호출·import를 파싱해서 만들고, 이 과정에 AI 모델을 쓰지 않는다. 메모리에는 Markdown·PDF·Office·HTML 문서, 검토를 거친 결정과 절차, 지난 Claude Code·Codex 세션이 들어가서 코드와 함께 검색된다. 질문이 들어오면 그래프를 따라 호출하는 쪽 코드까지 함께 끌어온다.

메모리는 에이전트가 마음대로 쓰지 못한다. 에이전트는 기억할 내용을 제안만 하고, 사람이 승인해야 저장된다. 잘못된 추측이 사실처럼 쌓이는 일을 막는 장치다.

세 가지 창구로 쓴다

창구방법이럴 때
MCP에이전트가 도구로 호출작업 중 에이전트가 맥락을 찾을 때
CLIgraphicle ask사람이 직접 근거를 찾거나, 설정해 둔 모델로 답을 받을 때
웹 앱graphicle open그래프와 메모리를 브라우저에서 둘러볼 때

함수를 고치기 전에 영향 범위를 보고 싶다면 graphicle graph extract . --code-only로 코드만 추출한 뒤 graphicle graph affected "retry()"를 실행한다. 그 함수에 기대는 코드가 목록으로 나온다. graphicle graph로는 심볼 설명, 경로 추적, HTML 그래프 내보내기도 할 수 있다.

내 컴퓨터 안에서만 돈다

API 키도, 계정도, 텔레메트리도 없다. 사용자가 요청하지 않으면 아무것도 밖으로 나가지 않는다. 바뀐 파일은 답하기 직전에 다시 동기화되므로, 방금 고친 코드를 두고 옛 버전 기준으로 답하는 일이 줄어든다. 연결을 끊고 싶으면 graphicle disconnect로 설정을 되돌린다.

아직 0.1 버전이다

처음 공개된 0.1 버전대라 기능과 명령어가 바뀔 수 있다. 개인과 팀 모두 무료로 쓸 수 있고, 팀용 상용 에디션은 비공개 프리뷰 단계다. 큰 저장소에 바로 도입하기보다 작은 프로젝트에서 에이전트 답변이 실제로 나아지는지 먼저 확인하는 편이 안전하다.
