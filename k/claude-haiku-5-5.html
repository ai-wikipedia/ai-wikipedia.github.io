클로드 하이쿠 5.5

Claude Haiku 5.5 (Anthropic)

클로드 하이쿠 5.5는 Anthropic Claude 5.5 제품군에서 가장 작고 빠르고 싼 모델이다. 요약, 분류, 서브에이전트, 브라우저 조작처럼 호출이 많고 비용에 민감한 작업을 싸게 돌릴 때 쓴다.

한눈에 보기

하이쿠 5.5는 Claude 5.5 제품군의 가장 가볍고 싼 모델이다. 깊은 판단은 Opus·Sonnet에 맡기고, 범위가 정해진 작은 작업을 대량으로 처리할 때 하이쿠를 쓴다. 텍스트와 이미지를 입력으로 받고, 컨텍스트는 최대 100만 토큰이다.

모델위치이럴 때 쓴다
Opus 5.5최상위무겁고 깊은 작업, 복잡한 에이전틱 코딩
Sonnet 5.5중간일상적인 중간급 작업
Haiku 5.5경량요약·분류·서브에이전트·브라우저 조작

이렇게 쓴다

API에서는 모델 ID claude-haiku-5-5로 부른다. 가장 잘 맞는 자리는 큰 모델 옆의 일꾼이다. Opus나 Sonnet이 계획을 세우고, 파일 수십 개 요약이나 로그 분류 같은 반복 작업은 하이쿠 서브에이전트에 넘긴다. 화면을 보고 클릭하는 브라우저 에이전트의 기본 모델로도 쓰기 좋다.

Cursor에서는 Settings > Models에서 모델 선택기에 추가한다. 하이쿠는 effort(응답 전에 얼마나 생각할지)를 조절할 수 있는 첫 Haiku 모델이라, 작업마다 강도를 바꿔 쓰면 된다.

작업모델 / effort이유
단순 분류, 빠른 질문Haiku, 낮게토큰과 지연을 줄인다
조금 까다로운 코드 수정Haiku, 높게정확도를 끌어올린다
설계 판단, 여러 단계 리팩터링Sonnet·Opus큰 모델이 여전히 낫다

가격이 약 90% 내려갔다

가장 크게 달라진 건 가격이다. 입력이 10만 토큰 이하면 Haiku 4.5보다 약 90% 싸다. 예전 요청의 약 90%가 이 범위였기 때문에, 대부분의 호출이 싼 요율로 처리된다.

구간입력출력
10만 토큰 이하$0.10$0.50
10만 토큰 초과$0.50$2.50
캐시 쓰기 / 읽기$0.125$0.01 (읽기)

100만 토큰당 가격. 긴 구간은 기본 요금의 5배다.

쓸 때 주의할 점

긴 컨텍스트 구간은 요율이 5배로 뛰니, 100만 토큰을 무심코 채우면 생각만큼 싸지 않다. 반복되는 앞부분은 프롬프트 캐싱으로 돌리고, 요청은 10만 토큰 아래로 쪼개 보내는 게 좋다. 공개 직후 성능 수치는 대부분 Anthropic이 직접 낸 것이라, 내 작업으로 직접 재 보는 게 가장 확실하다.
