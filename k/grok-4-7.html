그록 4.7

Grok 4.7 (xAI)

그록 4.7은 xAI(현재 SpaceXAI라는 이름으로 사업 중)가 2026년 9월 Grok 4.6의 후속으로 내놓은 플래그십 추론 모델이다. 몇 시간씩 걸리는 소프트웨어 엔지니어링 작업, 에이전트 작업, 문서 작성 같은 지식 업무를 겨냥했고, 50만 토큰 컨텍스트를 지원한다.

오래 버티는 작업을 위해 다시 만든 그록

그록 4.7은 xAI가 2026년 9월 21일 공개한 Grok 계열 최신 모델로, Grok 4.6의 뒤를 잇는다. xAI는 이제 SpaceXAI라는 이름으로 사업을 하고 있고, 두 이름은 같은 회사를 가리킨다. 이번 버전은 4.6을 조금 손본 수준이 아니다. 더 큰 새 베이스 모델 위에서 출발했고, 강화학습도 더 오래, 더 어려운 과제 위주로 돌렸다. 특히 사람이 해도 몇 시간씩 걸리는 문제에 비중을 많이 뒀다. 짧은 퀴즈를 더 잘 맞히는 모델이 아니라, 긴 엔지니어링 작업을 맡겨도 중간에 흐트러지지 않는 모델을 만들려 했다는 뜻이다. xAI가 강조하는 개선점은 두 가지다. 자기가 한 작업을 스스로 검증하는 능력, 그리고 길어진 컨텍스트를 다루는 능력이다. 여기에 xAI 자체 에이전트 환경인 Grok Bot 하네스를 기본으로 이해하도록 학습시켜, 대화형 작업과 일반 지식 업무 성능도 함께 끌어올렸다고 밝혔다.

스펙과 가격, 호출 방법

API 모델 ID는 grok-4.7이다. 컨텍스트 윈도우는 500,000 토큰, 입력은 텍스트와 이미지, 출력은 텍스트이며 지식 컷오프는 2026년 5월이다. 가격은 입력 100만 토큰당 2달러, 출력 6달러이고, 캐시된 입력 토큰은 0.50달러로 내려간다. 다만 요청 한 번이 200K 토큰을 넘으면 더 비싼 요율이 붙기 때문에, 50만 토큰을 다 쓸 수 있다고 매번 다 채우면 비용이 확 뛴다. Responses API와 Chat Completions API를 둘 다 지원하고, 함수 호출, 구조화된 출력, 웹 검색, X 검색, 코드 실행 도구를 쓸 수 있다. Batch API는 지원하지 않는다.

추론 강도는 reasoning_effort 파라미터로 low, medium, high, xhigh 중에서 고르며 기본값은 high다. 간단한 분류나 변환은 low로 빠르고 싸게 처리하고, 하루 종일 돌아갈 리팩토링 에이전트처럼 실수가 비싼 작업은 xhigh로 올리는 식으로 쓴다. 같은 모델을 더 빠른 인프라에서 돌리는 Grok 4.7 Fast도 있는데, 토큰 요금이 표준의 두 배다. Fast는 Cursor와 Grok Build에서만 쓸 수 있고, 공개 xAI API에는 없다.

개발자가 실제로 쓰는 자리

xAI가 이 모델로 가장 노린 곳은 코딩이다. 그록 4.7은 SpaceXAI의 터미널 코딩 에이전트인 Grok Build의 기본 모델이다. Grok Build는 터미널에서 대화형으로 띄울 수도 있고, 스크립트 안에서 헤드리스로 돌릴 수도 있으며, Agent Client Protocol을 통해 다른 도구 안에 끼워 넣을 수도 있다. 예를 들어 CI 스크립트에서 Grok Build를 헤드리스로 호출해 실패한 테스트를 고치게 하면, 모델이 스스로 결과를 검증하는 쪽으로 학습된 덕을 볼 수 있다. 에디터를 떠나기 싫다면 Cursor나 GitHub Copilot에서 모델 목록의 그록 4.7을 고르면 된다. 클라우드 쪽에서는 Oracle OCI Generative AI가 9월 25일부터 xai.grok-4.7이라는 이름으로 온디맨드 제공을 시작해, OCI 안에서 데이터를 돌리는 팀도 따로 xAI 계정 없이 쓸 수 있다. 반면 출시 시점에 grok.com과 Grok 앱은 여전히 4.6을 쓰고 있었으므로, 일반 챗봇 화면에서 4.7을 체감하려면 소비자 쪽 반영을 기다려야 한다.

코딩 외에는 문서와 프레젠테이션 작성 같은 전문 지식 업무를 겨냥했다. 변호사, 간호사, 재무 분석가가 하는 실제 업무를 시켜 보는 GDPval과 AA Briefcase에서 4.6보다 점수가 올랐고, xAI는 다른 프론티어 모델과 비슷한 수준이라고 설명한다. 안전 쪽에서는 세이프가드 스택을 처음부터 새로 짰고, 거절과 탈옥 저항에서 자사가 테스트한 모델 중 가장 강하다고 주장한다. 사이버보안이나 생물학처럼 이중 용도 분야에서 무해한 요청은 돕고 위험한 요청은 거절하는 균형을 따지는 LatchBio 바이오세이프티 벤치마크에서 62.4%로 1위를 기록했다고 밝혔다.

벤치마크를 읽을 때 조심할 점

출시 발표의 비교표는 대부분 xAI가 직접 낸 수치다. 그런데 표를 자세히 보면 그록 4.7은 대개 xhigh 설정으로, 4.6은 high 설정으로 측정돼 있어 같은 조건 비교가 아니다. 한 분석에서는 xAI 차트가 경쟁 모델 점수를 다른 모델 점수와 혼동해 표기한 부분도 지적했다. 독립 평가 결과도 발표와 온도 차가 있다. Artificial Analysis가 직접 돌린 Terminal-Bench 4.0에서 그록 4.7은 26%에 그쳤고, CursorBench에서는 Anthropic의 상위 모델이 앞섰다. 결국 같은 모델이라도 추론 강도와 하네스 조합에 따라 결과가 크게 갈리므로, 모델 이름만이 아니라 effort 설정과 실행 환경을 같이 놓고 비교해야 한다.

가격표가 싸다고 실제 비용도 싸다고 단정하기도 어렵다. 국내 사용자들 사이에서는 토큰 단가는 낮아도 같은 작업에서 토큰을 더 많이 써서 체감 소모가 빠르다는 반응이 있었다. 파라미터 수가 2.1조 개로 4.6보다 약 40% 커졌다는 얘기도 돌았지만, 이는 커뮤니티 주장일 뿐 xAI가 공식 사양으로 밝힌 수치는 아니다. 실제 업무에 넣기 전에 자기 작업으로 effort 단계별 정확도와 토큰 사용량을 직접 재 보는 게 가장 확실하다.
