그래파이

Graphify

Graphify(그래파이)는 프로젝트 전체를 지식 그래프로 만들어 주는 오픈소스 스킬이다. AI 코딩 어시스턴트가 파일을 하나하나 열어 보지 않고도 코드 구조를 물어보고 답을 얻어야 할 때 쓴다.

한눈에 보기

Graphify는 프로젝트를 한 번 훑어서 함수, 클래스, DB 테이블, API 핸들러, 설계 문서를 점으로 찍고 서로의 관계를 선으로 잇는다. 그렇게 AI가 볼 수 있는 코드 지도를 만든다. 파일이 많은 프로젝트에서 "이 기능이 저기와 어떻게 연결돼 있지?" 같은 질문을 자주 한다면 쓸 만하다.

방식AI가 하는 일결과
파일 직접 읽기관련 파일을 하나씩 열어 구조를 다시 짜 맞춘다토큰이 많이 들고 전체 그림을 놓치기 쉽다
Graphify미리 만든 그래프에서 답을 찾는다토큰이 적게 들고 연결 관계가 바로 보인다

설치하고 /graphify 한 줄이면 된다

패키지를 설치하고 어시스턴트에 스킬로 등록한 다음, 어시스턴트 안에서 /graphify .를 입력하면 프로젝트 폴더 전체를 분석한다. Claude Code, Codex, OpenCode 같은 어시스턴트에서 쓸 수 있다. 패키지 이름은 y가 두 개인 graphifyy라는 점에 주의한다.

단계명령어
설치pip install graphifyy
어시스턴트에 등록graphify install
프로젝트 분석/graphify .
질문하기graphify query "무엇이 인증과 DB를 연결하나?"

분석이 끝나면 graphify-out/ 폴더에 결과가 생긴다. 구조를 눈으로 훑어볼 때는 graph.html, 핵심 지점과 이상한 연결을 빠르게 확인할 때는 GRAPH_REPORT.md를 열면 된다. 이후의 질문은 graph.json을 바탕으로 답한다.

토큰이 70분의 1로 줄어든다

같은 질문이라도 그래프에서 답을 꺼내면 파일을 직접 읽을 때보다 토큰이 훨씬 적게 든다. 토큰을 아끼면 컨텍스트 한도에 걸릴 일이 줄고, 엉뚱한 파일을 뒤지다가 틀린 답을 내는 일도 줄어든다.

파일 직접 읽기약 123k
Graphify약 1.7k

코드·논문·이미지가 섞인 52개 파일에 질문 한 번을 했을 때 쓴 토큰 수.

코드 밖의 문서까지 함께 묶는다

코드뿐 아니라 설계 문서, PDF 논문, 다이어그램도 같은 그래프에 넣을 수 있다. 그래서 코드가 무엇을 하는지와 함께 왜 그렇게 설계됐는지도 물어볼 수 있다. 어떤 자료까지 넣느냐에 따라 그래프의 성격이 달라지므로, 질문하려는 내용에 맞춰 넣을 자료를 고르는 게 좋다.

코드가 바뀌어도 전체를 처음부터 다시 만들지 않는다. 바뀐 부분만 다시 분석해서 기존 그래프에 반영한다.

API 키와 보내는 데이터는 확인해 둔다

그래프를 만들 때는 어시스턴트에 이미 설정된 모델 API 키를 그대로 쓴다. 모델로 보내는 것은 소스 코드 전체가 아니라 문서와 다이어그램에서 뽑은 의미 요약이다. 쓰기 전에 이 동작 방식을 알아 두면 좋다.
