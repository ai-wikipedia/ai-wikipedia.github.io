스텝 5 프리뷰

Step 5 Preview (StepFun)

스텝 5 프리뷰는 상하이 AI 기업 StepFun이 2026년 9월 공개한 플래그십 모델이다. 코딩, 장시간 에이전트 작업, 금융 같은 전문 지식 업무를 겨냥했고, 비슷한 지능을 더 낮은 작업 비용으로 내는 것을 내세운다. 전체 600B·활성 27B 파라미터의 MoE 구조에 100만 토큰 컨텍스트를 갖췄다.

한 번 답하고 끝나지 않는 모델

스텝 5 프리뷰(Step 5 Preview)는 중국 상하이의 StepFun이 2026년 9월 20일 공개한 새 플래그십 모델이다. 질문 하나에 답 하나를 주는 챗봇용이 아니라, 계획을 세우고 도구를 호출하고 결과를 확인하고 접근 방식을 고쳐 가며 결과물이 나올 때까지 작업을 이어 가는 에이전트용으로 설계됐다. 신입 분석가에게 "이 회사 가치평가 보고서 만들어 와"라고 맡기면 공시 자료를 찾고, 숫자를 맞춰 보고, 엑셀을 돌리고, 보고서를 쓰는 과정을 혼자 해 오는 것과 비슷하다. StepFun이 내세우는 핵심은 비용이다. 비슷한 수준의 지능을 훨씬 낮은 작업당 비용으로 낸다는 것이고, 출시 페이지 제목인 "Advancing the Pareto Frontier"도 성능과 비용 사이의 균형점을 한 단계 앞으로 밀었다는 뜻이다.

600B인데 27B만 일하는 구조

모델 전체 파라미터는 6천억 개지만, 토큰 하나를 처리할 때 실제로 켜지는 건 270억 개뿐이다. 여러 전문가 네트워크 중 필요한 몇 개만 골라 쓰는 MoE(Mixture of Experts) 방식이라서, 큰 모델의 지식은 유지하면서 추론할 때 드는 연산은 중형 모델 수준으로 줄어든다. 이 구조가 낮은 가격의 바탕이다. API 가격은 입력 100만 토큰당 1.00달러, 출력 100만 토큰당 2.70달러로 책정됐다. 컨텍스트 창은 100만 토큰이고, 입력으로는 텍스트·이미지·비디오를 네이티브로 받으며 출력은 텍스트다. 공식 문서에는 최대 출력도 100만 토큰으로 적혀 있다. 이전 세대인 스텝 3.7 플래시가 256K 컨텍스트에 훨씬 싼 가격이었던 것과 비교하면, 스텝 5 프리뷰는 가격을 조금 올리는 대신 긴 맥락과 고난도 작업 쪽으로 무게를 옮긴 셈이다.

개발자가 붙여 쓰는 방법

쓰는 절차는 OpenAI 호환 Chat Completions API와 비슷하다. StepFun 오픈 플랫폼에서 API 키를 만들고, 모델 ID에 step-5-preview를 지정해 cURL이나 Python으로 요청을 보낸 뒤 choices.message.content에서 결과를 읽는다. 추론 강도는 low, medium, high 세 단계로 조절할 수 있어서, 간단한 분류는 low로 싸고 빠르게 처리하고 복잡한 리팩토링 계획은 high로 돌리는 식의 배분이 가능하다. 스트리밍, 툴 콜링, JSON 모드, JSON 스키마, 프롬프트 캐싱도 지원하므로, 에이전트가 같은 시스템 프롬프트와 대형 문서를 반복해서 보내는 구조라면 캐싱으로 입력 비용을 줄일 수 있다. 공식 문서는 운영 배포 전에 타임아웃, 재시도, 오류 처리, 키 관리 로직을 갖추라고 권한다. StepFun은 자사 Step Plan을 통해 Claude Code와 연동하는 방법도 문서로 제공해서, 익숙한 코딩 에이전트 환경에서 백엔드 모델만 스텝 5 프리뷰로 바꿔 쓸 수 있다.

어떤 작업에서 힘을 쓰나

StepFun이 강조하는 분야는 소프트웨어 엔지니어링, 전문 지식 업무, 특히 금융이다. 금융 쪽에서 노리는 건 회계 질문에 답하는 수준이 아니라, 공시 자료와 시장 데이터를 모으고 지표 정의를 맞추고 밸류에이션을 계산해 출처·가정·수식이 추적 가능한 보고서를 만드는 분석가 워크플로우다. 리서치 작업에서는 한 번의 에이전트 작업 안에서 웹 페이지 950개를 가져와 조율했다고 밝혔는데, 100만 토큰 컨텍스트가 이렇게 많은 자료를 한꺼번에 들고 가는 데 쓰인다. 프론트엔드 개발과 시각 작업을 엮는 것도 소개됐다. 웹 인터페이스와 데이터 시각화를 만들고, Blender를 조작해 3D 결과물을 만들면서 반복적으로 다듬는 식이다. 이미지와 비디오 입력을 받으니, 렌더링 결과 화면을 다시 보고 고치는 루프를 모델 혼자 돌릴 수 있다.

평가와 아직 남은 물음표

제3자 평가에서 Artificial Analysis는 Intelligence Index 44점을 매겼고, Vals 리더보드에서는 오픈 웨이트 모델 중 7위, 작업당 비용 2.54달러로 올라갔다. 다만 이름에 '프리뷰'가 붙은 만큼 정식판 전 단계다. 오픈 웨이트는 2026년 10월 15일 공개 예정으로 발표됐고, 일부 집계 사이트는 아직 가중치 공개가 확인되지 않았다며 순위를 '추정치'로 표시하고 있다. 벤치마크 점수가 곧 내 작업에서의 성능을 보장하지는 않으니, 비용 대비 성능을 따지는 팀이라면 실제 에이전트 태스크 몇 개로 작업당 비용과 성공률을 직접 재 보는 것이 안전하다. 가중치가 공개되면 600B 규모를 직접 서빙할 GPU 자원이 필요하다는 점도 자체 호스팅을 고민할 때 따져 봐야 한다.
