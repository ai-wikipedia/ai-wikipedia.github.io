클로드 소네트 5.5

Claude Sonnet 5.5 (Anthropic)

클로드 소네트 5.5는 Anthropic Claude 5.5 패밀리의 중간급 모델로, 오퍼스 5.5의 절반 가격이다. 버그 수정이나 문서 작성처럼 범위가 정해진 일상 작업과 에이전트 코딩에 기본 모델로 쓴다.

한눈에 보기

소네트 5.5는 Claude 5.5 패밀리의 주력 중간급 모델이다. 버그 수정이나 문서·슬라이드·스프레드시트 작성처럼 범위가 분명한 일은 소네트 5.5에 맡긴다. 오래 깊이 판단해야 하는 복잡한 일만 오퍼스 5.5로 보내면 된다.

모델위치이럴 때 쓴다가격
오퍼스 5.5최상위열린 질문, 신중한 판단이 필요한 설계가장 비쌈
소네트 5.5중간급일상 코딩, 버그 수정, 문서 작업오퍼스의 절반
하이쿠 5.5경량출시 예정-

effort를 낮춰도 성능이 꽤 나온다

API에서는 모델 ID claude-sonnet-5-5로 부른다. Claude Platform뿐 아니라 AWS, Google Cloud, Microsoft Azure에서도 쓸 수 있다. 컨텍스트는 1M 토큰, 최대 출력은 128K 토큰이다.

effort 기본값은 high지만 꼭 그대로 둘 필요는 없다. low나 medium으로 낮춰도 소네트 5의 최고 성능을 넘는 경우가 많고, 비용은 약 10분의 1로 줄어든다.

상황설정이유
대량 처리 파이프라인low·medium싸게 돌려도 품질이 충분하다
까다로운 디버깅high깊게 생각해야 실수가 준다
열린 설계, 계속 판단해야 하는 일오퍼스 5.5로 넘김판단력은 오퍼스가 낫다

코딩 에이전트로 쓰면 파일을 하나씩 읽지 않고 여러 개를 한꺼번에 요청한다. 덕분에 단계가 줄고 코드베이스를 더 빨리 파악한다.

단가는 소네트 5와 같고, 작업당 비용은 줄었다

토큰 단가는 전작 소네트 5와 똑같다. 그래도 같은 일을 더 적은 토큰으로 끝내기 때문에 작업당 비용은 최대 30% 낮다. 답이 나오는 속도도 30% 넘게 빨라졌다.

오퍼스 5.5$20
소네트 5.5$10

출력 100만 토큰당 가격이다. 입력은 오퍼스 $4, 소네트 $2이고, Batch API를 쓰면 50% 할인된다.

모델 ID만 바꾸면 기존 앱이 깨질 수 있다

공식 문서에는 기존 코드에 영향을 주는 breaking change가 다섯 가지 있다. 가장 눈에 띄는 변화는 도구 호출 사이에 나오던 텍스트가 이제 thinking 블록으로 온다는 점이다. 이 텍스트를 사용자에게 스트리밍해 보여주던 앱이라면 display 값을 설정하거나, between_tools로 도구 호출 사이의 사고를 꺼야 한다.

성능 수치는 대부분 Anthropic이 직접 발표한 것이다. 실제로 맡길 작업으로 비용과 결과를 직접 확인해 보는 게 가장 확실하다.
