Grok (xAI)

Grok은 xAI가 만든 AI 챗봇이자 언어 모델이다. X(옛 트위터)와 웹을 실시간으로 검색해서 답하기 때문에 '지금 무슨 일이 있는지'처럼 최신 정보가 필요한 질문에 쓴다.

한눈에 보기

Grok은 일론 머스크가 세운 xAI가 만든 챗봇이다. 대부분의 챗봇은 학습이 끝난 시점까지만 알지만, Grok은 답할 때마다 X와 웹을 바로 검색한다. 그래서 방금 올라온 소식까지 반영해서 답한다. 속보나 지금 화제인 글을 정리할 때 가장 먼저 떠올릴 만한 모델이다.

이런 작업이라면Grok을 쓸까
속보, 오늘의 여론, 화제글 정리유력한 후보
긴 문서 통째로 넣기, 도구를 많이 부르는 에이전트비용 대안으로 검토
검증된 사실이 가장 중요한 작업다른 모델과 비교 필요

X 앱에서는 태그, 차에서는 음성

가장 흔한 사용법은 X 앱에서 게시물에 Grok을 태그하고 그 글의 맥락을 묻는 것이다. Tesla 차량에도 음성 비서로 들어가 있다. 채팅 말고도 이미지·영상 생성(Grok Imagine), 음성 대화, 코딩까지 한곳에서 할 수 있다.

API는 OpenAI 코드 그대로

기존 OpenAI SDK 코드에서 baseURL만 https://api.x.ai/v1로 바꾸면 Grok이 붙는다. 다른 모델로 '오늘 이 키워드 여론 요약' 대시보드를 만들려면 검색 API를 따로 붙여야 하지만, Grok은 실시간 X 검색이 모델 안에 들어 있다.

주력은 Grok 4.1 계열이다. 긴 입력이나 도구 호출이 많은 작업에는 Grok 4.1 Fast가 맞는데, 컨텍스트가 크고 단가가 낮기 때문이다.

항목Grok 4.1 Fast
컨텍스트 길이200만 토큰
강점도구 호출, 낮은 단가
환각이전 세대의 절반 수준 (xAI 발표)

에이전트 부품은 플랫폼이 대신 든다

Agent Tools API를 쓰면 웹 브라우징, X 검색, 코드 실행, 업로드 문서 조회를 xAI가 직접 제공한다. 검색 API 키나 샌드박스를 따로 관리할 필요 없이, Grok이 필요한 도구를 골라 한꺼번에 부른다. 외부 MCP 서버 연결(Remote MCP)도 된다. 터미널에서는 grok CLI로 코딩 에이전트를 쓸 수 있는데, 여러 하위 에이전트를 동시에 띄워 코드베이스를 탐색하고 고친다.

출처 확인과 버전 고정은 필수

실시간 X 데이터는 검증되지 않은 게시물을 그대로 옮길 위험이 있고, '덜 검열된' 성격 탓에 편향되거나 부적절한 답변으로 여러 번 논란이 됐다. 사실 확인이 중요하면 근거가 된 게시물을 직접 보고 교차검증해야 한다. 모델이 자주 바뀌니 API로 서비스를 만들 때는 모델 버전을 고정해 둬야 답변 스타일이 갑자기 바뀌지 않는다.
