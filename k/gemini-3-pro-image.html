나노 바나나 프로

Nano Banana Pro (Gemini 3 Pro Image)

나노 바나나 프로는 구글의 이미지 생성·편집 모델로, 공식 이름은 Gemini 3 Pro Image다. 이미지 속 글자를 정확히 넣어야 할 때, 인포그래픽처럼 정보가 맞아야 할 때, 여러 참조 이미지로 캐릭터·브랜드를 일관되게 유지해야 할 때 쓴다.

한눈에 보기

나노 바나나 프로는 제미나이 3 프로를 바탕으로 만든 구글의 이미지 모델이다. 예전 이미지 모델이 자주 틀리던 글자와 사실 정보를 정확하게 넣는 데 강하다. 포스터 문구, 인포그래픽, 브랜드가 일관돼야 하는 광고 컷에 쓰고, 빠르게 대량으로 뽑을 때는 Flash 계열로 보낸다.

모델바탕이럴 때 쓴다
나노 바나나Gemini 2.5 Flash가볍고 빠른 생성
나노 바나나 프로Gemini 3 Pro글자 정확도, 인포그래픽, 다중 참조 일관성
나노 바나나 2Gemini 3.1 Flash대량으로 빠르게 뽑기

글자와 정보가 틀리지 않는다

간판 글씨가 뭉개지거나 레시피 순서가 엉터리로 나오던 문제를 겨냥했다. 짧은 문구부터 긴 문단까지 또렷하게 넣고, 여러 언어로 쓰거나 기존 이미지 속 문구를 다른 언어로 바꿀 수 있다. 구글 검색과 연결하면 날씨나 경기 결과 같은 실시간 정보도 그림으로 정리한다.

앱은 간단히, API는 제대로

제미나이 앱에서는 도구 메뉴의 이미지 만들기에서 모델을 Pro로 두면 된다. 기본 모델 결과를 'Pro로 다시 실행'으로 다시 뽑을 수도 있다. 다만 해상도와 입력 이미지 수에 제한이 있다.

Gemini API, AI Studio, Vertex AI에서는 기능을 다 쓸 수 있고, 유료다. 제품 사진·로고·인물 사진을 함께 넣고 "이 인물이 제품을 든 광고 컷, 라벨 폰트는 그대로"처럼 요청하거나, 만든 이미지를 다시 넣어 "라벨 폰트만 바꾸고 조명·구도는 유지"처럼 부분만 고치는 방식이 주력이다.

항목지원 범위
참조 이미지최대 14장 (인물 얼굴 유지 최대 5명)
출력 해상도1K / 2K / 4K
화면비1:1, 16:9, 9:16부터 21:9, 1:8, 8:1까지

같은 비주얼을 썸네일·세로 광고·배너로 비율만 바꿔 뽑을 때 잘 맞는다. 구글 슬라이드·Google Ads, 어도비 Photoshop의 생성형 채우기 안에서도 이 모델을 쓸 수 있다.

시안은 1K, 확정본만 4K

이미지도 토큰으로 과금한다. 참조 이미지를 많이 넣거나 4K로 수십 장 뽑으면 비용이 빠르게 쌓이니, 시안은 1K로 돌리고 확정된 컷만 4K로 다시 뽑는 게 좋다.

입력 이미지560
출력 1K·2K1,120
출력 4K2,000

이미지 한 장당 토큰 수(Google Cloud 문서 기준). 텍스트 토큰은 따로 붙는다.

워터마크와 남은 한계

생성 이미지에는 구글의 AI 생성 표시가 들어가고, 무료 계정 결과물에는 눈에 보이는 워터마크도 붙는다. 이 보이는 워터마크는 Ultra 구독에서만 빠진다. 실사에 가깝다는 평가가 많지만 얼굴이 미세하게 어색하다는 지적이 있고, Pro 기반이라 속도와 비용이 가볍지 않다.
