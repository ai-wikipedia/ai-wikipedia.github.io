뮤즈 원더

Muse Wonder (Meta)

뮤즈 원더는 Meta 슈퍼인텔리전스 랩이 2026년 10월에 처음 내놓은 프론티어급 모델이다. 저지연 경량 모델 뮤즈 스파크와 달리, 사용자를 오래 기억하고 막혀도 포기하지 않아야 하는 몇 시간짜리 에이전트 작업이나 코딩에 쓴다.

모델위치쓰는 곳
뮤즈 스파크경량·저지연빠른 응답이 중요한 일
뮤즈 원더프론티어급 주력Meta Model API, Muse Code
뮤즈 원더 풀최상위Muse Code 구독 전용

상위 모델 뮤즈 원더 풀은 API로 제공되지 않는다.

기억하고, 막혀도 끝까지 간다

핵심 기능은 두 가지다. 액티브 메모리는 여러 대화에 걸쳐 관련된 맥락을 스스로 찾아 이어 붙여서, 며칠이나 몇 주 전에 말한 내용을 다시 설명하지 않아도 된다. 액티브 포커스는 예상치 못한 문제가 생겨도 작업을 사용자에게 돌려보내지 않고 다른 방법을 시도하도록 학습된 성질이다.

그래서 보험 청구 처리, 임대 계약서 검토, 앱 만들기처럼 단계가 많은 일을 맡기기 좋다. 모델이 일을 계획하고 일부를 서브에이전트에게 나눠 주며, 도구를 병렬로 호출하고 오류에서 복구한다. 브라우저·데스크톱·모바일 앱 화면을 보고 조작하는 컴퓨터 사용도 지원한다.

어디서 쓰는지에 따라 구독이 다르다

사용처쓸 수 있는 모델비용
Meta Model API원더토큰당 과금
Muse Code (터미널 코딩 에이전트)원더, 원더 풀월 $50 또는 $200
Muse 개인 에이전트 앱원더 (구독자부터 순차 적용)월 $20 또는 $100

직접 에이전트를 만든다면 API로, 코딩을 맡기려면 Muse Code로, 일상 업무 비서로 쓰려면 Muse 앱 구독으로 접근하면 된다.

API 가격은 최상위 모델급

컨텍스트는 100만 토큰이다. 같은 맥락을 반복해서 보내는 장기 에이전트라면 캐시 입력 가격이 크게 낮아 비용을 줄일 수 있다.

입력$4.00
캐시 입력$0.20
출력$20.00

100만 토큰당 가격. TechCrunch는 GPT-6 Sol이나 오퍼스 5.5와 비슷한 수준으로 평가했다.

생각하는 일은 강하고, 화면 만들기는 아직

실사용 리뷰에서는 병원 청구서 오류 찾기, 개인 재무 분석, 대화 간 기억처럼 꼼꼼히 따져야 하는 일은 대부분 맞혔다. 반면 3D 방 구현처럼 눈에 보이고 클릭하는 결과물은 오퍼스나 GPT 쪽이 조금 앞섰다. 성능 수치 다수는 Meta 발표 기준이고 벤치마크에 맞춘 것 아니냐는 의견도 있으니, 내 작업으로 직접 비교해 보는 게 좋다.

여러 단계짜리 일을 통째로 맡긴다

가장 흔한 방식은 단계가 많은 일을 처음부터 끝까지 맡기는 것이다. 기억하는 능력과 끝까지 붙드는 성질이 강점이라, 한 번에 끝나지 않고 며칠에 걸쳐 이어지는 일일수록 잘 맞는다.
