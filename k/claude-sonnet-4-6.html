클로드 소네트 4.6

Claude Sonnet 4.6 (Anthropic)

Anthropic의 가운데 등급 모델로, Sonnet 가격 그대로 코딩·컴퓨터 사용·에이전트 작업에서 윗급 Opus에 가까운 실력을 낸다. 양이 많은 일상 작업을 싸게 처리할 때 쓴다.

한눈에 보기

Claude Sonnet 4.6은 Anthropic이 2026년 2월에 내놓은 모델로, 세 등급 가운데 가운데인 Sonnet이다. 가격은 Sonnet 그대로인데 실력은 윗급 Opus에 가까워졌다. 코드 리뷰, 문서 작성, 반복 에이전트 작업처럼 양이 많은 일에 알맞다.

등급특징이럴 때 쓴다
Opus가장 똑똑하고 비쌈가장 까다로운 추론
Sonnet 4.6균형형, Opus에 근접일상 코딩, 문서, 에이전트 작업
Haiku빠르고 쌈가볍고 빠른 작업

화면을 직접 다루는 일에 강하다

가장 크게 좋아진 것은 컴퓨터 사용(computer use)이다. 화면을 보면서 마우스를 움직이고 버튼을 누르는 식으로 일하는 능력인데, 윗급 Opus 4.6과 비슷한 수준까지 올라왔다. 웹사이트 양식 채우기나 여러 화면을 오가는 업무 자동화를 맡기면 된다.

강점쓰기 좋은 작업
컴퓨터 사용양식 입력, 화면 업무 자동화
긴 입력 (최대 100만 토큰)큰 코드베이스 탐색, 여러 파일 수정
에이전트 능력여러 단계짜리 일을 스스로 계획하고 끝까지 진행

claude.ai는 기본값, API는 ID 지정

claude.ai와 Claude Cowork에서는 무료·Pro 요금제의 기본 모델이라 따로 설정하지 않아도 쓰게 된다.

API에서는 모델 ID claude-sonnet-4-6을 지정해 부른다. Amazon Bedrock, Google Cloud의 Gemini Enterprise에서도 같은 ID로 쓸 수 있다.

어려운 것만 Opus로 보내 비용 줄이기

비용이 Opus의 몇 분의 일 수준이라 작업 난이도에 따라 모델을 나눠 쓰면 좋다. 정말 어려운 추론만 Opus에 보내고, 나머지는 Sonnet 4.6으로 돌리면 전체 비용이 크게 줄어든다.

작업보낼 모델
최고 난이도 추론, 품질을 양보할 수 없는 일Opus
코드 리뷰, 문서 작성, 반복 에이전트 작업Sonnet 4.6

이름이 같아도 Opus 4.6과 동급은 아니다

버전 숫자가 같다고 Opus 4.6과 실력이 같은 것은 아니다. 가장 까다로운 문제에서는 여전히 Opus가 앞선다. Sonnet 4.6은 성능 대비 가격으로 고르는 모델이다.
