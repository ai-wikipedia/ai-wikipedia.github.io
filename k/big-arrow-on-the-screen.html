빅 애로우 온 더 스크린

big-arrow-on-the-screen (Agent Screen Annotation Skill)

AI 에이전트가 사람이 직접 눌러야 하는 버튼이나 창을 맥 화면 위에 큰 화살표와 안내 문구로 가리키게 해 주는 macOS CLI이자 Claude Code·Codex용 스킬이다. 권한 승인, 2FA, 결제 확인처럼 에이전트가 대신 처리하면 안 되는 단계에서 쓴다.

한눈에 보기

빅 애로우 온 더 스크린(bigarrow)은 사람의 손이 필요한 순간에 AI 에이전트가 맥 화면의 실제 버튼 위에 큰 화살표와 안내 문구를 띄우게 해 주는 도구다. 에이전트가 터미널에 "Allow를 클릭하세요"라고 써 놔도 사람은 그 터미널을 안 보고 있을 때가 많다. 이 도구는 그 문구를 화면 위 해당 버튼에 바로 띄워서 이 문제를 푼다.

하는 일하지 않는 일
화살표·테두리 원·상자·문구 표시클릭·입력 대신 하기
안내 문구를 음성으로 읽기스크린샷 찍기
클릭을 아래 앱으로 그대로 넘기기포커스 빼앗기

에이전트가 멈추는 지점에서 쓴다

버튼 위치는 알아도 에이전트가 직접 누를 수 없거나, 눌러서는 안 되는 단계가 주 대상이다. 에이전트가 가리키면 사람이 판단해서 누르고, 그다음 작업을 에이전트가 이어 간다.

상황이렇게 쓴다
macOS 권한 요청, OAuth 동의눌러야 할 버튼에 화살표
2FA, CAPTCHA, 패스키, 결제 확인사람이 결정하는 칸을 표시
Chrome 창이 여러 개일 때특정 창이나 탭을 콕 집어 안내
단계별 설정·온보딩표시 → 조작 대기 → 지우기 반복

사람이 자리를 비웠을 것 같으면 --say로 문구를 소리 내어 읽어 부를 수 있다. 데모나 문서를 만들 때는 --png로 화살표를 이미지에 그려 넣을 수 있다.

설치는 두 줄, 사용 규칙은 스킬이 알려 준다

brew install franzenzenhofer/tap/bigarrow로 설치하고 bigarrow install-skill을 실행하면 Claude Code와 Codex에 스킬이 깔린다. 스킬은 에이전트에게 언제 가리킬지, 대상을 어떻게 고를지 알려 준다. 표지에는 완전한 문장을 쓰고, 사람이 화면을 안 볼 땐 --say를 붙이고, 사람이 누르고 나면 stop으로 지우라는 규칙도 들어 있다.

옵션쓰임
--style ring|box테두리만 그려 아래 내용이 그대로 보임
--shape zigzag정말 급한 일을 알릴 때
--follow창이나 요소가 움직여도 따라감
--until-click대상을 클릭하면 저절로 사라짐

권한은 적게, 대신 macOS 전용

작은 Swift 바이너리라서 그리기만 할 때는 권한이 필요 없다. 다만 UI 요소를 이름으로 찾으려면 손쉬운 사용이나 화면 기록 권한을 줘야 한다. 대상은 좌표, 창, UI 요소 이름, Peekaboo 결과로 지정한다. 좌표가 맞는지 불안하면 --dry-run --json으로 실제로 그리지 않고 표시될 위치만 확인할 수 있다. macOS에서만 돌아가는 MIT 라이선스 도구다. README의 상황별 데모는 실제 bigarrow로 녹화했지만, 화면에 나오는 대화상자는 연출용 가짜다.
