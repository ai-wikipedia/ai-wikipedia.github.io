맥파이

Magpie (Multi-Model Switcher for Coding Agents)

맥파이는 내 컴퓨터에서 돌아가는 오픈소스 게이트웨이이자 모델 전환 도구다. Codex, Claude Code, Gemini CLI 같은 코딩 에이전트가 쓰는 모델을 메뉴 막대 한 곳에서 바꿀 수 있다. 에이전트를 원래 회사가 아닌 다른 업체의 모델이나 로컬 모델로 돌리고 싶을 때 쓴다.

한눈에 보기

코딩 에이전트는 저마다 말하는 API 형식이 다르다. Codex는 OpenAI Responses, Claude Code는 Anthropic Messages, Gemini CLI는 Google 형식만 쓴다. 맥파이는 127.0.0.1:3425에 로컬 게이트웨이를 띄우고 이 세 형식을 서로 바꿔 준다. 그래서 어떤 에이전트든 어떤 모델로든 돌릴 수 있다. Go로 만들었고 MIT 라이선스다.

예시 조합원래 쓰는 형식맥파이가 하는 일
Codex + 딥시크OpenAI Responses딥시크 API 형식으로 번역
Claude Code + 키미Anthropic Messages키미 형식으로 번역
Claude Code + 올라마Anthropic Messages로컬 모델로 연결

번역 범위에는 스트리밍, 도구 호출, 추론(reasoning)까지 들어간다.

프로바이더 등록 후 클릭 한 번으로 전환

먼저 쓸 모델 업체를 등록한다. 미리 준비된 업체는 magpie provider add deepseek sk-...처럼 키만 넣으면 되고, 로컬 모델은 magpie provider add ollama로 붙인다. 중계 서버는 url, key, models 값을 직접 적어서 추가한다. magpie providers, magpie models로 등록 상태를 확인할 수 있다.

그다음 메뉴 막대 패널을 열면 내 PC의 에이전트 목록과 각자 지금 쓰는 모델이 보인다. 값을 누르면 등록한 모든 모델이 provider/model 형식으로 검색 목록에 뜨고, 고르면 끝이다. 맥파이는 에이전트 설정 파일에서 모델 키 하나만 원자적으로 고쳐 쓰고, 주석·순서·서식은 그대로 둔다. 화면이 없는 서버라면 magpie tui로 터미널에서 같은 작업을 한다.

프로필과 페일오버로 일하는 흐름 지키기

기능이럴 때 쓴다
프로필"Budget", "Focus"처럼 모든 에이전트 설정을 묶어 저장했다가 프로젝트를 바꿀 때 한꺼번에 전환
라우팅 그룹한 계정 할당량이 떨어지면 다음 계정이나 모델로 넘어가고, 에이전트에는 오류가 보이지 않음
웹 검색 연결검색을 못 하는 모델에 Tavily·Brave·Exa 같은 검색 API를 정한 순서대로 붙임
사용량 추적에이전트별 토큰, 캐시 적중, 비용 확인

이미 내는 구독도 연결된다

API 키만 되는 게 아니다. 로그인해 둔 Claude, ChatGPT, Copilot, Gemini, Grok 요금제도 프로바이더로 쓸 수 있어서, 이미 돈을 내는 구독을 다른 에이전트에 연결할 수 있다. 지원하는 업체는 40곳이 넘는다.

바뀌는 속도가 빠르다

공개 후 3주 남짓 동안 커밋이 수천 개 쌓일 만큼 빠르게 바뀌고 있다. 업데이트 뒤에는 쓰던 에이전트와 모델 조합이 잘 돌아가는지 다시 확인하는 게 좋다. 구독을 다른 에이전트에 연결해 쓸 때는 그 서비스 약관도 직접 확인해 두자.
