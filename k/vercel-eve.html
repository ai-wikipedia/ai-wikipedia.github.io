Eve (Vercel Agent Framework)

eve는 Vercel이 오픈소스로 공개한 에이전트 프레임워크로, 마크다운과 TypeScript 파일을 담은 폴더 하나를 실제 운영용 에이전트 서비스로 만들어 배포해 준다. Vercel 위에서 Slack 봇이나 정기 리포트 같은 에이전트를 직접 연결 작업 없이 빨리 띄우고 싶을 때 쓴다.

한눈에 보기

eve는 폴더 구조가 곧 에이전트 설계도인 프레임워크다. 지시문은 마크다운으로, 도구는 TypeScript 파일로 정해진 위치에 넣으면 eve가 이를 묶어 중단돼도 이어서 실행되는 서비스로 만들어 Vercel에 배포한다. 현재 베타이며 Apache-2.0 라이선스로 공개돼 있다.

폴더·파일담는 내용필수 여부
지시문 마크다운에이전트의 역할과 말투필수
도구 파일 (.ts)파일 하나가 도구 하나, 파일명이 곧 도구 이름선택
skills, 서브에이전트 폴더필요할 때 불러오는 절차서, 하위 에이전트선택
schedules/, agent.tscron 정기 실행, 모델·런타임 설정선택

등록 코드 없이 파일만 추가한다

보통 프레임워크는 도구를 만들고 나서 따로 등록해야 하지만, eve는 도구 폴더에 파일을 넣기만 하면 된다. 스킬은 에이전트가 필요할 때만 꺼내 읽는 마크다운 절차서라서, 긴 업무 매뉴얼을 처음부터 프롬프트에 다 넣지 않아도 된다. 특정 분야 일은 서브에이전트 폴더로 떼어 내면, 메인 에이전트가 일을 나눠 맡기고 결과를 합친다.

운영에 필요한 부품이 기본으로 들어 있다

직접 만들면 손이 많이 가는 부분을 eve가 Vercel 인프라로 채워 준다.

기능하는 일
내구성 실행단계마다 체크포인트를 남기고, 메시지를 기다리다 이어서 실행
샌드박스코드 실행을 격리된 환경에서 처리
승인 게이트확인이 필요한 도구는 사람이 승인할 때까지 세션을 멈춰 둠
채널한 코드로 웹 채팅, Slack, Teams, API, CLI, cron에 배포

시작은 defineAgent 한 줄부터

스캐폴드를 만든 뒤 npm run dev로 띄우면 바로 동작하는 에이전트가 생긴다. 모델을 바꾸려면 agent.ts에서 defineAgent로 모델 ID와 추론 강도를 지정한다. Claude Code에 Vercel 플러그인을 붙여 스캐폴드부터 실행, 배포까지 프롬프트만으로 맡기는 방법도 있다. 매일 아침 보내는 리포트라면 schedules/에 cron 표현식과 할 일을 적어 두면 세션을 열어 두지 않아도 돌아간다.

Vercel 전용이라는 점은 미리 알아 둔다

eve는 Vercel에 맞춘 에이전트를 위해 설계됐다. 여러 클라우드를 오가야 하거나 자체 호스팅이 중요한 팀이라면 Mastra처럼 이식성이 높은 프레임워크가 더 맞는다는 평가가 있다. Agent Runs 화면에서 세션, 턴, 토큰 사용량은 볼 수 있지만, 실행이 시작되기 전에 이벤트가 전달되지 않으면 추적할 기록 자체가 남지 않는다. 베타라서 API가 바뀔 수 있으므로 버전을 고정하고, 중요한 업무에 쓰기 전에 시범 운영을 거치는 것이 안전하다.
