Superpowers

Claude Code가 코드부터 짜지 않고 브레인스토밍·계획·테스트·리뷰 순서를 따르게 만드는 오픈소스 스킬 묶음(플러그인)이다. 복잡한 기능 개발이나 디버깅처럼 절차가 필요한 작업에 쓴다.

한눈에 보기

Superpowers는 Claude Code에 개발 절차를 지키게 하는 플러그인이다. 그냥 맡기면 곧장 코드부터 쓰다가 테스트를 건너뛰고 엉성한 결과를 내기 쉬운데, 이걸 설치하면 요구사항 정리 → 계획 → 테스트 → 리뷰 순서를 거친다. 복잡한 기능을 만들거나 버그를 잡을 때 쓰면 좋다.

단계하는 일관련 스킬
요구사항 정리아이디어를 먼저 다듬는다brainstorming
테스트 먼저테스트를 짜고 나서 구현한다test-driven-development
작업 나눠 맡기기작업마다 서브에이전트를 띄운다subagent-driven-development
리뷰스펙과 코드 품질을 확인한다requesting-code-review

설치 후 평소처럼 말하면 된다

Claude Code 플러그인 마켓플레이스에서 /plugin install superpowers@superpowers-marketplace로 설치한다. 그다음엔 "이 기능 같이 계획해보자", "이 버그 디버깅하자"처럼 평소대로 말하면 상황에 맞는 스킬이 알아서 켜진다.

에이전트는 "브레인스토밍 스킬로 먼저 아이디어를 다듬겠습니다"처럼 어떤 스킬을 쓰는지 먼저 말하고 나서 절차를 밟는다. 스킬은 작업별 절차서를 담은 마크다운 파일이다.

규칙이 꽤 엄격하다

코드를 건드리기 전에 git worktree로 따로 떨어진 개발 브랜치부터 만든다. 테스트보다 구현 코드를 먼저 쓰면 그 코드를 지우고 테스트부터 다시 시작하게 한다. 끝났다고 말하기 전에는 스펙을 지켰는지, 코드 품질은 괜찮은지 스스로 검토한다.

큰 작업은 서브에이전트에게 나눠 맡긴다

작업이 여러 개면 계획서의 작업마다 새 서브에이전트가 하나씩 맡고, 끝날 때마다 스펙 준수 → 코드 품질 순서로 두 번 리뷰를 받는다. 메인 세션은 코드를 직접 쓰지 않고 지휘·리뷰·진행 확인만 한다. 그래서 즉흥적인 바이브 코딩보다 스펙을 따르는 개발에 가까운 결과가 나온다. Codex CLI, Cursor, Gemini CLI 같은 다른 도구에서도 같은 스킬을 쓸 수 있도록 넓혀 가는 중이다.

간단한 작업엔 오히려 느리다

절차를 강제하는 만큼 단순한 작업에도 브레인스토밍과 계획 단계가 끼어들어 토큰과 시간이 더 든다. 기존 코드가 많은 대형 프로젝트에서는 이 앞단계가 실제 구현에 써야 할 컨텍스트를 잡아먹을 수 있다. 만들어진 코드는 직접 확인한 뒤에 프로덕션에 올리는 게 안전하다.
