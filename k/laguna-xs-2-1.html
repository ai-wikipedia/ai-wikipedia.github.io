Laguna XS 2.1

Poolside Laguna XS 2.1

Poolside가 만든 33B 규모의 코딩 특화 MoE 모델로, 토큰당 3B만 계산에 쓴다. 내 컴퓨터에서 에이전트 코딩이나 여러 단계로 이어지는 터미널 작업을 돌리고 싶을 때 쓴다.

한눈에 보기

Laguna XS 2.1은 Poolside가 만든 코딩 특화 모델이다. 전체 크기는 33B지만 토큰 하나를 만들 때 3B만 계산에 쓰는 MoE 구조여서, 내 컴퓨터에서 돌릴 수 있는 에이전트 코딩 모델이 필요할 때 고른다. 코드 수정이나 터미널 명령 실행처럼 여러 단계를 이어 가는 긴 작업에 맞춰져 있다.

항목내용
전체 파라미터33B
토큰당 쓰는 파라미터3B
최대 컨텍스트256K 토큰
라이선스OpenMDW-1.1

크게 알고 작게 계산한다

MoE는 모델 안에 여러 '전문가' 묶음을 두고, 입력마다 필요한 몇 개만 골라 쓰는 방식이다. 그래서 계산량은 3B급 소형 모델에 가깝지만, 담고 있는 지식은 33B 규모에서 나온다.

다만 지금 쓰지 않는 전문가도 메모리에는 올라가 있어야 한다. 답하는 속도는 작은 모델처럼 빠르지만, 필요한 메모리는 33B 모델 기준으로 잡아야 한다.

로컬은 Ollama, 클라우드는 OpenRouter

RAM이 36GB인 Mac이라면 ollama run laguna-xs-2.1 한 줄로 바로 실행된다. Claude Code, Codex App, OpenCode처럼 Ollama에 연결할 수 있는 에이전트 도구에서 이 모델을 지정하면, 코드가 외부로 나가지 않는 로컬 코딩 에이전트가 된다.

실행 방식이럴 때 쓴다
Ollama내 Mac·PC에서 바로 써 보기
vLLM, SGLang, TRT-LLM팀용 서버를 직접 띄울 때
Transformers, Llama.cpp직접 실험하거나 가벼운 환경에 올릴 때
OpenRouter API메모리가 부족하거나 긴 컨텍스트가 필요할 때

위 실행 도구들은 출시 당일부터 지원됐다.

XS.2와 구조는 같고, 코드 수정이 더 낫다

이전 버전 XS.2를 다듬은 업그레이드판이다. 구조는 그대로지만 여러 프로그래밍 언어로 된 코드를 고치는 작업과 터미널 작업 성능이 올라갔다. 새로 시작한다면 2.1을 고르면 된다.

성능 수치는 Poolside가 발표한 것이다. 아주 어려운 설계나 디버깅은 더 큰 클라우드 모델이 나을 수 있으니, 실제로 맡길 저장소에서 직접 시험해 보는 게 확실하다.

라이선스가 바뀌었다

버전라이선스
XS.2Apache 2.0 (완전 오픈 소스)
XS 2.1OpenMDW-1.1

XS.2와 조건이 다르므로, 상업 서비스에 넣거나 파인튜닝해서 배포하려면 OpenMDW-1.1 조건을 먼저 확인해야 한다.
