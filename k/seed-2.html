시드 2.0

ByteDance Seed 2.0

틱톡을 만든 바이트댄스가 내놓은 LLM 계열로, 일상 대화부터 코딩·복잡한 실무 작업까지 대규모 서비스 환경에서 안정적으로 처리하도록 다듬은 모델이다.

수억 명이 쓰는 서비스를 위해 다시 설계한 모델

Seed 2.0은 틱톡을 만든 바이트댄스의 AI 연구 조직 Seed 팀이 2026년 2월 공개한 언어 모델 시리즈다. 바이트댄스의 챗봇 Doubao와 코딩 도구 Trae 같은 서비스는 매일 수억 명이 쓰고, 하루 토큰 사용량은 500배로 불어났다. 이 규모에서는 벤치마크 점수 몇 점보다 빠른 응답, 낮은 비용, 복잡한 지시를 정확히 수행하는 안정성이 더 중요해진다. 그래서 Seed 2.0은 처음부터 대규모 운영 환경을 기준으로 다듬어졌다.

모델 카드는 실제 사용 데이터 분석을 설계 근거로 든다. 상당수 질문이 스크린샷, 차트, 스캔 문서 같은 이미지를 포함하고, 응답 지연이 만족도를 직접 좌우하며, 사용자는 여러 단계로 된 복잡한 지시를 자주 내린다. 이에 맞춰 이미지 이해에서의 환각을 줄이고, 문서와 도표에서 구조화된 정보를 뽑는 능력을 강화하고, 복잡한 지시 수행을 핵심 요구사항으로 다뤘다. 코딩 쪽 분석도 흥미로운데, 에이전트 코딩 요청은 프런트엔드 작업과 버그 수정이 압도적으로 많았고, 프레임워크는 중국 개발 생태계답게 Vue.js가 React의 세 배를 넘었다. 작업 종류로는 버그 수정 다음이 리팩토링과 문서 작업이었는데, 개발자들이 AI를 새 기능을 만드는 데보다 기존 코드를 고치고 유지하는 데 더 많이 쓴다는 뜻으로 해석했다.

평가 방식도 이런 방향을 따른다. Seed 팀은 과학적 발견, 바이브 코딩, 문맥 속 학습, 실제 업무 과제라는 네 축의 평가 틀을 만들어, 경시대회 문제보다 여러 단계에 걸친 실무를 끝까지 해내는지를 재려 했다. 사람의 선호를 겨루는 공개 순위표 LMSYS Chatbot Arena에서는 2026년 2월 기준 텍스트 6위, 비전 3위에 올랐다.

Pro, Lite, Mini 고르는 법

시리즈는 세 크기로 나뉜다. Pro는 길게 이어지는 추론과 긴 문맥 작업, Lite는 품질과 속도의 균형을 맞춘 범용 모델, Mini는 처리량과 배포 밀도를 최우선으로 한 대량 처리용이다. 모델 카드에 실린 중국 내 대표 가격은 100만 토큰당 Pro가 입력 0.47달러·출력 2.37달러, Lite가 0.09달러·0.53달러, Mini가 0.03달러·0.31달러다. 바이트댄스는 비슷한 사용자 경험을 내는 해외 프론티어 모델보다 토큰 가격이 대략 한 자릿수 낮다고 주장한다. 해외에서 쓰는 BytePlus나 OpenRouter의 가격은 이와 다르니 따로 확인해야 한다.

고르는 기준은 단순하다. 비정형 문서를 대량으로 분석해 보고서로 정리하거나 고객 문의를 분류하는 반복 작업이라면 Mini나 Lite로 충분하고, 연구 수준의 추론이나 긴 에이전트 작업에만 Pro를 쓰는 식으로 나누면 된다. 4월에는 Lite가 영상, 이미지, 오디오, 텍스트를 함께 이해하는 옴니모달 모델로 업그레이드됐다.

어떻게 쓰나

Seed 2.0 본체는 가중치를 공개하지 않는 폐쇄형이라 API로만 쓴다. 중국 내에서는 Volcano Engine의 Ark 플랫폼에서 Doubao-Seed-2.0-pro 같은 모델 ID로 호출하고, 해외 개발자는 BytePlus ModelArk나 OpenRouter를 거친다. OpenRouter에서는 bytedance-seed/seed-2.0-mini처럼 모델 이름만 바꾸면 기존 OpenAI 호환 코드에서 그대로 부를 수 있다. 공식 GitHub 쿡북에는 코드 에이전트, 검색 에이전트, MCP 도구 사용, 이미지를 보며 생각하기, 영상 이해 예제가 정리돼 있어 출발점으로 삼기 좋다.

스스로 밝힌 약점

모델 카드에서 눈에 띄는 대목은 한계를 직접 적었다는 점이다. 바이트댄스는 Seed 2.0이 여전히 해외 최상위 모델과 격차가 있다고 인정하며, 코딩에서는 Claude에 상당히 뒤지고, 사용자 경험과 직결되는 롱테일 지식에서는 Gemini에 뒤진다고 명시했다. 따라서 복잡한 코드베이스를 다루는 코딩 에이전트의 주력 모델보다는, 비용이 중요한 대량 처리와 멀티모달 이해 작업에서 장점이 크다. 이름이 비슷한 영상 생성 모델 Seedance 2.0과 자주 혼동되는데, Seed 2.0은 텍스트와 이미지를 이해하는 언어 모델이고 Seedance는 영상을 만드는 모델이다.
