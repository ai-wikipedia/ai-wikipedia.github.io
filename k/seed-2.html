시드 2.0

ByteDance Seed 2.0

틱톡을 만든 바이트댄스의 언어 모델 시리즈다. 문서·이미지 분석이나 대량 분류처럼 비용이 중요한 작업을 싸고 빠르게 처리할 때 쓴다.

한눈에 보기

Seed 2.0은 바이트댄스가 2026년 2월 공개한 언어 모델 시리즈다. 수억 명이 쓰는 자사 서비스에 맞춰 만들어서 빠른 응답과 낮은 비용을 앞세운다. 크기는 세 가지이고 작업 난이도에 따라 고르면 된다.

모델성격이럴 때 쓴다
Pro최상위연구 수준 추론, 긴 문맥, 오래 도는 에이전트
Lite균형형일반 업무. 영상·이미지·오디오도 함께 이해
Mini대량 처리용문의 분류, 문서 대량 분석처럼 반복되는 일

이미지와 복잡한 지시에 강하다

스크린샷, 차트, 스캔 문서처럼 이미지가 섞인 질문을 잘 다루도록 다듬었다. 문서와 도표에서 정보를 뽑아 정리하는 일, 여러 단계로 된 지시를 끝까지 따르는 일을 특히 신경 썼다. 4월에는 Lite가 영상·이미지·오디오·텍스트를 함께 이해하는 모델로 업그레이드됐다.

Mini와 Lite는 훨씬 싸다

반복 작업은 Mini나 Lite로 충분하고, 어려운 추론이나 긴 에이전트 작업에만 Pro를 쓰면 비용을 크게 줄일 수 있다.

Pro$2.37
Lite$0.53
Mini$0.31

중국 내 기준 출력 100만 토큰당 가격. 입력은 Pro $0.47, Lite $0.09, Mini $0.03이다. BytePlus·OpenRouter 가격은 다르니 따로 확인한다.

API로만 쓴다

가중치는 공개하지 않아 API로만 쓸 수 있다. 쓰는 곳에 따라 플랫폼과 모델 ID가 다르다.

어디서플랫폼모델 ID 예시
중국 내Volcano Engine ArkDoubao-Seed-2.0-pro
해외BytePlus ModelArk, OpenRouterbytedance-seed/seed-2.0-mini

OpenRouter에서는 기존 OpenAI 호환 코드에서 모델 이름만 바꾸면 바로 부를 수 있다. 공식 GitHub 쿡북에 코드 에이전트, 검색 에이전트, MCP 도구 사용, 영상 이해 예제가 있어 처음 시작하기 좋다.

코딩 주력으로는 아쉽다

바이트댄스 스스로 코딩은 Claude에, 폭넓은 지식은 Gemini에 뒤진다고 밝혔다. 복잡한 코드베이스를 맡는 코딩 에이전트보다는 비용이 중요한 대량 처리와 이미지·문서 이해에 쓰는 게 낫다. 이름이 비슷한 Seedance 2.0은 영상을 만드는 모델로, Seed 2.0과는 다르다.
