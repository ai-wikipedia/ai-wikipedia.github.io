Devin

Devin은 Cognition이 만든 자율형 AI 소프트웨어 엔지니어로, 브라우저·에디터·터미널을 스스로 다루며 코딩 작업을 끝까지 처리한다. 범위가 분명한 작업을 Slack이나 웹으로 맡겨 두고, 결과는 PR로 받아 검토할 때 쓴다.

한눈에 보기

Devin은 Cognition이 만든 자율형 AI 소프트웨어 엔지니어다. 2024년 3월 공개되면서 "AI 소프트웨어 엔지니어"라는 개념을 처음 널리 알렸다. 옆에서 한 줄씩 거드는 도구와 달리, 일을 맡기면 자기 작업 환경에서 혼자 처리한 뒤 결과를 돌려준다.

방식사람이 하는 일형태
코드 자동완성직접 코딩, AI는 제안만에디터 플러그인
대화형 코딩 에이전트옆에서 지켜보며 승인Claude Code 같은 터미널 도구
Devin일을 맡기고 결과만 검토원격 작업 환경 + Slack·웹

브라우저·에디터·터미널을 혼자 쓴다

Devin은 클라우드에 있는 별도 작업 환경에서 개발자가 쓰는 도구를 직접 다룬다. 브라우저로 문서를 찾아 읽고, 터미널에서 명령과 테스트를 돌리고, 에디터에서 파일을 고친다. 오류가 나면 메시지를 보고 다시 시도하는 일도 스스로 되풀이한다.

작업은 비동기로 진행된다. 지시해 두고 다른 일을 하다가 끝났다는 알림을 받으면 된다. 진행 중에 작업 화면을 들여다보거나 방향을 바꿀 수도 있다.

Slack으로 맡기고 PR로 받는다

순서할 일
1. 연결GitHub 저장소와 Slack을 연결한다
2. 지시Slack에서 Devin을 부르거나 웹 앱에 작업을 적는다
3. 계획 확인Devin이 세운 계획을 보고 필요하면 고친다
4. 결과 검토올라온 풀 리퀘스트(PR)를 리뷰하고 병합한다

예를 들어 "이 API의 응답 형식을 v2로 마이그레이션해줘"라고 맡기면 코드를 읽고 고친 뒤 테스트까지 돌리고 PR을 올린다. 지시할 때 대상 파일, 완료 기준, 돌려야 할 테스트를 같이 적어 두면 결과가 훨씬 정확해진다.

범위가 분명한 일에 맞는다

잘 맞는 일덜 맞는 일
라이브러리 업그레이드, 마이그레이션요구사항이 모호한 새 설계
버그 수정, 테스트 추가제품 방향을 정해야 하는 일
작은 작업 여러 건 동시 처리바로 대화하며 고칠 일

눈앞에서 빠르게 주고받으며 고칠 일은 에디터나 터미널에서 바로 대화하는 도구가 편하다. 작은 작업 여러 개를 한꺼번에 맡겨 두고 결과만 모아 보고 싶을 때 Devin 방식이 잘 맞는다.

결과물은 사람이 꼭 검토한다

스스로 하는 일이 많은 만큼 검토가 중요하다. 테스트를 통과했더라도 의도와 다르게 고쳤거나 필요 없는 변경이 섞여 있을 수 있다. 그래서 PR은 사람이 만든 것과 같은 기준으로 리뷰한다.

저장소나 외부 서비스 권한은 작업에 필요한 만큼만 준다. 쓴 만큼 비용이 나가는 방식이라, 길고 모호한 작업일수록 비용도 늘어난다.
