OpenAI Codex

OpenAI가 만든 AI 코딩 에이전트로, 할 일을 문장으로 주면 클라우드 샌드박스나 내 터미널에서 코드를 읽고 고치고 테스트까지 돌린 뒤 변경 내용을 돌려준다. 버그 수정·테스트 추가 같은 작업을 맡기고 결과를 리뷰만 하고 싶을 때 쓴다.

쓰는 곳어디서 실행되나이럴 때 쓴다

Codex CLI내 터미널지금 보는 코드를 바로 같이 고치기
IDE 확장에디터 안에디터를 떠나지 않고 작업하기

클라우드는 맡기고, CLI는 같이 한다

클라우드는 ChatGPT에서 GitHub 저장소를 연결해 쓴다. 작업마다 따로 샌드박스가 만들어져 여러 작업을 병렬로 돌릴 수 있고, 끝나면 변경 내용과 실행 로그를 확인한 뒤 PR로 올린다. 기다리는 동안 다른 일을 할 수 있어 반복적인 버그 수정, 테스트 추가, 문서 갱신에 잘 맞는다.

CLI는 오픈소스로 공개되어 있다. npm install -g @openai/codex로 설치하고 프로젝트 폴더에서 codex를 실행한 뒤 ChatGPT 계정이나 API 키로 로그인한다. 파일 수정이나 명령 실행 전에 얼마나 승인을 받을지 정할 수 있어, 처음에는 하나하나 확인하다가 익숙해지면 자동 범위를 넓히면 된다.

AGENTS.md로 규칙을 알려준다

저장소에 AGENTS.md 파일을 두면 Codex가 작업 전에 읽는다. 테스트 실행 명령, 코드 스타일, 건드리면 안 되는 폴더를 적어 두면 결과물 품질이 눈에 띄게 안정된다. Claude Code의 CLAUDE.md와 같은 역할이다.

맡기기 좋은 일, 아닌 일

범위가 분명하고 테스트로 확인할 수 있는 작업이 가장 잘 된다. "이 함수에 실패하는 테스트를 고쳐줘"처럼 끝이 명확하면 결과를 믿고 리뷰하기 쉽다. 반대로 요구사항이 모호한 설계나 여러 서비스에 걸친 큰 구조 변경은 사람이 방향을 잡고 작은 작업으로 쪼개 맡기는 편이 낫다.

결과는 반드시 리뷰한다. 테스트가 통과해도 의도와 다르게 고쳤을 수 있고, 클라우드 샌드박스는 실제 운영 환경과 설정이 다를 수 있다.

2021년의 Codex와는 다르다

같은 이름의 예전 Codex는 코드 생성용 언어 모델로, 초기 GitHub Copilot의 바탕이었고 지금은 서비스가 종료됐다. 지금 말하는 Codex는 모델 하나가 아니라 작업을 직접 수행하는 에이전트 제품이다. 처음에는 o3를 코딩에 맞게 다듬은 모델로 출발했고, 이후 전용 모델이 계속 바뀌고 있다.

작은 일은 클라우드에 맡기고, 큰 일은 터미널에서 같이

가장 흔한 방식은 끝이 분명한 작은 작업 여러 개를 클라우드에 동시에 맡겨 두고, 결과를 PR로 받아 리뷰하는 것이다. 방향을 잡아야 하는 작업은 터미널이나 에디터에서 Codex와 대화하며 한 단계씩 진행한다.

어디서어떻게 쓰나
클라우드 (ChatGPT)버그 수정·테스트 추가·문서 갱신을 여러 개 병렬로 맡기고, 로그를 확인한 뒤 PR로 올리기
터미널 (CLI)지금 작업 중인 저장소에서 같이 고치기 — 처음엔 승인을 하나씩 받다가 익숙해지면 자동 범위를 넓히기
에디터 (IDE 확장)보고 있는 파일을 바로 고치거나 설명을 들으며, 큰 작업은 클라우드로 넘기기
