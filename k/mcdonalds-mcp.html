맥도날드 MCP

McDonald's China MCP Server

맥도날드 중국이 직접 운영하는 공식 원격 MCP 서버다. Claude Code나 Cursor 같은 AI 클라이언트에 연결하면 AI가 메뉴 조회, 쿠폰 받기, 포인트 교환, 실제 주문까지 대신 처리한다.

항목내용
운영 주체맥도날드 중국 공식
사용 가능 지역중국 본토만 (홍콩·마카오·대만 제외)
방식원격 호스팅, Streamable HTTP, 토큰 인증
비용무료

설치할 것이 없다. 맥도날드가 서버를 직접 돌리기 때문에 클라이언트 설정에 접속 주소와 토큰만 넣으면 된다.

토큰 하나 받고 JSON 붙여넣으면 끝

맥도날드 MCP 개방 플랫폼에서 휴대폰 번호로 로그인한 뒤, 콘솔에서 활성화 버튼을 누르고 서비스 약관에 동의하면 MCP 토큰이 발급된다. 이후 GitHub 가이드에 있는 설정 JSON을 복사해 클라이언트에 붙이고, YOUR_MCP_TOKEN 자리를 받은 토큰으로 바꾼다.

Cursor라면 설정 → Tools & MCP → Add Custom MCP에서 mcp.json에 붙여넣고 저장한 다음, 에이전트 대화창에서 원하는 걸 말하면 AI가 알아서 도구를 호출한다. TRAE 등 다른 클라이언트도 같은 방식이다.

쿠폰 조회에서 실제 주문까지 넓어졌다

처음에는 이벤트 캘린더와 쿠폰 받기만 됐는데, 몇 달마다 업데이트되면서 주문 기능이 붙었다.

버전추가된 기능
1.0.0 (2025-12)맥맥 캘린더, 쿠폰 받기
1.0.1~1.0.2영양 정보, 맥딜리버리 주문, 포인트 교환권
1.0.3 (2026-04)매장 픽업, 단체 주문
1.0.4 (2026-05)포인트로 실물 교환, 쇼핑몰 주문 조회, 드라이브스루, 예약 주문

주문할 때는 매장 코드와 주문 유형(매장 픽업, 배달, 드라이브스루, 단체 주문)을 함께 넘겨야 해서, 보통 AI가 근처 매장 조회 → 메뉴 조회 → 주문 순으로 도구를 이어 부른다.

결제 전에는 사람이 확인한다

실제 돈이 나가는 서비스라 주문과 결제는 마지막 단계에서 사용자가 직접 확인해야 한다. 세트 안의 단품을 바꾸는 기능은 아직 없다. 예시 설정과 코드는 개인적·비상업적 용도로만 쓸 수 있고, 맥도날드 중국 이용약관을 따라야 한다.
