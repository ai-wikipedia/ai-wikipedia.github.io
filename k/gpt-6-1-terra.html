GPT-6.1 Terra (OpenAI)

OpenAI GPT-6.1 라인업의 중간급 실무 모델로, 이미지 분석·화면 조작·문서 작성처럼 양이 많은 일을 GPT-6.1 Sol의 절반 가격으로 처리할 때 쓴다.

모델위치이럴 때 쓴다가격 (입력/출력)
GPT-6.1 Sol주력복잡한 코딩, 긴 에이전트 작업$2 / $10
GPT-6.1 Terra중간대량 실무, 화면 조작, 이미지 해석$1 / $5
GPT-6 Luna경량단순 반복 작업$0.10 / $0.50

GPT-6가 나올 때 Terra급이 빠져서, Sol은 느리고 비싸며 Luna는 실수가 잦다는 불만이 많았다. 6.1 Terra는 그 빈 중간 자리를 다시 채운 모델이다.

가격은 반, 할 수 있는 일은 더 많다

이전 Terra와 6.1 Sol보다 API 가격이 절반이다. Artificial Analysis 측정에서는 최고 추론 강도 기준 과제 하나를 처리하는 비용도 이전 Terra의 3분의 1 이하로 떨어졌다.

GPT-5.6 Terra$12
GPT-6.1 Sol$10
GPT-6.1 Terra$5

출력 100만 토큰당 표준 API 가격.

화면을 보고 조작하는 일에 강하다

OpenAI는 이 모델을 시각 추론, 정밀한 컴퓨터 조작, 자연스러운 글쓰기에 맞춰 내놨다. 입력은 텍스트와 이미지, 출력은 텍스트다. 기술 도면을 해석하거나 앱 화면을 보고 양식을 채우는 것처럼, 하루 업무를 채우는 자잘한 화면 작업을 맡기기 좋다.

API는 강도 조절, Codex는 사용량 절약

API 모델 ID는 gpt-6.1-terra다. 추론 강도에 따라 성격이 꽤 달라서 작업마다 골라 쓰면 된다.

설정특징맞는 작업
추론 없음가장 빠름 (초당 약 91토큰)짧은 답변, 분류, 문장 다듬기
최고 강도가장 똑똑함, Sol과 차이 작음코드 수정, 복잡한 양식 처리

ChatGPT Work와 Codex에서는 Terra를 고르면 같은 사용 한도로 더 많은 작업을 돌릴 수 있다.

가장 어려운 코딩은 Sol·Astra로

코딩 성능은 이전 Terra보다 크게 올랐지만, OpenAI도 가장 복잡한 코딩은 Sol이나 Astra가 낫다고 밝힌다. 성능 수치는 대부분 OpenAI 발표라서 실제 작업으로 직접 비교해 보는 게 안전하다.

사람들은 주로 이렇게 쓴다
