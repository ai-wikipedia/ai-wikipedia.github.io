DeepSeek

중국 AI 기업이 만든 오픈소스 대규모 언어 모델로, 가중치를 MIT 라이선스로 공개해 누구나 내려받아 쓸 수 있다. 비용을 아끼고 싶거나 데이터를 밖으로 보낼 수 없어 로컬에서 모델을 돌려야 할 때 쓴다.

한눈에 보기

DeepSeek은 중국 항저우의 AI 기업이 만드는 오픈소스 언어 모델 시리즈다. 최상위 모델에 가까운 성능을 훨씬 적은 비용으로 만들었고, 가중치를 MIT 라이선스로 공개해 상업적으로도 자유롭게 쓸 수 있다. 싼 API가 필요하거나 내 컴퓨터에서 직접 모델을 돌려야 할 때 고른다.

모델특징이럴 때 쓴다
DeepSeek-R1단계별로 생각하는 추론 모델수학·논리처럼 따져 봐야 하는 문제
R1 증류 버전R1을 작게 줄인 모델노트북에서 로컬 실행
DeepSeek-V4100만 토큰 컨텍스트, Pro·Flash 두 종류코드베이스 전체나 긴 문서를 한 번에 넣을 때

적게 계산하고 같은 결과를 낸다

DeepSeek의 강점은 효율이다. 거대한 모델이지만 질문 하나를 처리할 때는 일부만 켜서 계산량을 줄이는 방식(MoE)을 쓴다. 그래서 GPT-4급 모델에 1억 달러 넘게 든다고 여겨지던 때에 비슷한 성능을 훨씬 싸게 만들었다.

GPT-4급 통념1억 달러 이상
DeepSeek-V3약 600만 달러

학습 비용 기준. DeepSeek 수치는 회사 발표이며, 집계 방식을 두고 논쟁이 있었다.

API는 주소만 바꾸고, 로컬은 한 줄이면 된다

API로 쓸 때는 OpenAI와 같은 형식이라 기존 코드에서 base_url과 API 키만 바꾸면 된다. 비용이 부담되는 프로젝트에서 모델만 바꿔 끼우기 좋다.

로컬에서 쓸 때는 Ollama에서 ollama run deepseek-r1을 실행하면 경량 증류 버전이 돌아간다. 회사 데이터처럼 외부로 보낼 수 없는 자료를 다룰 때 알맞다. 최상위 모델을 직접 돌리려면 GPU가 많이 필요해서, 보통은 증류 버전을 쓰거나 클라우드 호스팅 업체를 거친다.

V4는 긴 문맥을 현실적인 값에

2026년 4월 공개된 V4는 100만 토큰을 한 번에 받는다. 긴 문맥에서 드는 연산을 V3.2의 4분의 1 수준으로 줄였다고 발표됐다. 그래서 코드 저장소 전체나 책 여러 권 분량을 넣는 작업도 비용을 감당할 만해졌다. 큰 작업은 V4-Pro, 가볍고 빠른 작업은 V4-Flash를 쓰면 된다.

민감한 데이터는 로컬로

중국 기업의 API라 데이터 프라이버시와 특정 주제 검열에 대한 우려가 있다. 민감한 내용은 API 대신 가중치를 받아 로컬에서 돌리는 편이 안전하다. 한국어 성능은 영어·중국어보다 떨어질 수 있으니 한국어 작업은 미리 시험해 보는 게 좋다.
