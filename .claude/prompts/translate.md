아래 AI Wiki 항목의 요약(sum)과 상세(det)를 영어(en), 중국어 간체(zh), 일본어(ja)로 번역하라. 결과는 지정된 JSON 스키마로만 출력한다.

## 번역 규칙
- HTML 태그 구조(`<h4>`, `<p>`, `<strong>`, `<code>`, `<em>`)를 원문과 똑같이 유지한다. 태그를 추가·삭제하지 않는다.
- `<code>` 안의 내용, 제품·브랜드·모델명(Claude, GPT, MCP 등), 널리 쓰이는 영어 기술 용어는 번역하지 않는다.
- 직역보다 각 언어 독자가 자연스럽게 읽히는 문장으로 옮기되, 내용을 더하거나 빼지 않는다.
- 섹션 제목(`<h4>`)도 해당 언어로 자연스럽게 번역한다.
