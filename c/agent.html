에이전트

스스로 판단하고 도구를 써서 일을 끝까지 처리하는 것이 AI 에이전트입니다. 한 번 묻고 한 번 답하는 챗봇과 달리, 에이전트는 목표를 받으면 계획을 세우고 도구를 골라 쓰고 결과를 확인하며 여러 단계를 돌립니다. AI 에이전트 항목에서 기본 그림을 잡은 뒤, 생각과 행동을 번갈아 반복하는 ReAct 패턴, 여러 에이전트가 역할을 나누는 멀티에이전트, 작업 기억을 유지하는 에이전트 메모리로 확장해보세요. 에이전트끼리 통신하는 A2A 같은 프로토콜, 브라우저를 조작하는 컴퓨터 유즈, 에이전트를 평가하는 방법론까지 — "알아서 일하는 AI"를 이해하는 키워드를 모았습니다.
  • 도커 에이전트 Docker AgentDocker Agent는 역할이 다른 AI 에이전트 여러 개를 YAML 파일 하나로 팀으로 묶고 `docker agent` 명령으로 실행하는 Docker의 오픈소스 프레임워크다. 코드를 짜지 않고 에이전트 팀을 만들고, 그 구성을 컨테이너 이미지처럼 팀원과 공유하고 싶을 때 쓴다.
  • 랭그래프 LangGraphLangGraph는 AI 에이전트가 일하는 순서를 그래프(단계와 연결선)로 그려서 만드는 프레임워크다. 조건에 따라 길이 갈리거나, 같은 단계를 반복하거나, 중간에 사람이 승인해야 하는 에이전트를 만들 때 쓴다.
  • 레코드 앤 리플레이 Record and Replay (AI Skill Creation)레코드 앤 리플레이는 Mac에서 업무 흐름을 한 번 직접 해 보이면, AI가 그 과정을 기록해 다시 쓸 수 있는 스킬(SKILL.md)로 만들어 주는 기능이다. 반복 업무를 프롬프트로 길게 설명하지 않고 한 번 보여 준 뒤, 다음부터 에이전트에게 맡길 때 쓴다.
  • 루프 엔지니어링 Loop EngineeringAI 에이전트가 목표를 이룰 때까지 행동하고, 결과를 보고, 다음 행동을 정하는 일을 스스로 되풀이하게 만드는 시스템 설계 기술이다. 단계마다 프롬프트를 직접 넣지 않고 목표만 정해 둔 채 에이전트에게 끝까지 맡기고 싶을 때 쓴다.
  • 리서치 기반 에이전트 Research-Driven Agent조사 목표를 주면 검색, 자료 수집, 분석, 보고서 작성까지 여러 단계를 스스로 계획하고 실행하는 AI 에이전트다. 사람이 며칠씩 걸리던 자료 조사나 보고서 초안을 빨리 만들고 싶을 때 쓴다.
  • 멀티 에이전트 Multi-Agent System여러 AI 에이전트가 조사·코딩·검증처럼 역할을 나눠 하나의 작업을 함께 처리하는 시스템이다. 에이전트 하나로는 컨텍스트가 모자라는 복잡한 작업을 나눠서 동시에 처리할 때 쓴다.
  • 서머라이저 Summarizer서머라이저는 AI 에이전트가 일하면서 쌓인 긴 컨텍스트를 핵심만 남겨 압축하고 다음 모델에 넘기는 단계다. 컨텍스트 윈도우가 꽉 차거나 토큰 비용이 커질 때 에이전트 사이, RAG, 긴 대화에 끼워 넣어 쓴다.
  • 셀프 스캐폴딩 LLM Self-Scaffolding LLMLLM이 자기를 감싸는 실행 구조(스캐폴드)를 작업마다 직접 짜고, 그 구조를 따라 문제를 푸는 방식이다. 사람이 고정된 에이전트 하네스를 손으로 설계하는 대신, 작업 유형에 맞는 진행 절차를 모델에게 맡기고 싶을 때 쓴다.
  • 에이전틱 검색 Agentic Search에이전틱 검색은 AI 에이전트가 무엇을 찾을지 스스로 정하고, 결과를 읽어 본 뒤 모자라면 다시 검색하는 반복 방식이다. 문서 한 조각으로는 답이 안 나오는 복잡한 질문이나 자주 바뀌는 정보를 찾을 때 쓴다.
  • 에이전틱 OS Agentic Operating SystemAI 에이전트가 기억을 이어 가고, 도구를 쓰고, 여러 단계에 걸친 일을 계속할 수 있게 메모리·도구·권한·조율 기능을 한곳에 묶은 운영 계층이다. 에이전트에게 맥락을 매번 처음부터 알려주지 않고 며칠짜리 작업을 맡기고 싶을 때 쓴다.
  • 오픈 멀티 에이전트 Open Multi-Agent목표 한 줄을 주면 할 일을 작업 그래프(task DAG)로 쪼개 여러 에이전트에게 나눠 맡기는 오픈소스 프레임워크다. 멀티 에이전트의 작업 순서를 손으로 엮지 않고 자동으로 돌리고 싶을 때 쓴다.
  • 오픈태그 OpenTagOpenTag은 Slack이나 Teams 채널에서 AI를 멘션해 일을 맡기면 결과를 같은 스레드에 올려 주는 'AI 동료'형 에이전트다. 특정 모델 회사에 묶이지 않고 작업마다 모델을 고르거나 직접 서버를 운영하고 싶을 때 쓴다.
  • 크리틱 패턴 Critic Pattern한 AI가 만든 답을 다른 AI가 읽고 점수나 피드백을 주는 구조다. 답변이 너무 많아 사람이 다 검토할 수 없을 때 품질을 자동으로 재고 고치는 데 쓴다.
  • 툴 콜링 Tool CallingLLM이 외부 함수나 API를 '이 인자로 불러 달라'고 요청하고, 실제 실행은 개발자 코드가 맡는 기능이다. 검색, 계산, DB 조회처럼 모델 혼자서는 못 하는 일을 시킬 때 쓴다.
  • 휴먼 인 더 루프 Human-in-the-LoopAI 에이전트가 위험한 행동을 하기 직전에 멈추고 사람의 승인을 받게 하는 설계 방식이다. 파일 삭제, 결제, 이메일 발송처럼 되돌리기 어려운 작업에 쓴다.
