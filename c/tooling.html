도구

AI를 실제 개발과 업무에 활용하게 해주는 도구와 표준입니다. 모델 자체는 텍스트를 주고받는 것밖에 못 하기 때문에, 파일을 읽고 명령을 실행하고 외부 서비스에 연결하는 일은 전부 도구 계층이 담당합니다. 터미널에서 코드를 짜주는 Claude Code, 모델과 외부 시스템을 잇는 표준 프로토콜 MCP, 에이전트 애플리케이션을 조립하는 LangChain이 대표적입니다. 도구를 확장하는 방식인 스킬과 훅, 프로젝트 규칙을 심는 CLAUDE.md처럼 실무에서 매일 마주치는 설정 개념들도 함께 다룹니다. AI 코딩을 시작했다면 이 카테고리의 용어부터 부딪히게 됩니다.
  • 가드 스킬 Guard Skills가드 스킬은 AI가 만든 코드·테스트·문서가 자주 빠지는 함정을 잡아내는 2차 검증용 스킬이다. 에이전트가 작업을 마친 뒤 커밋·머지하기 직전에 변경분에 한 번 더 돌려서 쓴다.
  • 구스 Goose (Block AI Agent)구스(Goose)는 Block이 만든 오픈소스 AI 에이전트로, 내 컴퓨터에서 돌아가며 원하는 LLM을 연결해 코드 수정부터 테스트, 에러 수정까지 직접 실행한다. 특정 모델에 묶이지 않는 로컬 코딩 에이전트가 필요할 때 쓴다.
  • 그래파이 GraphifyGraphify(그래파이)는 프로젝트 전체를 지식 그래프로 만들어 주는 오픈소스 스킬이다. AI 코딩 어시스턴트가 파일을 하나하나 열어 보지 않고도 코드 구조를 물어보고 답을 얻어야 할 때 쓴다.
  • 다이나믹 워크플로우 Dynamic WorkflowsClaude가 큰 작업을 받으면 그 작업에 맞는 지휘 스크립트를 직접 짜서 여러 서브에이전트를 병렬로 돌리고, 검증된 결과만 모아 주는 Claude Code 기능이다. 대규모 마이그레이션이나 깊은 조사처럼 단계가 많은 작업에 쓴다.
  • 랭체인 LangChainLLM 호출, 메모리, 도구 연동, 에이전트 실행을 하나의 인터페이스로 묶은 오픈소스 프레임워크다. 문서 기반 챗봇(RAG)이나 도구를 쓰는 AI 에이전트를 Python으로 빠르게 만들 때 쓴다.
  • 슈퍼파워스 SuperpowersClaude Code가 코드부터 짜지 않고 브레인스토밍·계획·테스트·리뷰 순서를 따르게 만드는 오픈소스 스킬 묶음(플러그인)이다. 복잡한 기능 개발이나 디버깅처럼 절차가 필요한 작업에 쓴다.
  • 오크 Oak (Agent-Native Version Control)오크(Oak)는 AI 코딩 에이전트에 맞춰 새로 만든 버전 관리 시스템이다. 에이전트 여러 개가 한 저장소에서 동시에 작업할 때 Git의 클론 시간과 worktree 충돌을 줄이고 싶다면 쓴다.
  • 오픈AI SDK OpenAI SDKOpenAI 모델을 Python·TypeScript 코드에서 함수 호출처럼 부를 수 있게 해 주는 공식 라이브러리다. 내 프로그램에 채팅·이미지·음성·임베딩 기능을 붙이거나 에이전트를 만들 때 쓴다.
  • 위브 라우터 Weave Router위브 라우터는 코딩 에이전트와 모델 제공사 사이에 두는 프록시로, 요청마다 난이도를 보고 감당할 수 있는 가장 싼 모델로 자동으로 보낸다. Claude Code 같은 에이전트를 많이 돌려서 비용을 줄이고 싶을 때 쓴다.
  • 제브 라우터 Jev Router (TypeSafe)제브 라우터는 TypeSafe의 판단 전용 모델 Jev가 요청마다 알맞은 LLM과 추론 강도를 골라 주는 자동 라우터다. 쉬운 요청과 어려운 요청이 섞인 서비스에서 엔드포인트 하나로 품질·속도·비용을 맞추고 싶을 때 쓴다.
  • 케이브맨 CavemanAI가 원시인처럼 핵심만 짧게 말하게 해서 출력 토큰을 줄이는 Claude Code 스킬이다. 사용량 한도가 빠듯하거나, 이미 익숙한 작업을 길게 반복시키는 세션에서 켜 둔다.
  • 코드번 CodeburnCodeBurn은 Claude Code, Codex 같은 AI 코딩 도구가 토큰과 비용을 어디에 썼는지 터미널 대시보드로 보여주는 오픈소스 도구다. 구독 한도가 너무 빨리 차거나, 어떤 작업에서 토큰이 새는지 알고 싶을 때 쓴다.
  • 클로드 코드 Claude Code CLI터미널에서 자연어로 지시하면 코드를 읽고, 고치고, 테스트하고, 커밋까지 해 주는 AI 코딩 에이전트다. 작업 하나를 통째로 맡기고 결과만 검토하고 싶을 때 쓴다.
  • 포니테일 Ponytail (AI Coding Agent Skill)포니테일은 AI 코딩 에이전트가 코드를 쓰기 전에 "더 단순한 방법은 없는가"를 먼저 따져 보게 하는 오픈소스 스킬이다. 에이전트가 필요 이상으로 코드를 만드는 과잉 구현을 줄이고 싶을 때 쓴다.
  • 플레이그라운드 AI Playground플레이그라운드는 코드 없이 브라우저에서 바로 LLM을 불러 프롬프트를 시험하는 웹 화면이다. 새 프롬프트가 잘 먹히는지 빠르게 확인하고 다듬을 때 쓴다.
  • auth.md auth.md Agent Authentication Protocolauth.md는 AI 에이전트가 외부 서비스에 접속할 때 필요한 인증 방법을 적어 두는 마크다운 파일 협약이다. 에이전트가 GitHub·Slack·데이터베이스 같은 서비스를 쓰는 프로젝트에서 API 키 위치, OAuth, 권한 범위를 사람과 에이전트 모두에게 알려줄 때 쓴다.
  • MCP Model Context ProtocolMCP는 AI 앱이 외부 도구와 데이터에 연결할 때 쓰는 공통 규격이다. 서버를 한 번만 만들어 두면 Claude Code, Cursor, ChatGPT처럼 MCP를 지원하는 모든 AI 앱에서 같은 방식으로 쓸 수 있다.
  • MCPB MCP Bundle (MCPB)MCPB(MCP Bundle)는 로컬 MCP 서버와 설명서 manifest.json을 ZIP 파일 하나(.mcpb)로 묶은 배포 포맷이다. 터미널이나 설정 파일을 몰라도 MCP 서버를 설치하게 하고 싶을 때 쓴다.
