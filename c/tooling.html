도구

AI를 실제 개발과 업무에 활용하게 해주는 도구와 표준입니다. 모델 자체는 텍스트를 주고받는 것밖에 못 하기 때문에, 파일을 읽고 명령을 실행하고 외부 서비스에 연결하는 일은 전부 도구 계층이 담당합니다. 터미널에서 코드를 짜주는 Claude Code, 모델과 외부 시스템을 잇는 표준 프로토콜 MCP, 에이전트 애플리케이션을 조립하는 LangChain이 대표적입니다. 도구를 확장하는 방식인 스킬과 훅, 프로젝트 규칙을 심는 CLAUDE.md처럼 실무에서 매일 마주치는 설정 개념들도 함께 다룹니다. AI 코딩을 시작했다면 이 카테고리의 용어부터 부딪히게 됩니다.
  • 가드 스킬 Guard Skills가드 스킬은 AI 코딩 에이전트가 작업을 마친 뒤 그 변경분(diff)에 한 번 더 돌리는 2차 검증용 스킬로, 겉으로는 그럴듯하지만 허점이 있는 AI 코드·테스트·문서를 커밋·머지 직전에 걸러낼 때 쓴다. 가드마다 맡는 영역이 정해져 있어서 무엇을 바꿨는지에 따라 골라 부른다.

  • 그래파이 GraphifyGraphify(그래파이)는 프로젝트의 함수·클래스·DB 테이블·API 핸들러·설계 문서를 점과 선으로 이어 AI가 볼 수 있는 코드 지도(지식 그래프)로 만들어 주는 오픈소스 스킬이다. AI 코딩 어시스턴트가 파일을 하나씩 열지 않고도 "이 기능이 어디와 연결돼 있지?" 같은 질문에 적은 토큰으로 답하게 하고 싶을 때 쓴다.

  • 깃허브 코파일럿 GitHub CopilotGitHub이 만든 AI 코딩 도구로, 입력하는 동안 다음 코드를 미리 제안하는 자동완성에서 출발해 지금은 한 구독으로 채팅과 에이전트까지 쓸 수 있다. 쓰던 편집기와 GitHub 저장소를 그대로 두고 AI 도움을 받고 싶을 때 고르면 된다.

  • 도구 사용 Tool Use / Function Calling텍스트만 만드는 AI 모델이 호출할 함수와 인자를 골라 요청하면, 개발자 코드가 그 함수를 실행해 결과를 돌려주는 방식이다(OpenAI에서는 Function Calling). 최신 정보 조회, DB 검색, 파일 수정처럼 모델 밖의 일을 맡길 때 쓰며, 에이전트에게 "손"을 달아 주는 기능이다.
  • 딥시크 서치 API DeepSeek Search & Fetch APIDeepSeek가 모델 API와 함께 내놓은 웹 검색·페이지 읽기 API다. 에이전트나 RAG 앱이 학습 데이터가 아니라 지금 웹에 있는 내용을 보고 답해야 할 때 쓰며, Search로 쓸 만한 페이지를 찾고 Fetch로 그 본문을 읽는 두 단계로 나뉜다.
  • 딥시크 하네스 DeepSeek Harness (DSH)딥시크가 MIT 라이선스로 공개한 오픈소스 에이전트 하네스(명령어 dsh)로, 언어 모델이 파일을 읽고 고치고 명령을 실행하게 해 실제로 일하는 코딩 에이전트로 만들어 준다. 모델 연결부·도구·세션 기록·에이전트 루프까지 모두 플러그인으로 갈아 끼울 수 있어서, 원하는 모델로 내 코딩 에이전트를 직접 구성하고 싶을 때 쓴다.
  • 라마인덱스 LlamaIndex내 문서·DB·API 데이터를 LLM에 연결해 주는 오픈소스 프레임워크로, 문서를 읽고 나눠 인덱스로 만든 뒤 질문에 맞는 부분을 찾아 LLM에 넘기는 RAG 전 과정을 짧은 코드로 처리한다. 사내 문서 Q&A처럼 내 데이터를 바탕으로 답하는 앱을 빠르게 만들 때 쓴다.
  • 라우팅 패턴 Routing Pattern들어온 요청의 난이도나 종류를 보고 그 요청에 맞는 LLM을 골라 보내는 구조다. 쉬운 요청은 작고 싼 모델로, 어려운 요청은 큰 모델로 나눠 비용은 줄이면서 어려운 요청의 품질은 지키고 싶을 때 쓴다.
  • 랭스미스 LangSmithLangSmith는 LangChain이 만든 LLM 앱 관찰·평가 플랫폼으로, 모델 호출의 입력·출력·중간 단계를 기록해 이상한 답의 원인을 찾거나 프롬프트를 고친 뒤 품질이 떨어지지 않았는지 확인할 때 쓴다. 프롬프트와 에이전트를 감이 아니라 기록과 비교를 보며 고치고 싶을 때 맞는 도구다.
  • 랭체인 LangChainLLM 호출, 메모리, 도구 연동, 에이전트 실행을 표준 부품으로 묶은 오픈소스 프레임워크로, 모델·도구·데이터베이스를 부품처럼 끼웠다 뺐다 하며 문서 기반 챗봇(RAG)이나 도구를 쓰는 AI 에이전트를 Python으로 빠르게 만들 때 쓴다. 대화 기억, 재시도, 모델 교체처럼 매번 반복되는 일을 다시 짤 필요가 없어 앱의 핵심 로직에만 집중할 수 있다.
  • 랭퓨즈 LangfuseLLM 앱이 실제로 무엇을 했는지 트레이스(실행 기록)로 남겨 호출 과정, 비용, 품질을 분석하는 오픈소스 관측성 플랫폼이다. 실제 사용자가 쓰기 시작한 챗봇이나 에이전트가 어디서 틀리고 비용을 얼마나 쓰는지 확인할 때 붙인다.

  • 사이언 Scion (Anthropic Version Control System)사이언은 Anthropic이 자사 모노레포에서 Git 대신 쓰려고 직접 만든 서버 중심 버전 관리 시스템으로, 주 사용자를 항상 온라인인 AI 에이전트와 CI 작업으로 보고 대량의 병합·체크아웃을 서버가 맡게 했다. 외부에 공개되지 않는 사내 도구라서 직접 쓰기보다 대규모 에이전트 개발 환경의 설계 사례로 참고하면 된다.
  • 슈퍼파워스 SuperpowersClaude Code가 곧장 코드부터 짜지 않고 요구사항 정리 → 계획 → 테스트 → 리뷰 순서를 따르게 만드는 오픈소스 스킬 묶음(플러그인)이다. 그냥 맡기면 테스트를 건너뛰고 엉성한 결과를 내기 쉬운 복잡한 기능 개발이나 디버깅에 쓴다.
  • 스킬 Skills / Slash Commands스킬은 커밋·리뷰·배포처럼 매번 같은 순서로 하는 일의 지시를 SKILL.md 파일 하나로 저장해 두고 /이름 한 줄로 실행하는 Claude Code의 재사용 워크플로우다. 항상 읽히는 CLAUDE.md와 달리 필요할 때만 불리며, 설명을 보고 Claude가 알아서 꺼내 쓰기도 한다.
  • 스테이트리스 MCP Stateless MCP2026-07-28 명세에 들어간 MCP 구조로, 세션 없이 프로토콜 버전·클라이언트 정보·지원 기능을 요청마다 담아 보내서 요청 하나만 봐도 처리할 수 있다. 초기화 핸드셰이크로 세션을 먼저 만들던 이전 방식과 달리, 원격 MCP 서버를 일반 로드밸런서나 서버리스에 올려 여러 대로 늘릴 때 특히 도움이 된다.

  • 에이전트 세션 리플레이 Agent Session ReplayAI 에이전트가 한 번 실행되는 동안 남긴 프롬프트, 응답, 도구 호출, 결과를 실제로 일어난 순서대로 타임라인에 다시 펼쳐 보는 디버깅 방식이다. 로그를 grep해 머릿속으로 순서를 맞추는 대신 세션 하나를 열어 따라가며, 에이전트가 실제로 무엇을 했는지, 왜 같은 일을 반복했는지, 어디서 엉뚱한 길로 빠졌는지 찾을 때 쓴다.
  • 에이전트 CLI Agent-Friendly CLIAI 에이전트가 화면(GUI) 대신 터미널 명령(CLI)으로 일하는 방식이자, 에이전트가 쓰기 좋게 CLI를 다시 설계하는 흐름이다. git·빌드·테스트 같은 로컬 작업은 CLI로 맡기고, 인증이 필요한 원격 서비스는 MCP로 나누는 게 일반적이다.
  • 오크 Oak (Agent-Native Version Control)오크(Oak)는 AI 코딩 에이전트에 맞춰 새로 만든 에이전트 전용 버전 관리 시스템으로, 작업 단위를 커밋이 아니라 세션으로 잡는다. 에이전트 여러 개가 한 저장소에서 동시에 일할 때 Git의 클론 시간과 worktree 충돌을 줄이고 서로 부딪히지 않게 병렬로 돌리고 싶다면 쓴다.
  • 오픈 메모리 프로토콜 Open Memory Protocol여러 AI 도구가 하나의 로컬 메모리 저장소를 함께 읽고 쓰게 하는 MCP 기반 오픈소스 프로토콜이다. Claude에서 쌓은 프로젝트 맥락을 다른 도구에서 다시 설명하지 않고 이어 쓰고 싶을 때 쓴다.
