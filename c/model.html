  • Phi-4 Phi-4 (Microsoft)Phi-4는 마이크로소프트가 만든 140억 파라미터 규모의 작은 오픈 모델로, 크기에 비해 수학과 논리 추론을 잘한다. 내 컴퓨터나 작은 서버에서 비용을 아끼면서도 어느 정도 추론력이 필요한 작업을 맡길 때 쓴다.
  • RLHF RL from Human Feedback사람이 더 나은 답을 고른 선호 데이터로 LLM을 도움이 되고 해롭지 않은 쪽으로 다듬는 학습 기법이다. 모델의 말투·거절·장황함 같은 "성격"이 이 단계에서 만들어지므로, 모델 행동을 이해하거나 직접 선호 학습을 해볼 때 알아두면 좋다.
