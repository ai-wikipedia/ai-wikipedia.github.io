GPT·Claude·Gemini 같은 대규모 언어 모델은 AI의 "두뇌"에 해당합니다. 이 분야의 용어는 크게 세 갈래입니다. 모델이 글을 이해하고 생성하는 원리(트랜스포머, 어텐션, 토큰), 모델을 만들고 다듬는 과정(사전학습, 파인튜닝, RLHF, LoRA), 그리고 모델을 가볍고 빠르게 만드는 기술(양자화, 증류, MoE)입니다. LLM 항목에서 출발해 트랜스포머로 내려가면 뉴스에서 스치던 용어들이 하나의 이야기로 연결됩니다. 멀티모달·추론 모델처럼 최근 모델들이 어디로 진화하고 있는지 보여주는 키워드도 함께 모았습니다.

  • RLHF RL from Human Feedback사전학습을 마친 LLM을 사람이 더 나은 답을 고른 선호 데이터로 다듬어 도움이 되고 해롭지 않은 어시스턴트로 만드는 학습 기법이다. 능력은 사전학습이 만들고 말투·거절·장황함 같은 모델의 "성격"은 RLHF가 만든다. 그래서 모델 행동을 이해하거나 직접 선호 학습을 해볼 때 알아두면 좋다.
  • SFT Supervised Fine-Tuning질문과 좋은 답변을 짝지은 데이터로 사전학습 모델을 추가 학습해, 모델이 지시를 따르고 원하는 형식과 말투로 답하게 만드는 방법이다. RLHF나 DPO 같은 선호 학습보다 먼저 거치는 첫 단계다.
