응용

AI가 실제 제품과 현장에서 어떻게 쓰이는지에 관한 개념입니다. 모델과 기법이 재료라면 이 카테고리는 완성된 요리에 해당합니다. 개발 현장을 바꾸고 있는 AI 코딩과 바이브 코딩, 검색의 판도를 흔드는 AI 검색, 가장 오래된 응용인 챗봇, 반복 업무를 자동화하는 AI 워크플로우가 큰 줄기입니다. 텍스트를 넘어 이미지·영상·음성을 만드는 생성 기술, 문서를 읽고 처리하는 문서 AI, 코드 리뷰·테스트 생성처럼 개발 파이프라인 곳곳에 스며든 세부 응용까지 — 기술이 실제 가치로 바뀌는 지점의 키워드를 모았습니다.
  • 구조화된 출력 Structured OutputAI 응답이 개발자가 정한 JSON 스키마를 반드시 따르도록 강제하는 기능이다. LLM의 출력을 사람이 아니라 코드가 받아 처리할 때 쓴다.
  • 나노 바나나 Nano Banana (Gemini Image)구글이 만든 Gemini 기반 이미지 생성·편집 모델이다. 사진을 올리고 "이렇게 바꿔줘"라고 말로 지시해 고치거나, 여러 장을 합치거나, 같은 인물이 이어지는 그림을 만들 때 쓴다.
  • 나노 바나나 2 Nano Banana 2 (Gemini 3.1 Flash Image)나노 바나나 2는 구글 딥마인드의 이미지 생성·편집 모델(Gemini 3.1 Flash Image)로, Pro급 기능을 더 빠르고 싸게 쓸 수 있다. 같은 인물·제품을 여러 장에 유지해야 하는 작업이나 작은 썸네일을 많이 만들 때 쓴다.
  • 나노 바나나 2.1 Nano Banana 2.1 (Google)나노 바나나 2.1은 Google의 이미지 생성·대화형 편집 모델로, 나노 바나나 2의 후속작이다. 속도와 비용은 2와 같은 수준으로 두고 품질을 높여서, 대부분의 이미지 만들기·고치기 작업에 기본으로 쓴다.
  • 나노 바나나 프로 Nano Banana Pro (Gemini 3 Pro Image)나노 바나나 프로는 구글의 이미지 생성·편집 모델로, 공식 이름은 Gemini 3 Pro Image다. 이미지 속 글자를 정확히 넣어야 할 때, 인포그래픽처럼 정보가 맞아야 할 때, 여러 참조 이미지로 캐릭터·브랜드를 일관되게 유지해야 할 때 쓴다.
  • 런웨이 Runway (Gen)런웨이는 글이나 사진 한 장을 넣으면 짧은 영상으로 만들어 주는 AI 영상 생성·편집 서비스다. 광고 시안, 숏폼, 영화 콘셉트 영상을 코드 없이 브라우저에서 만들 때 쓴다.
  • 리리아 Lyria (Google)구글 딥마인드가 만든 음악 생성 AI로, 텍스트나 사진을 넣으면 보컬과 반주가 들어간 곡을 만들어 준다. 영상 배경음악이나 짧은 곡이 필요할 때 쓴다.
  • 미드저니 Midjourney글로 적은 장면을 그림으로 바꿔주는 대표적인 AI 이미지 생성 서비스다. 전문가가 다듬은 듯한 화풍이 강점이라, 광고 시안이나 컨셉아트처럼 그럴듯한 시각물이 빠르게 필요할 때 쓴다.
  • 바이브 코딩 Vibe Coding원하는 결과를 말로 설명하면 AI가 코드를 만들어 주고, 사람은 실행 결과를 보며 말로 고쳐 나가는 개발 방식이다. 빠른 프로토타입이나 아이디어 검증, 내부 도구를 만들 때 쓴다.
  • 비오 Veo (Google)Veo는 구글 딥마인드가 만든 영상 생성 AI로, 글로 적은 장면 묘사나 이미지를 짧은 동영상으로 만들어 준다. 소리까지 함께 만들어 주므로 촬영이나 편집 없이 장면 하나를 빨리 만들어야 할 때 쓴다.
  • 소라 Sora (OpenAI)Sora는 OpenAI가 만든 영상 생성 모델로, 장면을 글이나 이미지로 설명하면 짧은 동영상을 만들어 준다. 앱에서 바로 쓰거나, 개발자는 API로 서비스에 붙여 유튜브·틱톡용 영상을 뽑을 때 쓴다.
  • 수노 SunoSuno는 짧은 설명이나 가사만 넣으면 보컬과 반주까지 갖춘 완성곡을 1분 안에 만들어 주는 AI 음악 생성 서비스다. 영상 배경음악이나 팟캐스트 인트로처럼 곡이 필요하지만 작곡을 할 줄 모를 때 쓴다.
  • 아이디오그램 Ideogram이미지 안에 글자를 정확하게 그려 넣는 데 특화된 이미지 생성 AI다. 로고·포스터·간판처럼 글씨가 핵심인 디자인 시안을 빠르게 만들 때 쓴다.
  • 에이전틱 엔지니어링 Agentic EngineeringAI 에이전트가 코드를 쓰고, 사람은 설계와 검증, 품질을 책임지는 개발 방식이다. 바이브 코딩처럼 '일단 돌아가면 OK'로 끝내지 않고, 테스트와 리뷰를 갖춘 채 에이전트에게 실제 개발을 맡길 때 쓴다.
  • 이미지 인페인팅 Image Inpainting이미지 인페인팅은 사진에서 지우거나 망가진 부분을 주변 정보로 자연스럽게 채우는 기술이다. 원치 않는 물체 지우기, 오래된 사진 복원, 마스크로 고른 부분만 프롬프트대로 바꾸는 편집에 쓴다.
  • 일레븐랩스 ElevenLabsElevenLabs는 글자를 사람 목소리처럼 자연스럽게 읽어주는 AI 음성 서비스다. 영상 내레이션이나 더빙을 만들 때, 내 목소리를 복제해 쓸 때, 전화 응대용 음성 에이전트를 만들 때 쓴다.
  • 질의응답 Question Answering자연어 질문을 이해하고 문서나 지식베이스에서 근거를 찾아 답 한 줄을 돌려주는 AI 기능이다. 사내 규정 챗봇이나 AI 검색처럼 문서 목록 대신 바로 답이 필요할 때 쓰며, RAG의 가장 대표적인 쓰임새다.
  • 챗봇 Conversational AI사람 말로 묻고 답하며 질문 응대나 간단한 업무를 처리하는 AI다. 고객 지원, 사내 문서 안내, 주문 조회처럼 자주 반복되는 문의를 맡길 때 쓴다.
  • 클링 Kling (Kuaishou)중국 숏폼 플랫폼 콰이쇼우가 만든 AI 영상 생성 모델이다. 글이나 사진 한 장으로 몇 초짜리 영상을 만들 때 쓰고, 카메라 움직임까지 직접 지시할 수 있다.
  • AI 검색 AI-Powered Search키워드가 아니라 질문의 뜻을 이해해서 문서를 찾고, 링크 목록 대신 출처가 달린 답변을 바로 써 주는 검색이다. 기술 조사처럼 여러 문서를 읽고 정리해야 할 때나, 사내 문서를 자연어로 검색하고 싶을 때 쓴다.
  • AI 디자인 AI-Powered DesignAI 디자인은 만들고 싶은 화면이나 그래픽을 말로 설명하면 AI가 와이어프레임, 프로토타입, 그래픽 초안을 만들어 주는 방식이다. 디자이너 없이 화면을 빨리 만들어야 하거나 여러 시안을 빠르게 시험해 볼 때 쓴다.
  • AI 코딩 어시스턴트 AI Coding AssistantAI가 코드 작성·디버깅·리뷰를 거드는 개발 도구다. 반복 코드 작성부터 여러 파일에 걸친 기능 구현까지 맡길 수 있고, 에디터·터미널·클라우드 가운데 작업에 맞는 곳에서 골라 쓴다.
  • GEO Generative Engine OptimizationGEO는 Perplexity, ChatGPT Search 같은 AI 검색이 답변을 만들 때 내 글을 출처로 인용하게 만드는 최적화 전략이다. 검색 순위보다 AI 답변 속 인용을 노리고 블로그나 문서를 쓸 때 활용한다.
